---
title: "Changing the Priority of Your MX Records"
---

It is not possible, or necessary, to change the Priority values (e.g., 0, 10, 20) of MX records in Wix.

The Priority values of your MX records are automatically determined by the order in which you add them. The first record you add is given a Priority value of 10, the next is given a Priority of 20, and so on. 

When adding MX records, add the record with the lowest Priority value first. Then, continue adding the records in order, with the second lowest Priority value next, and so on. 

MX record Priority values are only arbitrary numbers that indicate the order of the records. Their numbers do not need to match the values in your email provider's directions, but they do need to be in the same order.
