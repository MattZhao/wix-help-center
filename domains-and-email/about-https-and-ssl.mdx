### What is HTTPS?

Hypertext Transfer Protocol Secure (HTTPS) is a method for sending and receiving information on the internet in a secure way.

With HTTPS enabled, the data that travels between a web browser and a site is encrypted and authenticated, making it much more difficult to intercept. If a site is not secured with HTTPS, data may be intercepted more easily by attackers.

### What is an SSL certificate?

A Secure Sockets Layer (SSL) certificate is a digital certificate that verifies the identity of a website and allows a site to be viewed securely over a HTTPS connection. It secures the connection between your browser and the web address you’re visiting.

When you visit a website with an SSL certificate, your browser will check the certificate to make sure it's valid. Your browser can then use the certificate to encrypt any information you send to the website.

URLs for websites with SSL certificates usually start with "https", and there is often a lock icon beside the URL in your browser's address bar. Depending on your browser, you may see a settings icon or an "i" instead. Usually, clicking the icon shows you more information on the SSL details.

> We provide an SSL certificate automatically for all sites created on Wix at no additional cost.

### Using HTTPS on older browsers

Some older browsers don’t support the higher security standards required by SSL certificates. Visitors accessing your site on these browsers may have trouble loading the HTTPS version of your site.

**Unsupported browsers include: **

Google Chrome versions older than 6  Internet Explorer versions older than 7  Firefox versions older than 2.0  Safari versions older than 2.1  All versions of Internet Explorer on Windows XP

**Unsupported mobile browsers include:**

Safari browsers running on an iOS version older than 4.0  Android browsers running on a version older than 3.0 (Honeycomb)  Windows Phone browsers running on a version older than 7

### FAQs

Click below for answers to common questions about HTTPS and SSL.

### What happens if I visit a site that is not using HTTPS?

Some browsers, such as Google Chrome, now display warnings anytime a user visits a site that is not using HTTPS. If a site is not secured (e.g. does not have the 'S' at the end of 'HTTP'), then site visitors may get a warning message anytime they access the site.

### What can I do if I'm having issues with my HTTPS?

If you're having HTTPS issues, see how to [troubleshoot your SSL Certificate](https://support.wix.com/en/article/troubleshooting-your-ssl-certificate).

### How can I tell if my site has an SSL certificate?

You can see if your site has an SSL certificate if the URL begins with **https://** instead of **http://**.

### Does Wix provide SSL certificates for free?

Yes. All Wix sites include an SSL certificate at no extra cost.

 **Note: **SSL certificates are also provided for custom domains. While the certificate is free, connecting a custom domain to your site does require [upgrading your site with a plan](http://www.wix.com/upgrade/website). Once you connect your domain, the SSL certificate will automatically be generated.

### Do my subdomains have SSL certificates?

Yes. Wix automatically generates a certificate for each custom domain and subdomain connected to your site.

### Is it possible to manually disable an SSL certificate for a Wix site?

No, it is not possible to manually disable an SSL certificate for a Wix site.

### Can I use the SSL from my site for my business email?

The SSL we provide is for your Wix site, and cannot be used for a business email. All Wix sites are enabled with HTTPS, so are created with inbuilt SSL certification.

### What browsers are supported for viewing and editing Wix sites?

Make sure to use a supported browser to edit and view your Wix site. See a [list of Wix's supported browsers](https://support.wix.com/en/article/supported-browsers).
