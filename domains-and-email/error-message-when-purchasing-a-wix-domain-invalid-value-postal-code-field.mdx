---
title: "Error Message When Purchasing a Wix Domain: \"Invalid Value\" (Postal Code Field)"
---

If you are trying to purchase a domain and are seeing the error "Invalid value" next to the postal code field, please make sure that you have entered the correct postal code for your country.

> **Important:**
>
> If you are located in the UK, make sure to include the space in your post code (e.g., SW7 4DN).
