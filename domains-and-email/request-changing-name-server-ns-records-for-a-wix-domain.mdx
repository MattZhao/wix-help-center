---
title: "Request: Changing Name Server (NS) Records for a Wix Domain"
---

Currently, it's not possible to change name servers (edit NS records) for a Wix domain.

You can, however, point your Wix domain to an external site. Learn more in this [article](https://support.wix.com/en/article/connecting-a-wix-domain-to-an-external-site).

To change the name servers, you'll need to [transfer your domain away from Wix.](https://support.wix.com/en/article/transferring-your-wix-domain-away-from-wix-2477749)
