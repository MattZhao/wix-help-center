The blog post sidebar is a quick and handy way to manage things like settings, SEO and categories. For example, as you write your post, you can easily make changes to things like the cover image, the post URL, and the post category etc.

Using the blog post sidebar, you can edit:

[Settings](https://support.wix.com/en/article/wix-blog-editing-a-blog-post-using-the-blog-post-sidebar#editing-settings-using-the-blog-post-sidebar)  [SEO](https://support.wix.com/en/article/wix-blog-editing-a-blog-post-using-the-blog-post-sidebar#editing-seo-using-the-blog-post-sidebar)  [Categories](https://support.wix.com/en/article/wix-blog-editing-a-blog-post-using-the-blog-post-sidebar#adding-and-assigning-categories-using-the-blog-post-sidebar-1)  [Tags](https://support.wix.com/en/article/wix-blog-editing-a-blog-post-using-the-blog-post-sidebar#adding-and-assigning-tags-to-blog-posts)  [Subscriptions](https://support.wix.com/en/article/wix-blog-editing-a-blog-post-using-the-blog-post-sidebar#adding-a-subscription-plan-to-a-blog-post)  [Translations](https://support.wix.com/en/article/wix-blog-editing-a-blog-post-using-the-blog-post-sidebar#translating-your-blog-post)

### Editing settings using the blog post sidebar

You can make quick edits to some settings while writing using the post sidebar. Edit things like the display cover image, the author name, and more.

#### To edit settings using the blog post sidebar:

Go to the [Blog](https://www.wix.com/my-account/site-selector/?buttonText=Manage%20My%20Blog&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https://www.wix.com/dashboard/\{\{metaSiteId\}\}/blog) tab in your site's dashboard.  Click **Manage My Blog**.  Click **Create New Post** or **Edit** to edit an existing post.  Create or edit the post to include the relevant information.  Click the **Settings** tab on the left sidebar.  Edit the following settings:

- Click the **Display Cover Image** toggle to enable or disable the cover image.
- Choose the publish date.
- Choose the author.
- Add an excerpt about the post.
- Click the **Set as Featured Post** toggle:

- **Enabled**: The post appears in the post list.
- **Disabled**: The post does not appear in the post list.

### Editing SEO using the blog post sidebar

Using the sidebar, you can access some SEO settings while writing posts. Here you can edit things like the post URL, the post's title tag and meta description that appears in search engines, and more.

#### To edit SEO using the blog post sidebar:

Go to [your Blog](https://manage.wix.com/my-account/site-selector/?buttonText=Manage%20Blog&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https:%2F%2Fwww.wix.com%2Fdashboard%2F%7B%7BmetaSiteId%7D%7D%2Fblog%2Fpublished) in your site's dashboard.  Select the blog post you want to edit.  Click **SEO **in the left sidebar.  Customize the following SEO settings:

- **URL slug**: This text is the last part of your page's URL. You should only change this if it's necessary to reflect the content of your page. We recommend keeping it short and easy to read.
- **Title tag**: Add a title tag that summarizes the content of the page. Enter your title tag as it is meant to appear on search engines results.
- **Meta description**: Add a short meta description of the content on the page. This description helps users decide if the blog post is relevant to them.
    Click the **Let search engines index this page** toggle to set whether search engines can [crawl and index](https://developers.google.com/search/docs/beginner/how-search-works#crawling) your page or not: 

- **Enabled**: Search engines will index your page. People can find your page when searching keywords and phrases in search engines.
- **Disabled**: Search engines will not index your page. People cannot find your page when searching keywords and phrases in search engines.
    Click **Publish**.

### Adding and assigning categories using the blog post sidebar

You can easily add and assign categories to a blog post as you create your post. You can also create new categories if you don't have  a suitable existing category.

#### To add and assign categories using the blog post sidebar:

Go to the [Blog](https://www.wix.com/my-account/site-selector/?buttonText=Manage%20My%20Blog&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https://www.wix.com/dashboard/\{\{metaSiteId\}\}/blog) tab in your site's dashboard.Click **Manage My Blog**.Click **Create New Post** or **Edit** to edit an existing post.Create or edit the post to include the relevant information.Click the **Categories **tab on the left sidebar.Do one of the following:
- Select a category from the existing options.
- Create a new category for your post.

> **Tip:**
>
> You can assign a post to more than one category.

### Adding and assigning tags to blog posts

You can add keywords known as tags that help organize and describe your post.

#### To add and assign tags to blog posts:

Go to the [Blog](https://www.wix.com/my-account/site-selector/?buttonText=Manage%20My%20Blog&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https://www.wix.com/dashboard/\{\{metaSiteId\}\}/blog) tab in your site's dashboard.  Click **Manage My Blog**.  Click **Create New Post** or **Edit** to edit an existing post.  Create or edit the post to include the relevant information.  Click the **Tags** tab on the left sidebar.   Click the text box and add some keywords that define your post.

### Adding a subscription plan to a blog post

Monetize your blog by adding paid subscription plans to your posts.

#### To add a subscription plan to a blog post:

Go to the [Blog](https://www.wix.com/my-account/site-selector/?buttonText=Manage%20My%20Blog&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https://www.wix.com/dashboard/\{\{metaSiteId\}\}/blog) tab in your site's dashboard.  Click **Manage My Blog**.  Click **Create New Post** or **Edit** to edit an existing post.  Create or edit the post to include the relevant information.  Click the **Sell Subscriptions** tab on the left sidebar.   Do one of the following:

1. Click **Create Plan** to create a new plan.
2. Click the toggle next to the relevant existing plan to enable it.

> **Tip:**
>
> Click [here](https://support.wix.com/en/article/wix-blog-creating-blog-post-subscriptions) to learn more about creating blog post subscriptions.

### Translating your blog post

Use this tab to manage your translations.

#### To translate your blog post:

Go to the [Blog](https://www.wix.com/my-account/site-selector/?buttonText=Manage%20My%20Blog&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https://www.wix.com/dashboard/\{\{metaSiteId\}\}/blog) tab in your site's dashboard.  Click **Manage My Blog**.  Click **Create New Post** or **Edit** to edit an existing post.  Create or edit the post to include the relevant information.  Click the **Translate** tab on the left sidebar.  Add [Wix Multilingual](https://support.wix.com/en/article/wix-multilingual-translating-your-blog) to your site and start translating your categories and posts.
