---
title: "Wix Apps: Creating Folders in the File Share App"
---

With the File Share app, you can create a file sharing library where people can exchange ideas and collaborate on projects.

You can create folders on your live site or from your site's dashboard to organize your file sharing library. Folders make it easier for your site visitors to find the content they're looking for.

**In this article, learn more about:**

[Creating folders from your dashboard](https://support.wix.com/en/article/wix-apps-creating-folders-in-the-file-share-app#creating-folders-from-your-sites-dashboard)  [Creating folders on your live site](https://support.wix.com/en/article/wix-apps-creating-folders-in-the-file-share-app#creating-folders-on-your-live-site)  [Frequently asked questions (FAQs)](https://support.wix.com/en/article/wix-apps-creating-folders-in-the-file-share-app#faqs)

---

### Creating folders from your site's dashboard

[Go to File Share](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Fdashboard%2F%7BmetaSiteId%7D%2Fapp%2F1537b24e-29d1-6d8f-b8e1-d6860f2f70b9%3F&primaryButtonText=Manage+Files) in your site's dashboard.  (Optional) Navigate to the place that you want the new folder to be. For example, to create a subfolder inside the "Spanish" folder, click the "Spanish" folder.  Click **+ Add New **at the top right.

Select **Folder**.   Enter a name for the new folder in the **What's the folder name **field.  Click **Save**.

---

### Creating folders on your live site

Go to the File Share app on your live site.  Log in using the email address associated with your Wix account.  If necessary, navigate to where you want the new folder to be. For example, to create a subfolder inside the "Spanish" folder, click the "Spanish" folder.  Click **New Folder**.

Enter a name for the new folder.  Press Enter on your keyboard.

### FAQs

Click a question below to learn more about creating folders in the Wix File Share app.

### Can I create subfolders within a folder?

Yes. You can create subfolders within any existing folder. While in a folder, click **+ Add New**, name your folder, and then drag and drop files into the new folder.

### How do I rename a folder?

You can rename a folder in your File Share app directly from your dashboard. 
1. [Go to File Share](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Fdashboard%2F%7BmetaSiteId%7D%2Fapp%2F1537b24e-29d1-6d8f-b8e1-d6860f2f70b9%3F&primaryButtonText=Manage+Files) in your site's dashboard.
2. Click the **More Actions** icon  next to the relevant folder and select **Rename**.
3. Enter the name of the folder.
4. Click **Save**.

### Can I delete a folder?

Yes. You can delete a folder in your File Share app directly from your dashboard. Deleting a folder deletes all files and subfolders within it.
1. [Go to File Share](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Fdashboard%2F%7BmetaSiteId%7D%2Fapp%2F1537b24e-29d1-6d8f-b8e1-d6860f2f70b9%3F&primaryButtonText=Manage+Files) in your site's dashboard.
2. Click the **More Actions** icon  next to the relevant folder and select **Delete**.
3. Click** Delete**.
