---
title: "Wix Forum: Changing the Layout"
---

Choose the layout that best showcases your forum's content. You can select a separate layout for the main forum page and the posts page.

There are two layouts to consider — the main page layout and the post page layout.

### To customize your forum layout:

Click the Wix Forum app in your editor.  Click **Settings**.  Click the **Layout **tab.  Choose what you would like to edit:

### Main page layout

1. Customize the main page layout settings:

- Choose a Main Page layout (option available if you display categories on your forum):

- **Classic: **An organized, classic layout, better for forums with lots of text.
- **Cards:** A beautiful masonry layout to showcase posts.
- **Show subcategories**: Click the **Show subcategories** toggle to enable or disable subcategories

- **Enabled**: Any subcategories you've created will be shown on your main forum page.
- **Disabled**: Any subcategories you've created will be hidden from your main forum page.
- **Show header**: Click the **Show header** toggle to enable or disable it:

- **Enabled:** A header is displayed on the main forum page.
- **Disabled: **No header is displayed on the main forum page.
- **Header height**: Drag the slider to change the size of the header.
- **Header text alignment**: Choose to have your header aligned to the left or to the right:

- **Left: **Displays header text aligned to the left.
- **Centered: **Displays header text centered.

### Post Page Layout

1. Click the **Post Page** tab to customize the post page layout:

- Choose a Posts Page layout:

- **Classic: **An organized, classic layout, better for forums with lots of text.
- **Cards:** A beautiful masonry layout to showcase posts. If you selected the Cards layout, click to select a card size.
- **Show header**: Click the **Show header** toggle to enable or disable it:

- **Enabled:** A header is displayed on category pages.
- **Disabled: **No header is displayed on category pages.
- **Header height**: Drag the slider to change the size of the header.
- **Header text alignment**: Choose to have your header aligned to the left or to the right:

- **Left: **Displays header text aligned to the left.
- **Centered: **Displays header text centered.
