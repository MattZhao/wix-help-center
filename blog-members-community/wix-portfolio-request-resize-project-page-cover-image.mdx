---
title: "Wix Portfolio Request: Resize Project Page Cover Image"
---

Currently, it is not possible to resize the project cover image. The layout that you select for your project page automatically affects the cover image ratio, proportion and size.

As a workaround, you can manually [change your project page layout](https://support.wix.com/en/article/wix-portfolio-customizing-your-wix-portfolio#customizing-the-project-pages) to a different option.

We are always working to update and improve our products, and your feedback is greatly appreciated.
