---
title: "Wix Groups: Using the Wix Groups Feed API"
---

The [Wix Groups Feed API](https://www.npmjs.com/package/@wix/wix-groups-feed-client) simplifies post management, offering tools for content curation. Additionally, the API handles group creation requests and aids in building feeds with website updates.

**The Groups Feed API enables you to:**

Create, update, and delete posts, allowing easy sharing of group-related news and updates.  Read and sort posts by group ID for streamlined content organization, enhancing navigation for group members.  Build a group feed with any news or updates related to your groups' content.  Utilize code to perform various post-related actions within the group feed, offering flexibility and customization options.

> **Additional info:**
>
> - Enable access to Wix Groups solutions and site data using the Wix REST API: [https://dev.wix.com/docs/rest](https://dev.wix.com/docs/rest)
> - [Create Requests API](https://dev.wix.com/docs/velo/api-reference/wix-groups-v2/create-requests/introduction) provides functionality for managing requests to create a group.
