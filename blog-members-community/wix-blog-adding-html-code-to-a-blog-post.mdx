title: "Wix Blog: Adding HTML Code to a Blog Post"
---

Use HTML to embed an iframe (external code or components) in a blog post or display an external site.

> **Important:**
>
> Make sure to read through the [limitations](https://support.wix.com/en/article/wix-editor-embedding-a-site-or-a-widget) of the HTML element before using it.

### To add HTML code to a blog post:

Go to [Blog](https://www.wix.com/my-account/site-selector/?buttonText=Manage%20My%20Blog&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https://www.wix.com/dashboard/%7B%7BmetaSiteId%7D%7D/blog) in your site's dashboard.  ﻿Click **Edit** on the relevant blog post, or **Create New Post** to write a new one.  Click **Add**  on the left side.  Click **HTML code.**  Do one of the following:

- **Add HTML code: **Adds features from external sites using HTML code.

1. Click **HTML Code**.
2. Enter your HTML code.
3. Click **Save**.
- **Embed an external site: **Displays an external site in a window in your post.

1. Click **Website Address (URL)**.
2. Enter a URL.
3. Click **Save**.
    (Optional) Customize the element using the options; width, height and alignment.
