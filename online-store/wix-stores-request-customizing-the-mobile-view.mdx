---
title: "Wix Stores Request: Customizing the Mobile View"
---

We're excited to announce that it's now possible to customize the mobile view of almost all Wix Stores elements.

**Studio editor: **If you are using the [Studio Editor](https://support.wix.com/en/article/wix-studio-about-the-studio-editor), most settings can now be customized for all breakpoints.  **Wix editor: **If you're using the [Wix Editor](https://support.wix.com/en/article/wix-editor-getting-started-with-the-wix-editor), many settings are customizable in the mobile view. To vote for customizations in the Product Page, click [here](https://support.wix.com/en/article/wix-stores-request-customizing-product-page-in-mobile-view).
