---
title: "Wix Stores Request: Adding a 'Request Quote' Button"
---

Currently, it is not possible to add a Request Quote button in Wix Stores.

> **Workarounds:**
>
> - You can add a "Request Quote" button to your site using [Wix Forms](https://support.wix.com/en/article/wix-forms-an-overview). You can also use any form or quote apps available in the Wix App Market.
> - [Wix Studio](https://support.wix.com/en/article/about-wix-studio) users can add a "Request Quote" button using Velo following [these instructions](https://dev.wix.com/docs/develop-websites/articles/wix-apps/wix-e-commerce-stores/tutorial-request-a-quote).

We are always working to update and improve our products, and your feedback is greatly appreciated.
