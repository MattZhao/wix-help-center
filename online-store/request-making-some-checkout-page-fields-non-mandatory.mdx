---
title: "Request: Making Some Checkout Page Fields Non-Mandatory"
---

> **Important:**
>
> This feature request is relevant for Wix Stores, Wix Bookings, and Wix Restaurants Orders (New).

Currently, customers must fill out the following fields to complete checkout:

Email  First Name  Last Name  Street Name  House Number  City  Country  Zip/Postal Code  Phone number (required by some payment providers)

It is not possible to make any of these fields optional.

We are always working to update and improve our products, and your feedback is greatly appreciated.
