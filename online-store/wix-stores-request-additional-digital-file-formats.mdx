title: "Wix Stores Request: Additional Digital File Formats"
---

Currently, it is possible to sell digital products in the following formats:

Digital File TypeSupported FormatsMaximum File Size**Image**.jpg, .png, .gif50MB**Audio**WAV, FLAC, M4A (Apple lossless, MP3)100MB**Document**.doc, .docx, .xls, .xlsx, .ppt, .pptx, .odt, .odp, .pdf, .epub40MB**Zip**.zip1 GB

It is not possible to sell digital files in other formats.

We are always working to update and improve our products, and your feedback is greatly appreciated.
