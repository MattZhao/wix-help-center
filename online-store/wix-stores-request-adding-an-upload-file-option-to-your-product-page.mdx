---
title: "Wix Stores Request: Adding an \"Upload File\" Option to Your Product Page"
---

Currently, it is not possible to add an Upload File option to your Product Page which would allow customers to provide more details (e.g. images) about the product they want to purchase.

> **Workarounds:**
>
> - You can add an upload file button to the Product Page using the following apps:
>
> - [Uploadly third-party app](https://www.wix.com/app-market/uploadly-file-upload)
> - [FUP: File Upload for Products](https://www.wix.com/app-market/fup-file-upload-for-products?searchLocation=home)
> - You can [add a customer message box](https://support.wix.com/en/article/wix-stores-allowing-customers-to-add-a-message-when-purchasing-a-product) to your Product Page so customers can provide more information.

We are always working to update and improve our products, and your feedback is hugely appreciated.
