---
title: "Wix Stores: Linking a Button to a Specific Product Page"
---

Make it easy for customers to access a product you're showcasing by adding a button that links directly to the relevant product page.

For example, if you add a site page about a great jacket you sell, you can add one or more buttons linking to that product.

#### To add a button that links to a specific product:

Wix EditorStudio Editor
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Go to the page where you want to add the button.
3. Click **Add Elements **on the left side of the editor.
4. Click **Button** and drag a button onto the page.
5. Click the button and select the Link  icon.
[image: Screenshot of a added button in the editor with the link icon indicated]
1. Link the button to a specific product:

1. Select **Page** on the left.
2. Select **Product Page** from the **Which page?** drop-down.
[image: Screenshot of the link setup page]
1. Select the product you want to link to from the **Which item? **drop-down.
