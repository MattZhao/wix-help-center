### Retrieving your Access key ID and Secret key

The Access key ID and Secret key, enable you to integrate Amazon's Product Advertising API (images and product listings) in your site. Without these keys, you cannot use Amazon's product images and content on your site.

> **Important:**
>
> Due to recent changes to Amazon policy, new Amazon affiliates need to [make 3 affiliate sales](https://support.wix.com/en/article/making-your-first-sales-as-an-amazon-affiliate) **before **the Access Key ID and Secret Access Key become active.

#### To retrieve your Access key and Secret key:

Sign in to your [Amazon Associate Account](https://affiliate-program.amazon.com/).   Click the **Tools** menu at the top of the page.  Click **Product Advertising API**.  Do one of the following:

- Click **Join** and copy the **Access Key ID **and **Secret Key**.
- Click **Add Credentials **and copy the **Access Key ID **and **Secret Key**.

**Note: **Make sure you save a record of your **Secret Key **and **Access Key**.
    Try to connect your Amazon Affiliate account, using the [instructions in step 2](https://support.wix.com/en/article/adding-and-setting-up-the-amazon-app).

**Note: **You can create a maximum of two keys at a time. If you have already created two keys, delete one before creating a new one.

### My access key was created with Amazon Web Services (AWS), what should I do?

In the past, the Access Key ID and Secret Key were linked to your Amazon Web Services (AWS) account. Amazon has now merged the Product Advertising API with Associates registration. Affiliates whose access keys were created in AWS [can migrate them to the Products Advertising API](https://affiliate-program.amazon.co.uk/help/topic/api/registration/ref=amb_link_196910_1).

### My emails for my Associates account and Web Services account are different, how do I log in?

You must log in to your Amazon Associates account and the Amazon Web Services account using the same email address and country. If the email is different, [you can add yourself as a new user (secondary user) with the a different email address](https://affiliate-program.amazon.com/help/node/topic/GYE3WNKLBUR3GFZQ). While adding the secondary user, make sure to select the same country used in your AWS account.

### Is the app available worldwide?

No. The Amazon app is not currently available for users in India and China.
