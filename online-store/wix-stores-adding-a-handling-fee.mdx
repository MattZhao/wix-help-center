---
title: "Wix Stores: Adding a Handling Fee"
---

> **Important:**
>
> We're in the process of rolling out new shipping settings. If you have a **Create Region** button instead of **Add Region**, then you have the new version. Learn how to [set up shipping using the new settings](https://support.wix.com/en/article/setting-up-store-shipping).

You can add a handling fee (in addition to a shipping fee) to orders placed through your store.

> **Note:**
>
> You cannot add a handling fee to the following shipping rules:
> - [Free Shipping](https://support.wix.com/en/article/wix-stores-setting-up-free-shipping)
> - [Calculate with USPS](https://support.wix.com/en/article/wix-stores-setting-up-real-time-shipping-calculation-with-usps)
> - [Allow Store Pickup Only](https://support.wix.com/en/article/wix-stores-setting-up-store-pickup-as-a-delivery-option)

### To add a handling fee:

Go to the [Shipping & fulfillment](https://www.wix.com/my-account/site-selector/?buttonText=Manage%20Shipping&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https://www.wix.com/dashboard/\{\{metaSiteId\}\}/store/shipping-and-tax/list?referralInfo=sidebar) settings in your site's dashboard.  Edit an existing rule or click **Add Region** to create a new one.  Set up a shipping rule for the region.  Select the **Add a handling fee to every order** checkbox.

  Enter the handling fee.
