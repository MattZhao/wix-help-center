---
title: "Wix Stores: Limiting Coupon Usage"
---

Coupons are a great way to attract visitors to your store and encourage them to make a purchase.

### To limit coupon usage:

[Go to Coupons](https://www.wix.com/my-account/site-selector/?buttonText=Manage%20Coupons&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https://www.wix.com/dashboard/\{\{metaSiteId\}\}/coupons/) in your site's dashboard.  Click **+New Coupon**.  Select a coupon type.  Enter the coupon code in the **Coupon Code** field.

**Note: **This is the code customers enter to get the discount.  Enter the name of the coupon in the **Coupon** **Name** field.

**Note: **This name appears in your dashboard and on the Cart page.  Enter the required details in the **Discount / Now only / Offer** field.

**Tip: **This step varies according to the coupon type you selected.  Choose what you want to do next:

### Limit which products the discount applies to

The **Apply to **drop-down is where you select the products a coupon applies. The options vary by coupon type.

**"Apply to" options: ** 
- **All products: **This coupon can apply to multiple products in a customer's cart.
- **Specific product: **You select a specific product.
- **Specific category:** You select the category the coupon applies to. Note that this coupon can apply to multiple products in a customer's cart.
- **Minimum order subtotal** Enter the minimum about above which the coupon applies (e.g. Coupon good on purchases above $50).
- **All orders: **Available for the Free Shipping coupon.
**

**
**Tip: **If you want to apply a coupon to a group of products, you can create a hidden category that contains all those products. Then, you can apply the coupon to that category.

### Limit the dates your coupon is valid

You can create a coupon with a time limit (e.g. Offer good in July only) or create one that can be used at any time.

To allow the coupon to be used at any time, enter a start date and select the **Don't set an end date** checkbox. To limit use, enter a start date and an end date. **Note: **The time of day a coupon expires depends on the time of day it was created. For example, if you created the coupon at 7:40 PM, and it is set to expire July 31, it will expire on July 31 at 7:40 PM (your time zone).

### Limit how many times the coupon can be used

You can limit the number of times a coupon can be used (e.g. offer available for the first 50 customers) and prevent customers from using a coupon more than once.

To limit the number of times a coupon can be used, select the **Limit the total number of uses for this coupon **checkbox and enter the number of times.

**Note: **Multiple purchase by the same customer or purchases by different customers are both counted. 

To let customers use a coupon only once, select the **Limit to one use per customer **checkbox.

### Limit a $ or % discount to 1 item per order

You can select **Apply once per order **to limit the use of $ Discount or % Discount coupons to one item in a particular order. This means that if you have a $20 off hats coupon, and a customer buys two hats, the discount only applies to one of them (the hat with the lowest price).

> **Tips:**
>
> - Coupon codes are not case sensitive.
> - You can use the free [Bulk Coupon Creator app](https://support.wix.com/en/article/adding-and-setting-up-the-bulk-coupon-creator-app) to generate bulk codes.
> - Check out the full course in Wix Learn on driving traffic to your store, or skip to the video on [creating and sending coupons](https://www.wix.com/learn/online-course/ecommerce/drive-traffic-to-your-online-store#create-and-send-coupons).
