---
title: "Wix Stores Request: Purchasing Shipping Labels Using the Wix App"
---

Currently, it is not possible to buy and print shipping labels using the Wix app. Wix shipping labels can only be [purchased on desktop](https://support.wix.com/en/article/wix-stores-about-shipping-labels).

We are always working to update and improve our products, and your feedback is greatly appreciated.
