---
title: "Wix Stores Request: Embedding External HTML Code to a Product Page"
---

Currently, it's not possible to add HTML code from external sources to individual Wix Stores Product Pages.

As a workaround, you can use the HTML element to embed code onto your product page. Click [here ](https://support.wix.com/en/article/wix-editor-embedding-a-site-or-a-widget)to learn more.

> **Note:**
>
> It is not possible to add different HTML codes to individual products. The Product Page is a dynamic page, therefore any changes made to one Product Page affect all Product Pages.

We are always working to update and improve our products, and your feedback is greatly appreciated.
