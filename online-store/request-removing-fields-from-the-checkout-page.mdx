---
title: "Request: Removing Fields from the Checkout Page"
---

> **Important:**
>
> This feature request is relevant for Wix Stores, Wix Bookings, and Wix Restaurants Orders (New).

Currently, customers checking out must fill out the following fields:

Email  First Name  Last Name  Street Name  House Number  City  Country  Zip/Postal Code

It is not possible to remove any of these fields from your Checkout Page.

We are always working to update and improve our products, and your feedback is greatly appreciated.
