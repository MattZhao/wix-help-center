---
title: "Wix Forms Request: Changing Text Size or Scaling per Breakpoint"
---

> **Important**
>
> This feature request is only relevant for forms in the Studio Editor.

Currently in the [new Wix Forms,](https://support.wix.com/en/article/studio-editor-adding-and-customizing-a-form) it's not possible to control text size per breakpoint using percentages (%), or set it to scale proportionally. You can still change text sizing using pixels (px) for each of the individual form widgets.

We are always working to update and improve our products, and your feedback is greatly appreciated.
