---
title: "Request: Adding Form Submission Time to Wix Automations"
---

We are excited to announce it is now possible to use the form submission time in Wix Forms automations.

For example, when setting a Wix Forms trigger, you can now select "Form submission time" from the "Data from trigger" drop-down and match it to a field in a Google sheet, like the screenshot below. Learn more about [creating an automation](https://support.wix.com/en/article/wix-automations-creating-a-new-automation).
