---
title: "Request: Setting an Automation Action to Send Push Notification"
---

We are excited to announce that you can now set up an automation that [sends a push notification](https://support.wix.com/en/article/wix-automations-creating-a-new-automation#step-3-choose-an-action). This notification appears on a customer's device screen ("pushed" by their mobile app).

> **Notes:**
>
> - This action is only available with a [Branded App Premium plan](https://support.wix.com/en/article/branded-app-purchasing-a-branded-app-plan) and when your app is live in stores.
> - We are currently in the process of releasing this feature, so it's not available for all triggers yet. If you select a trigger and see the **Send a push notification** action, it's available for that trigger.
