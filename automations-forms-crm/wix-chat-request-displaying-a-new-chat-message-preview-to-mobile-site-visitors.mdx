---
title: "Wix Chat Request: Displaying a New Chat Message Preview to Mobile Site Visitors"
---

Currently, visitors to the mobile version of your site cannot see a preview of a new chat message. Instead they see a red dot notification indicating a new message. The message preview is only available on sites built using [Editor X](https://support.wix.com/en/article/introducing-editor-x).

We are always working to update and improve our products, and your feedback is greatly appreciated.
