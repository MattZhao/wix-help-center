---
title: "Request: Using Zapier as an Automation Trigger"
---

Currently, it is not possible to use Zapier as an automation trigger. It is only possible to [use Zapier as an automation action](https://support.wix.com/en/article/wix-automations-connecting-your-automations-with-a-third-party-app-using-zapier).

We are always working to update and improve our products, and your feedback is greatly appreciated.
