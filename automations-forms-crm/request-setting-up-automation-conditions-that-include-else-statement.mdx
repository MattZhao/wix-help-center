---
title: "Request: Setting Up Automation Conditions That Include “Else” Statement"
---

Currently, it is not possible to set up an automation condition that includes an "else" statement. You can [add a condition to an automation](https://support.wix.com/en/article/wix-automations-creating-a-new-automation#step-4-optional-add-a-condition), but if this condition isn't met, the automatic "else" outcome is exiting the automation's flow.

We are always working to update and improve our products, and your feedback is greatly appreciated.
