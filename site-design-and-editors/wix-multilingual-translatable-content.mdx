---
title: "Wix Multilingual: Translatable Content"
---

Wix makes it easy to build a multilingual site without needing a developer. Wix Multilingual lets you translate many features and apps, but some elements currently can't be translated.

**In this article, learn more about:**

[Features](https://support.wix.com/en/article/wix-multilingual-translatable-content#features)  [Apps](https://support.wix.com/en/article/wix-multilingual-translatable-content#apps)

---

### Features

Use Wix Multilingual to translate various features and site elements. Click below to learn about the features you can translate and those you cannot.

### Translatable

- [Wix Automation emails](https://support.wix.com/en/article/wix-automations-translating-automated-emails-with-wix-multilingual)
- [Lightboxes](https://support.wix.com/en/article/wix-editor-adding-and-setting-up-a-lightbox)
- [Single video player](https://support.wix.com/en/article/single-video-player-adding-and-setting-up-the-single-video-player)
- [Menu](https://support.wix.com/en/article/wix-multilingual-customizing-your-site-menu-per-language)
- [Text](https://support.wix.com/en/article/wix-multilingual-translating-text-buttons-and-links) (in text boxes, on buttons, in lists and grids, links, etc.)
- [Images and backgrounds](https://support.wix.com/en/article/wix-multilingual-editing-images-and-backgrounds-per-language)
- [SEO settings](https://support.wix.com/en/article/wix-multilingual-optimizing-seo-settings-for-multilingual-sites)

**Note: **[Subdomains](https://support.wix.com/en/article/wix-multilingual-about-multilingual-subdomains) are automatically generated for your secondary languages.

### Untranslatable

- [Wix Email Marketing Campaigns](https://support.wix.com/en/article/wix-multilingual-request-translating-wix-email-marketing-campaigns)
- [Wix Invoices](https://support.wix.com/en/article/wix-multilingual-request-translating-wix-invoices)
- [Google Maps](https://support.wix.com/en/article/wix-multilingual-request-translating-google-maps)

### Apps

Wix offers many apps, but not all support translation with Wix Multilingual. Click below for more info on the Wix apps you can translate and those you cannot.

### Translatable

- [Wix Bookings](https://support.wix.com/en/article/wix-bookings-translating-your-site)
- [Wix Restaurant Menus](https://support.wix.com/en/article/wix-multilingual-translating-your-restaurant-menu)
- [Restaurant Reservations](https://support.wix.com/en/article/wix-restaurants-translating-your-restaurant-reservations)
- [Members Area](https://support.wix.com/en/article/wix-multilingual-request-translating-the-members-area-in-multilingual-sites)
- [Pro Gallery](https://support.wix.com/en/article/wix-multilingual-translating-your-pro-gallery)
- [Wix Chat](https://support.wix.com/en/article/wix-chat-translating-wix-chat)
- [Wix FAQ app](https://support.wix.com/en/article/wix-multilingual-translating-your-faq)
- [Online Programs](https://support.wix.com/en/article/wix-online-programs-translating-your-online-programs)
- [Cookie Banner](https://support.wix.com/en/article/translating-your-cookie-banner-using-wix-multilingual)
- [Wix Blog](https://support.wix.com/en/article/wix-multilingual-translating-your-blog)

**Note:** Blog content is translated through the Blog Manager.
- [Wix Forms](https://support.wix.com/en/article/wix-forms-translating-your-forms-with-wix-multilingual)

**Note:** You can translate forms within the Wix Editor. With the Studio Editor, go to the dashboard to translate forms.
- [Wix Stores](https://support.wix.com/en/article/wix-stores-translating-your-store)

**Note: **Some automatically generated storefront text does not appear in every language.
- [Wix Events](https://support.wix.com/en/article/wix-events-translating-your-event)

**Note: **Some text elements in the app need to be translated manually through your editor. [Event Schedules are currently non-translatable](https://support.wix.com/en/article/wix-multilingual-request-translating-your-events-schedule-in-wix-events)
- **Accepting Payments:** Currently, you can only translate payment instructions for Manual Payments.
- [Wix CMS (Content Management System)](https://support.wix.com/en/article/wix-multilingual-translating-cms-collection-content)
- [Automatic Discounts](https://support.wix.com/en/article/wix-stores-translating-your-store#faqs)
