---
title: "Wix Logo Request: Automatically Creating a Branded Logo Based on Existing Site Design"
---

Currently, it is only possible to create a branded website from an existing logo design. It is not possible to automatically create a branded logo from an existing website.

If you'd like a matching logo design, you can manually create your logo in the [Logo Maker](https://www.wix.com/logo/maker/esh) using the same fonts and colors used in your site editor.

We are always working to update and improve our products, and your feedback is hugely appreciated.
