title: "Adding Additional Meta Tags to Your Site's Pages"
---

Meta tags are pieces of HTML code that contain page information that web browsers and search engines can read. Wix adds some standard meta tags, like your site's name, to your site by default.

You can also add additional meta tags to your site to give search engines extra information about your pages. For example, Google can [use additional meta tags](https://developers.google.com/search/docs/appearance/title-link) to create rich results for your site in search results.

**In this article, learn how to:**

### Adding an additional meta tag

Add additional meta tags in your editor to improve your site's search engine optimization.

Wix EditorEditor XStudio Editor
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).

3. Click the **More Actions** icon  next to the relevant page.

### FAQs

Click a question below to learn more about additional meta tags:

### How many additional meta tags can I add to my site?

You can add up to 10 tags, but you can't add a meta tag that Wix already [created for you](https://support.wix.com/en/article/understanding-your-pages-default-seo-settings).

### What tag types can I add?

You can only use the following tag types:
- \<meta>
- \<link>
If you want to add an additional tag that is not supported, you can use the [Custom Code section](https://support.wix.com/en/article/embedding-custom-code-on-your-site).

### Why can't I see an option to delete certain meta tags?

It's not possible to delete the default meta tags that Wix adds to your site. You can only delete additional meta tags.
