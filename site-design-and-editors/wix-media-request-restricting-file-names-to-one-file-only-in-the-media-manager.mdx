---
title: "Wix Media Request: Restricting File Names to One File Only in the Media Manager"
---

Currently, it is not possible to automatically restrict file names to one file only. This means you can have multiple files in the Media Manager with the same title.

We are always working to update and improve our products, and your feedback is hugely appreciated.
