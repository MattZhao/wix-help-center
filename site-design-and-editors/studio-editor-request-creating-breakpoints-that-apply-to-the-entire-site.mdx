---
title: "Studio Editor Request: Creating Breakpoints that Apply to the Entire Site"
---

In the Studio Editor, you can apply breakpoints to a global section or a page, so their design is responsive to different screen sizes. Currently, it is not possible to create breakpoints that apply to the entire site by default. You need to set those for every section or page you're working on.

We are always working to update and improve our products, and your feedback is greatly appreciated.
