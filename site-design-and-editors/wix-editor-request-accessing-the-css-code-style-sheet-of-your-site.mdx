---
title: "Wix Editor Request: Accessing the CSS Code (Style Sheet) of Your Site"
---

Currently, it is not possible to access the CSS code of your site.

Many CSS changes can be made by updating your content in the Editor. The changes take effect when you click **Publish**.

> **Tip:**
>
> [CSS editing](https://support.wix.com/en/article/studio-editor-about-css-editing) is one of many advanced features that are available in the [Studio Editor](https://support.wix.com/en/article/wix-studio-about-the-studio-editor).

We are always working to update and improve our products, and your feedback is hugely appreciated.
