---
title: "Wix Multilingual Request: Using Multiple Dialects of the Same Language"
---

Currently, Wix Multilingual allows you to choose only one dialect per language. Supporting dialects would allow you to create separate language versions of your site.

Wix Multilingual does not support other dialects beyond Chinese. To use the Chinese dialect, you can select either Traditional or Simplified Chinese. If you need Traditional Chinese, choose the flag for Macao, Taiwan, or Hong Kong.

For example, a business targeting both mainland China and Taiwan could show content in both Simplified and Traditional Chinese. That way, it can cater to the preferences of each audience which improves site visitors' experience.

> **Workaround:**
>
> As a workaround, you can create separate sites for each dialect.

We are always working to update and improve our products, and your feedback is greatly appreciated.
