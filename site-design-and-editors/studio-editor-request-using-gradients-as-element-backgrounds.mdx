---
title: "Studio Editor Request: Using Gradients as Element Backgrounds"
---

When designing elements like text boxes and shapes, you can set a fill color as the background. Currently, it is not possible to apply a gradient background to Studio Editor elements.

> **Update:**
>
> We are pleased to announce that you can now [set gradients as the background for responsive containers](https://support.wix.com/en/article/studio-editor-using-containers#designing-containers).

We are always working to update and improve our products, and your feedback is hugely appreciated.
