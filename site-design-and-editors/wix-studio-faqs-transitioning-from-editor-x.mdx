---
title: "Wix Studio FAQs: Transitioning from Editor X"
---

Currently, Editor X is transitioning to [Wix Studio](https://www.wix.com/studio), our new platform for agencies and enterprises. We're gradually releasing an update that lets you seamlessly [move Editor X sites to Studio](https://support.wix.com/en/article/updating-an-editor-x-site-to-the-studio-editor) in just a few clicks.

Eventually, all Editor X sites will be updated to Studio. Starting April 2024, it is no longer possible to create new sites on Editor X.

> **Important:**
>
> We've closed the sign-up for Editor X. If you have existing Editor X sites, you can keep working on them for now – but we highly recommend starting any new projects on Wix Studio.

### FAQs

### Can I still log in to my Editor X account?

Absolutely, you can still log in to your account through the Editor X home page. [Log in to your account](https://www.editorx.com/).

### Can I still create new sites on Editor X?

No, it is no longer possible to create new Editor X sites. Having said that, you can still access sites that are currently on Editor X. We highly recommend using Wix Studio for any new projects you get.

### What will happen to my Editor X sites?

We've started rolling out the option to [update Editor X sites to Wix Studio](https://support.wix.com/en/article/updating-an-editor-x-site-to-the-studio-editor). This process is done gradually, to ensure a seamless transition for your sites.
When an Editor X site is ready to be updated, a clickable banner appears at the top of the editor. 
Eventually, all Editor X sites will be updated to Studio.

### What will eventually happen to Editor X?

We plan to fully transition Editor X to Wix Studio in the coming months. Eventually, all Editor X sites will be updated to Wix Studio. 
Don’t worry—you’ll get plenty of notice before this happens.

### Can I update Wix Editor sites to Studio?

We know a lot of you have asked for an option to update Wix Editor sites to Wix Studio, but it’s currently not in our plans for 2024.

> **Switch to Wix Studio:**
>
> If you haven’t stepped into the Studio yet, now’s a great time to [make the switch](https://manage.wix.com/account/about-wix-studio). Packed with powerful design features on top of all the capabilities you already know, plus a brand new collaborative workspace, [Wix Studio](https://www.wix.com/studio) allows you to deliver exceptional work at scale.
