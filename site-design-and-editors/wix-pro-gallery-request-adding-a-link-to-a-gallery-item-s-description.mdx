---
title: "Wix Pro Gallery Request: Adding a Link to a Gallery Item's Description"
---

Currently, it is not possible to hyperlink the text of a gallery item's description.

It is possible however, to add a link to a gallery item itself. [Learn how to add links to gallery items](https://support.wix.com/en/article/wix-pro-gallery-adding-a-link-to-a-gallery-item).

We are always working to update and improve our products, and your feedback is hugely appreciated.
