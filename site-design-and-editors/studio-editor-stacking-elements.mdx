---

A stack is a flexbox container that "hugs" a group of elements – whether they are in a vertical or horizontal order. It ensures the elements stay in order, with the spacing you define, and never overlap.

Having said that, you can use negative margins to make elements overlap intentionally.

### Applying a stack

Click an element that you want to be in the stack.  Hold down the **Shift** key and select the other stack elements.  Click **Stack**.  (Optional) Drag the line between the elements to set margins.

> **Tip:**
>
> You can also create negative margins to make elements overlap intentionally. [image: Dragging the stack margins to the opposite direction to create an overlap between the image and text]

---

### Changing the stack direction

When you stack elements, the direction is automatically determined by the order of the elements. If the elements are arranged vertically, for example, the stack will be vertical.

Either way, you can always switch the direction using the drop-down. This automatically rearranges the elements so they're in the right order.

### Managing a stack

You can customize the stack to match new content and requirements. Add more elements to the stack, move them around in a click of a button, and detach elements that are no longer needed.

#### To manage a stack:

Select the relevant stack.  Choose what to do next:

### Add an element to the stack

You can add any element to an existing stack by simply dragging it onto the stack. An **Attach to Stack **notification** **appears to let you know you are adding an element to the stack. 
[image: A GIF showing the notification that appears when dragging an element into the stack]
You can also select the stack, hold the **Shift** key on your keyboard while selecting the element you want to add. You can then choose to add it to the stack.

### Detach an element from the stack

To detach an element from a stack, just drag it anywhere outside of the stack.
You can also select the element and click the More Actions icon . Then, click **Detach from Stack**.[image: Detaching an element from a stack]

### Reorder elements in the stack

1. Select the relevant element in the stack.
2. Depending on the stack direction (vertical or horizontal), click the **Move Up**  / **Move Down**  , or the **Move Left** ** **/ **Move Right **** **icons.

[image: Moving a vector art element up and down in a stack]

### Unstack elements

Select the stack in the Editor, then click **Unstack**.

---

### Designing a stack

The stack does not have to be transparent – you can design it to make the content stand out on the page. Add a background color, border and shadow. You can also make the stack corners more round or square.

#### To design a stack:

Select the relevant stack.  Click the Open Inspector arrow  at the top right of the Editor.  Scroll down to **Design**.   Design the stack using the available options:

- Set the background color and its opacity.
- Add a border to frame the stack.
- Choose a radius for the corners.
- Enable shadow and manage settings like its angle, distance, size, etc.
