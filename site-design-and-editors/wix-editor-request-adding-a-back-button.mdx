---
title: "Wix Editor Request: Adding a Back Button"
---

Currently, it is not possible to add a "Back" button to your site. However, you can add a button, change the text, and link it to whatever page you'd like. [Learn how to add and set up a text button](https://support.wix.com/en/article/wix-editor-adding-and-setting-up-a-text-icon-button)

> **Note:**
>
> This request refers to adding a "Back" button to your Wix Editor site. If you would like to see a "Back" button added to product pages in Wix Stores, you can [vote for it here](https://support.wix.com/en/article/wix-stores-request-adding-a-back-button-to-your-product-page).

We are always working to update and improve our products, and your feedback is hugely appreciated.
