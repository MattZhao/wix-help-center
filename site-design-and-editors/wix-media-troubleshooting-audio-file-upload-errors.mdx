---
title: "Wix Media: Troubleshooting Audio File Upload Errors"
---

If you are having trouble uploading your audio files, make sure you're uploading the file in a [supported file format](https://support.wix.com/en/article/wix-media-supported-media-file-types-and-file-sizes).

If you get a specific error message when uploading your audio file, click the error message below to find out how to resolve it:

### This file is corrupted and could not be uploaded.

The file is corrupted and cannot be read by our system. Try to upload a different copy of the file or re-create it if possible.

### File extension doesn't match the file type.

Check the file properties to make sure the [file type is supported](https://support.wix.com/en/article/wix-media-supported-media-file-types-and-file-sizes).

### This file is empty. Upload a different file.

The file is empty. Please recreate the file and check that the content has been properly added.

### Audio File could not be uploaded due to unsupported stereo format.

Re-encode or convert audio file and make sure that the audio is either stereo or mono.

### Audio File could not be uploaded due to unsupported bit rate.

The sample size of your audio file is not supported. Please check that your bit rate is 16, 24 or 32 kbps. Re-encode or convert file with [supported bit rate](https://support.wix.com/en/article/wix-media-supported-media-file-types-and-file-sizes).

### Audio File could not be uploaded due to unsupported mono format.

Re-encode the audio file making sure that the audio is either stereo or mono.

### Audio File could not be uploaded due to unsupported MP3 format.

Re-encode the audio file or convert your audio using a different mp3 codec.

### Audio File could not be uploaded due to unsupported sample rate.

Check that your sample rate is 44,100, 48,000, 96,000, 88,200 or 192,000 hz. Re-encode or convert the file with [supported sample rate](https://support.wix.com/en/article/wix-media-supported-media-file-types-and-file-sizes).

### Audio File could not be uploaded due to unsupported sample size.

Check that your sample rate is 44,100, 48,000, 96,000, 88,200 or 192,000hz & that your bit rate is 16, 24 or 32 kbps. Re-encode or convert the file.

#### Still need help?

If the problem persists, [contact us](https://support.wix.com/en/article/contacting-wix-customer-care-for-support) and we will be happy to help.
