---
title: "Studio Editor Request: Using Variable Fonts in Your Site's Typography"
---

Currently, variable fonts are not supported in the Studio Editor.

A variable font is a single font file that includes a collection of master styles. It lets you display text in many different stylistic variations while saving on space and bandwidth.

> **Tip:**
>
> If you need to use multiple typefaces of the same font (e.g. Light, Bold, Semi-Bold), you can [upload them](https://support.wix.com/en/article/studio-editor-using-different-text-fonts) as individual font files.

We are always working to update and improve our products, and your feedback is greatly appreciated.
