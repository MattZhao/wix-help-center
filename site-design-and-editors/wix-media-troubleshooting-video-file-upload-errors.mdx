---
title: "Wix Media: Troubleshooting Video File Upload Errors"
---

If you are having trouble uploading your video files, make sure you're uploading the file in a [supported file format](https://support.wix.com/en/article/wix-video-supported-files).

If you get a specific error message when uploading your video file, click the error message below to find out how to resolve it:

### Unsupported MP4 format. Upload this video file in a different format.

The file format is not supported. Check the specs of your video, make sure that it is H.264 codec and re-encode or convert the file using the [supported specs](https://support.wix.com/en/article/wix-media-supported-media-file-types-and-file-sizes).

### Unsupported sample rate. Upload this video file in a different format.

Check that your sample rate is 44,100, 48,000, 96,000, 88,200 or 192,000 hz. If not, re-encode or convert the file with a supported [sample rate](https://support.wix.com/en/article/wix-media-supported-media-file-types-and-file-sizes).

### Video bit rate (\{bps\}) is too high.

Check the video bit rate (bps) and make sure that it's ~2600 kb\s.

### Video length (\{videoDuration\}) and audio length (\{audioDuration\}) don't match.

Check that the video and audio duration match. Converting the file to a different or the same format can help correct this.

### The \{codec\} video codec used to make this file isn't supported.

Make sure that your video is encoded with the H.264 codec and re-encode or convert file with our [supported specs](https://support.wix.com/en/article/wix-media-supported-media-file-types-and-file-sizes).

### Upload this file again in stereo format.

Make sure that the audio of your video is in stereo format and not mono format. If it is mono format, change it and re-upload the video.

#### Still need help?

If the problem persists, [contact us](https://support.wix.com/en/article/contacting-wix-customer-care-for-support) and we will be happy to help.
