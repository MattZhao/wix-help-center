---
title: "Wix Editor Request: Using PHP Programming Language"
---

Currently, Wix only supports adding HTML code, which can be added through the [HTML element](https://support.wix.com/en/article/wix-editor-embedding-a-site-or-a-widget). Velo by Wix, which uses [Javascript](https://support.wix.com/en/article/velo-javascript-support), also allows the use of [Java Script Libraries](https://support.wix.com/en/article/velo-working-with-the-html-iframe-element) when using the HTML element. It is not possible to add PHP code to your Wix site.

We are always working to update and improve our products, and your feedback is hugely appreciated.
