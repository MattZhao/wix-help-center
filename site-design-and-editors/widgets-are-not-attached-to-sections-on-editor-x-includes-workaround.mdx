---
title: "Widgets Are Not Attached to Sections on Editor X (Includes Workaround)"
---

Currently there is an issue that causes widgets for some applications to not be attached inside of a section.

> **Meanwhile, you can use the following workaround:**
>
> 1. Add a new blank section to the top of the page.
> 2. Arrange the affected widget to be on top of the page for every breakpoint (even above the header)
> 3. Set the Position type to "pinned" for the affected widget.
> 4. Set the Position type back to "default"
> 5. Adjust the Size, Docking, Margins for the widget on all breakpoints after is attached to a section.

The Widget must be at the top of page for every breakpoint or it will not be able to be pinned,  In the cases you have another component already pinned to the top of the page, it must be temporarily set back to default first.  When adding a new blank section, make sure it is placed at the top of the page (below the affected widget).

> **Important**
>
> If you are having any issues applying this workaround, please [contact our customer care team](https://support.wix.com/en/article/editor-x-contacting-customer-care-for-support) for assistance.
