---
title: "Studio Editor Request: Showing the Same Element on Multiple Pages"
---

While you can [set any section as global](https://support.wix.com/en/article/studio-editor-using-global-sections), it is not possible to set individual elements as global so they appear on multiple site pages.

Alternatively, you can [save elements as design assets](https://support.wix.com/en/article/studio-editor-saving-and-reusing-design-assets). Your design assets are always available from the Add Elements panel, to reuse on any page or Studio Editor site.

We are always working to update and improve our products, and your feedback is greatly appreciated.
