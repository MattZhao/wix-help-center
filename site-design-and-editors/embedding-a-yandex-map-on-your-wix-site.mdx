title: "Embedding a Yandex Map on Your Wix Site"
---

> **Important:**
>
> The Yandex Maps app has been retired from the Wix App Market. You can still add a Yandex map to your site by using the Yandex map constructor to build the map and pasting the code into your site.

Add a custom Yandex map to your site to let your customers know where they can find your business.

---

### Step 1 | Create a map using the Yandex Map constructor

The Yandex Map constructor lets you create your own map, where you can design routes and highlight locations. After creating the map, you'll be able to generate a code which you can embed on your site.

#### To create a map:

Log in to [Yandex](https://passport.yandex.com/auth?retpath=https%3A%2F%2Fmail.yandex.com).  Go to the [Yandex Maps constructor](https://yandex.com/map-constructor/?from=mapsapi).  Click **Create map**.  Customize your map title and description.  (Optional) Add objects to the map using the** Import **option.

Click **Save and continue**.  Select **Embed on site**.   Customize the size of your map.   Click **Get map code**.   Copy the code in the box.

---

### Step 2 | Embed the code on your site

After you've copied the code from the Yandex Map constructor, return to your site's editor to embed it.

#### To embed code on your site:

Wix EditorStudio Editor
1. Click **Add Elements ** on the left side of the Editor.
2. Click **Embed Code**.
3. Click **Embed HTML**.
4. Paste the code you copied from Yandex into the **Add your code here (HTTPS only)** field.
5. Click **Update**.
6. (Optional) Enter alt text that describes what you're embedding in the **What's in the embed? Tell Google **field.
7. When ready, publish your site.

1. Click **Add Elements**  on the left side of the editor.
2. Click **Embed & Social**.
3. Click **Embed Code**.
4. Click **Enter Code**.
5. Paste the code you copied from Yandex into the **Add your code here (HTTPS only)** field.
6. Click **Apply**.
7. (Optional) Enter alt text that describes what you're embedding in the **What's in the embed? Tell Google **field.
8. When ready, publish your site.
