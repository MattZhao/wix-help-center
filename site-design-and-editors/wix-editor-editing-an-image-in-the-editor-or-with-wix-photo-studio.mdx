---
title: "Wix Editor: Editing an Image in the Editor or with Wix Photo Studio"
---

You can edit any image you have uploaded in the editor by[ adding a frame](https://support.wix.com/en/article/wix-editor-editing-and-customizing-images#adding-and-customizing-image-frames), [cropping your image using shape crop](https://support.wix.com/en/article/wix-editor-cropping-an-image) and more. However, the edited version of an image is not saved in the Media Manager so that you can use the image again.

Instead, you can use the Wix Photo Studio in the Media Manager to create stunning images without leaving the editor. The Photo Studio allows you to edit images that you've uploaded to your site and save the edited version in your Media Manager. Add filters, rotate or crop an image and more with Wix Photo Studio.
