title: "Site Performance: Removing Unused JavaScript"
---

When you check your site on Google PageSpeed Insights, you may be prompted to remove unused JavaScript files. Some of these files may come from third-party code that you have added, whereas others are a vital part of your Wix site.

**In this article, learn more about:**

[JavaScript files on Wix sites](https://support.wix.com/en/article/site-performance-removing-unused-javascript#javascript-files-on-wix-sites)  [JavaScript files from third-party code](https://support.wix.com/en/article/site-performance-removing-unused-javascript#javascript-files-from-third-parties)

---

### JavaScript files on Wix sites

The PageSpeed Insights results page may display opportunities to remove files and unused JavaScript. However, some files are part of the structure of your Wix site. Any code delivered through [static.parastorage.com](http://static.parastorage.com/) is packaged by Wix, and therefore crucial to the site's structure.

We are consistently optimizing these files, and using methods such as code splitting to ensure ideal chunk sizes. While Google may advise you to remove these files, they are a vital part of the site and you therefore cannot modify, manipulate, or delete them. [Learn more about unused JavaScript and PageSpeed Insights](https://web.dev/unused-javascript/)

> **Note:**
>
> When you add apps and components to a page, JavaScript files are automatically added for them. As this can affect the loading speed, we recommend spacing apps and components between different site pages where possible. [Learn about other ways to create a performance-focused site](https://support.wix.com/en/article/site-performance-designing-a-performance-focused-website)

---

### JavaScript files from third-parties

As well as essential files from your Wix site, Google may also flag other unused JavaScript, which can come from third-party code that is not optimized. We recommend identifying these files, and reviewing them to check whether they are necessary to your site.

If you find that the files are no longer necessary, you can remove them, or replace them with an optimized alternative. [Learn more about removing unused JS files](https://web.dev/unused-javascript/)
