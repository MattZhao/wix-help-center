Currently, it is not possible to set a lightbox to only open once per site visitor.

> **Tip:**
>
> If you have a little coding experience, you can create a one-time popup using Velo by Wix. [View Tutorial](https://support.wix.com/en/article/velo-tutorial-creating-a-one-time-popup)
>
>
>
> You can also browse through the Wix Marketplace to find a designer to do this for you. [Find a Designer](https://www.wix.com/marketplace)

We are always working to update and improve our products, and your feedback is hugely appreciated.
