---
title: "Studio Editor Request: Password Protecting a Studio Editor Site"
---

You can add passwords to specific pages of a site you build in the Studio Editor. However, it is not currently possible to apply a single password to the entire site.

As an alternative, you can [manually add a password to each site page](https://support.wix.com/en/article/studio-editor-adding-and-managing-pages#changing-the-page-settings) from its settings.

We are always working to update and improve our products, and your feedback is hugely appreciated.
