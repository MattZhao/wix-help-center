### Site language and accessibility

Some site visitors use assistive technologies and settings (such as screen readers and live captions) while browsing the internet. Setting the site's main language provides these technologies with information they need to accurately render the content.

The language you set:

Indicates the script / characters used in text  Determines how text content should be read aloud (i.e., the pronunciation, accent, pitch, and speaking rate)  Tells the device / browser what language generated captions should be in

If the site language is incorrect, it can cause issues for visitors using these technologies (e.g., screen readers may use different accents, or pronounce things incorrectly). It is therefore important to set and manage a site languages to provide the most accurate experience for visitors.

### Checking and setting the language of a single-language site

If you have a single-language site, you can check the language from the site's dashboard and change it if needed.

#### To check / set the site's language:

Go to [Settings in the site's dashboard](https://www.wix.com/my-account/site-selector/?buttonText=Manage%20Settings&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https://www.wix.com/dashboard/\{\{metaSiteId\}\}/manage-website).  Select **Language & Region**.  Select the **Site language** drop-down menu and set the language of your site.

### Changing a site's language in the Accessibility Wizard

You may be prompted to change the language of a single-language site in the Accessibility Wizard. Use the steps to update the language in your site builder.

Wix EditorStudio Editor
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Click **Settings **at the top and select **Accessibility Wizard**.
3. (First time only) Click **Scan My Site **in the Accessibility Wizard panel on the right.
4. Select **Settings** at the top of the your Editor.
5. Click the **All pages** collapsible in Step 1.
6. Click the drop-down under **What is the main language of your site? **and select your site's language.
7. Click **Set Site Language**.
Note:The card only appears if your site's language does not match the language of the content itself (e.g. the site's language is set to English, but the site text is in Spanish).
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Click **Site Checker** ** **on the left side of your editor.
3. Select **Fix Accessibility Issues**.
4. Click **Scan Site**.
5. Select the **Detected issues** tab.
6. Open the **Site level** drop-down.
7. Click **Edit** beside **Main site language**.
8. Select the relevant language from the drop-down menu.
9. Click **Apply**.
Tip:Even if the Accessibility Wizard doesn't flag the site's language, you can still check and change it from the panel.

### Working with languages on a Multilingual site

[Multilingual sites](https://support.wix.com/en/article/wix-multilingual-an-overview) generally contain language menus that allow visitors to switch between languages. The flag icons in these menus are automatically assigned alt text that reflects the corresponding language.

As screen readers read both regular and [alt text](https://support.wix.com/en/article/accessibility-preparing-your-images-and-galleries), menus containing text and icons may cause the screen reader to repeat the language name. We therefore suggest setting the menu to show only the text or icon in your site's editor.

Wix EditorStudio Editor
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Select the language menu.
3. Click the **Layout** icon .
4. Choose what you want to display on the menu:

- **Flags:** 

1. Enable the **Show flags** toggle.
2. Select **Flags only** under **Display**.
- **Language name: **

1. Disable the **Show flags** toggle.
2. Choose either **Full name** or **Abbreviated** under **Display**.

### FAQs

### I manually added different languages to the site. What should I set as the main language?

If your site contains content in multiple languages and does **not** have Wix Multilingual, you should set the main language as the one you use most.
If the languages are in equal use across the site, we recommend selecting the language used when you initially created the site.

### Can I change the site's main language if I have Multilingual?

If you have added Wix Multilingual to your site, the main language chosen [during set-up](https://support.wix.com/en/article/wix-multilingual-adding-and-setting-up-wix-multilingual) cannot be changed. [Vote for this feature](https://support.wix.com/en/article/wix-multilingual-request-changing-your-sites-main-language)
