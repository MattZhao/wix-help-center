title: "Editor X: Working With Menus Across Breakpoints"
---

When designing a responsive site, always check that your menu appears as it should on all screen sizes. You may want to adjust the same menu for each viewport, or design unique menus that suit specific breakpoints.

**In this article, learn how to work with menus on different breakpoints:**

[Adding a menu on a desktop breakpoint](https://support.wix.com/en/article/editor-x-working-with-menus-across-breakpoints#adding-a-menu-on-a-desktop-breakpoint)  [Adding a menu on a mobile breakpoint](https://support.wix.com/en/article/editor-x-working-with-menus-across-breakpoints#adding-a-menu-on-a-mobile-breakpoint)  [Showing a different menu on each breakpoint](https://support.wix.com/en/article/editor-x-working-with-menus-across-breakpoints#showing-a-different-menu-on-each-breakpoint)

### Adding a menu on a desktop breakpoint

When adding a horizontal menu from the desktop breakpoint, it's automatically hidden from mobile. Instead, a [hamburger menu](https://support.wix.com/en/article/editor-x-using-hamburger-menus) is displayed as it takes up much less space.

>
> You can still [add a horizontal menu](https://support.wix.com/en/article/editor-x-adding-menus-to-your-site#adding-a-menu-1) to your mobile site while working on that breakpoint.

---

### Adding a menu on a mobile breakpoint

When adding a new menu to your mobile breakpoint, it's automatically hidden from larger breakpoints (e.g., tablet, desktop). This is useful in case you want to show a more minimal version that suits a smaller screen.

---

### Showing a different menu on each breakpoint

Editor X allows you to show different menus on different screen sizes using the same Master section. However, this can cause unintentional changes to other breakpoints while working on a specific one.

There are two ways we recommend that only affect the breakpoint you're working on:

[Create a dedicated Master section](https://support.wix.com/en/article/editor-x-using-global-sections) for each breakpoint, showing the unique menu that you designed for that screen size.   Create a new menu in a [lightbox (pop-up)](https://support.wix.com/en/article/editor-x-using-lightboxes) and add [an element that links to the lightbox](https://support.wix.com/en/article/editor-x-using-lightboxes#link-elements-to-a-lightbox) in the specific breakpoint.

> **Tip:**
>
> Use the **Don't Display** option to hide sections and elements from a breakpoint.
