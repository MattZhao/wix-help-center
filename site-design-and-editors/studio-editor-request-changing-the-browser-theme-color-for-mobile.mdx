---
title: "Studio Editor Request: Changing the Browser Theme Color for Mobile"
---

Currently, the Studio Editor does not offer a feature that lets you choose the color of the browser when visitors view your client's site on mobile.

As a workaround, you can add custom code to change the browser color, specifically for Safari:

**Single page: **[Add it as a meta tag](https://support.wix.com/en/article/adding-additional-meta-tags-to-your-sites-pages#adding-an-additional-meta-tag) in the page's Advanced SEO settings panel.  **Multiple or all pages: **[Add it to the Custom Code tab](https://support.wix.com/en/article/embedding-custom-code-on-your-site#adding-custom-code-to-your-site) in the dashboard.

This code, for example, changes the browser color to white:

`<meta name="theme-color" content="#ffffff">`

We are always working to update and improve our products, and your feedback is greatly appreciated.
