---
title: "Wix Photo Albums: Store Image Quality Web Ready vs. Original File"
---

> **Important:**
>
> Wix Photo Albums Store is not available to all users. As of February 2023, it is no longer possible to add Wix Photo Albums Store to your site. As an alternative, you can [add Wix Stores to your site](https://support.wix.com/en/article/wix-stores-adding-wix-stores) and [connect it to Printful](https://support.wix.com/en/article/wix-stores-connecting-to-printful) to sell your photos.

> **Important:**
>
> This option is only available if you are selling digital images only.

In the Wix Photo Albums Store, you can sell your images either as **Web Ready**, **Original File** or both. You can set different prices for each option.

#### Web Ready

If you upload an image over 1200 pixels, the Wix Photo Albums Store takes your image file and automatically creates a smaller version (the Web Ready file) which your customers can purchase. The Web Ready file has a slightly reduced quality and therefore can be sold at a lower price. These files are perfect for web use, and ideal if you are selling your images to be used online.

#### Original File

When purchasing your image through the Wix Photo Albums Store, customers receive the original file that you upload. The Original File has no reduction in quality and can therefore be sold at a higher price. If you intend to sell images for print, it is recommended to upload images over 1200 pixels in order to retain the quality.
