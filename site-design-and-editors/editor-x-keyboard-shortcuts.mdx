---
title: "Editor X: Keyboard Shortcuts"
---

While building your site with Editor X, you can use the following keyboard shortcuts to work quickly and efficiently.

> **Working on a Mac?**
>
> Use the **Cmd** key instead of the **Ctrl** key, and **Option** instead of **Alt**.

---

### Basic actions

ActionDescriptionCtrl + ZUndoCtrl + YRedoCtrl + Alt + PEnter and exit Preview modeCtrl + SSaveCtrl + Shift + PPublish

---

### Interaction with different elements

ActionDescriptionCtrl + XCut Ctrl + C Copy Ctrl + V Paste Ctrl + D Duplicate Delete / Backspace Delete an element Alt + SStack elementsAlt + Shift + SUnstack elementsCtrl + Shift + ↑Bring an element to the frontCtrl + Shift +  ↓Send an element to the backgroundCtrl +  ↓Move an element backwardCtrl +  ↑Move an element forward ←↑→↓ Move an element by 1px (i.e. Nudge) in a specific directionShift + ←Shift + →Shift + ↑Shift + ↓Move an element by 10px in a specific directionEscDeselect an elementShift + ResizeResize an element while maintaining its original proportionsAlt + ResizeResize an element from its center pointShift + DragDrag an element in a straight line, along a horizontal or vertical axis

---

### View Options

ActionDescriptionCtrl + (+)Zoom inCtrl + (-) Zoom outCtrl + 0 Reset your view to actual size (100%)Ctrl + .Open and close side panelsCtrl + IShow or hide the [Inspector](https://support.wix.com/en/article/editor-x-using-the-inspector-panel) panelCtrl + LShow or hide the [Layers](https://support.wix.com/en/article/editor-x-using-the-layers-panel) panelCtrl + / Show or hide the Keyboard Shortcuts panel

---

ActionDescriptionCtrl + BBoldCtrl + IItalicCtrl + UUnderline
