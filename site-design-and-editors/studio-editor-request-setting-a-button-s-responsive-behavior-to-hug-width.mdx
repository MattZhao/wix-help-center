Currently, the Hug Width [responsive behavior](https://support.wix.com/en/article/studio-editor-setting-the-size-of-your-elements#choosing-an-elements-responsive-behavior) is not available for buttons in the Studio Editor. This behavior would ensure the button text remains visible on all screens.

We are always working to update and improve our products, and your feedback is greatly appreciated.
