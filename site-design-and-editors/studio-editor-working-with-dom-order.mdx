Document Object Model (DOM) refers to how site pages are structured, and determines the tabbing and loading order of elements. Organizing the DOM order of a site can improve its accessibility and performance, and provide a better experience for visitors.

### The importance of DOM order

DOM order determines the loading, reading, and tabbing order of elements on a page. This means it can impact a site's:

**Accessibility:** Some site visitors may use assistive technologies to navigate sites, such as screen readers and / or the Tab key. A site's DOM determines the order in which it's read by screen readers, as well as the tabbing order. [Learn more about DOM and accessibility](https://support.wix.com/en/article/accessibility-checking-and-adjusting-a-sites-dom-order#why-dom-order-is-important)

**Performance:** The DOM determines the sequence in which elements load on a site. Matching the DOM order to the the visual order of elements therefore creates a logical loading experience. [Learn more about DOM and performance](https://support.wix.com/en/article/site-performance-your-sites-dom-order)

**SEO rankings:** As an aligned, logical structure can improve accessibility and site loading, it may also increase the site's SEO rankings.

A logical DOM order is therefore important, as it ensure the best experience for site visitors. For example, the site menu should come first, followed by the rest of the elements in the header, then the page title, then the page contents, etc.

### Auto DOM order

Automatic (auto) DOM is based on the visual order of elements on a page - from left to right, and top to bottom. The DOM order automatically rearranges as you add, align, and resize elements, so it should stay optimized as you go.

#### Disabling auto DOM

If you notice an issue with the DOM order of a site you're working on, you can disable it across the site. If there's an issue with specific elements, you can disable it on individual sections and containers, as well as grid cells within a section.

Select an option to learn how to disable auto DOM:

### The entire site

1. Click the **Wix Studio** icon  at the top left of the editor.
2. Click **Tools**.
3. Click **Auto DOM Order **to deselect it.
4. Click **Turn Off **to confirm.

[image: The tools subsection in the Studio Editor. The cursor has clicked Auto DOM order, disabling it.]

### Sections and containers

1. Right-click the relevant section / container.
2. Click **Auto DOM Order** in the right-click menu to deselect it.

[image: The right-click menu of a section in the Studio Editor. The cursor has clicked Auto DOM order, disabling it.]

### Grid cells in a section

1. Right-click the grid cell.
2. Click **Auto DOM Order** in the right-click menu to deselect it.

[image: The right-click menu of a section grid cell in the Studio Editor. The cursor has clicked Auto DOM order, disabling it.]

### Manually changing the DOM order of elements

After turning auto DOM order off, you can manually change it to match the visual order of elements (left to right, top to bottom).

#### To change the DOM order manually:

Click **Layers**  on the left side of the editor.  Choose what you want to organize:

- **Elements inside a section: **

1. Select a section to open it.
2. Drag and drop the elements into the correct position.
- **Sections: **

1. Hover over the top section and click the **More Actions** icon .
2. Click **Arrange**.
3. Click **Bring to Front**.
4. Repeat steps i-iii with all other sections, going from top to bottom in the panel.

---

### Reorganizing the DOM order

You can rearrange the DOM order of elements in a section, flexbox, or stack, or on an entire page with a single click. The order is optimized to match the visual order of the elements (left to right and top to bottom).

#### To reorganize the page's DOM order:

Click **Pages**  on the left side of the editor.  Select the relevant page.  Click the **More Actions** icon .  Click **Reorganize DOM Order**.

#### To reorganize the elements' DOM order:

Click **Layers**  on the left side of the editor.  Select the relevant section, flexbox, or stack.  Click the** More Actions** icon .  Click **Reorganize DOM Order**.

### FAQs

Select a question to learn more about DOM order on a site.

### How can I check the DOM order of a site I'm building?

You can test out the automatic DOM order of a site by using your keyboard's Tab key, or a screen reader on the live version of the site.

### How does auto DOM work on site pages?

It is not possible to disable auto DOM on specific site pages. If you want to turn it off, you need to disable auto DOM across the entire site.

### Where else can I enable auto DOM?

You may see the option to automatically organize a site's DOM order in [the Accessibility Wizard](https://support.wix.com/en/article/accessibility-using-the-accessibility-wizard-in-the-studio-editor). We recommend selecting this option, as it ensures the Wizard's scan and resulting tasks are correct.

### Is auto DOM applied anywhere else?

Auto DOM is applied to element stacks. You can disable auto DOM in the **Layers** panel.

### What happens to auto DOM if I rearrange elements in the Layers panel?

The auto DOM of sections and containers is automatically disabled if you change the order of their elements from the Layers panel. You can always reenable auto DOM for them if desired.

### Is there anything else I should know?

The automatic DOM order on a site has been built for left-to-right scripts (e.g. English, Spanish, etc.) If your site uses a right-to-left script such as Arabic or Hebrew, you need to manually re-arrange the DOM order in the Layers panel.
