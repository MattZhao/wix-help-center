---
title: "Studio Editor: Keyboard Shortcuts"
---

While building your client’s site on the Studio Editor, you can use keyboard shortcuts to work quickly and efficiently.

> **Working on a Mac?**
>
> Use the **Cmd** key instead of the **Ctrl** key, and **Option** instead of **Alt**.

---

### Basic actions

ShortcutWhat it doesCtrl + ZUndoCtrl + Y(or Cmd + Shift + Z)RedoCtrl + Alt + PEnter and exit Preview modeCtrl + SSaveCtrl + Shift + PPublish

---

### Interaction with different elements

ShortcutWhat it doesCtrl + XCut Ctrl + C Copy Ctrl + V Paste Ctrl + D Duplicate Delete / Backspace Delete an element  Ctrl + ClickSelect a child elementAlt + CPlace selected elements in a containerAlt + Shift + CRemove the container around the elementsAlt + SStack the selected elementsCtrl + ↑Bring an element to the frontCtrl +  ↓Send an element to the backCtrl +  ↓Move an element backwardCtrl +  ↑Move an element forward ←↑→↓ Move an element by 1px (i.e. Nudge) in a specific directionShift + ←Shift + →Shift + ↑Shift + ↓Move an element by 10px in a specific directionEscDeselect an elementCtrl + Drag / ResizeDisable the auto-docking while resizing or moving an elementShift + ResizeResize an element while maintaining its original proportionsAlt + ResizeResize an element from its center pointShift + DragDrag an element in a straight line, along a horizontal or vertical axis

---

### View options

ShortcutWhat it doesCtrl + (+)Zoom inCtrl + (-) Zoom outCtrl + 0 Reset your view to actual size (100%)Ctrl + .Open and close side panelsCtrl + IShow or hide the [Inspector](https://support.wix.com/en/article/studio-editor-using-the-inspector-panel) panelCtrl + LShow or hide the [Layers](https://support.wix.com/en/article/studio-editor-working-with-layers) panelCtrl + / Show or hide the Keyboard Shortcuts panel
