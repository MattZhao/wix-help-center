---
title: "Studio Editor Request: Defining Multiple Editor Views"
---

Currently, it is not possible to define separate settings or views of a single site in the Studio Editor (such as a view with the code panel open, a view displaying specific collections, etc.).

We are always working to update and improve our products, and your feedback is greatly appreciated.
