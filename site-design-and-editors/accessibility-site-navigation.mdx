---
title: "Accessibility: Site Navigation"
---

Site navigation is the way visitors move through the site's pages and content. A site should have multiple, consistent navigation methods, as this can make it accessible to a wider audience. For example, some visitors may find it easier to click, and others may find it easier to type.

There are 2 methods currently available to add to a Wix site: site menus, and Site Search.

**In this article, learn more about:**

[Adding a site menu](https://support.wix.com/en/article/accessibility-site-navigation#adding-a-site-menu)  [Adding Site Search](https://support.wix.com/en/article/accessibility-site-navigation#adding-site-search)  [Consistent site navigation](https://support.wix.com/en/article/accessibility-site-navigation#consistent-site-navigation)

> **Where does Wix get its information?**
>
> - We make recommendations as per the [Web Content Accessibility Guidelines (WCAG) document](https://www.w3.org/TR/WCAG21/#abstract), which has been developed by the [World Wide Web Consortium (W3C)](https://www.w3.org/).
> - This article is based on [success criterion 2.4.5 (Multiple Ways)](https://www.w3.org/WAI/WCAG21/Understanding/multiple-ways) and [success criterion 3.2.3 (Consistent Navigation)](https://www.w3.org/WAI/WCAG21/Understanding/consistent-navigation.html).

### Adding a site menu

Site menus are a popular method of navigation, and are usually placed in the header or footer of a site. Use them to display pages, sections, and links so visitors can find and access site content.

Most site templates already contain menus. However, you can also add a menu from the **Add Elements** panel in your site editor.

Studio EditorWix Editor
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Click **Add Elements ** on the left side of the editor.
3. Click **Menu & Search**.
4. Select the menu type you want (Horizontal, Vertical, etc.).
5. Click and drag the menu to add it to your site.

### Adding Site Search

Site Search allows visitors to find specific content or information via a search bar, and displays the results in a list. This can improve accessibility, as visitors don't need to click / scroll through content to find what they want.

You can add Site Search to a site from the **Add Elements** panel in your editor.

Studio EditorWix Editor
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Click **Add Elements ** on the left side of the editor.
3. Click **Menu & Search**.
4. Select **Site Search**.
5. Click **Add to Site** .
[image: Add Elements in the Studio Editor. Site Search is highlighted, and the cursor is clicking the icon to add it.]
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Click **Add Elements ** on the left side of the editor.
3. Click **Menu & Anchor**.
4. Select **Site Search**.
5. Click and drag your chosen search bar to add it to the site.
[image: Add Elements in the Wix Editor. Site Search is highlighted, and the cursor is clicking an option to add it.]

> **You should know:**
>
> [Some site elements / content can't be found by Site Search](https://support.wix.com/en/article/about-wix-site-search#visitors-can-search-for-the-content-they-need).

### Consistent site navigation

Once you have added site navigation methods, you should make sure that they are visible in the same position on all pages of the site.

If you're building a site with the Studio Editor, you can attach the navigation elements to the [header, footer, or a global section](https://support.wix.com/en/article/studio-editor-using-global-sections).

With the Wix Editor, you can attach navigation elements to the [site's header or footer](https://support.wix.com/en/article/wix-editor-placing-elements-in-your-header-footer-and-page). If you'd prefer to display them in the page body, you can [set them to show on all pages](https://support.wix.com/en/article/wix-editor-showing-an-element-on-all-pages).
