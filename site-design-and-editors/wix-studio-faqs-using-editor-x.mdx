As a [Wix Studio](https://www.wix.com/studio) user, you can choose to build a site on our brand new Studio Editor or, if you prefer, you can stick with Editor X for the meantime. Below we'll answer some of the most common questions we've received from Studio users about Editor X.

---

### Studio Editor vs Editor X

Click a question below to learn more about the difference between Editor X and the new Studio Editor.

### Is Wix Studio a rebranding of Editor X?

No, Wix Studio is a brand new web-creation platform with many advanced features and fresh new capabilities that set it apart from Editor X.

### How is Wix Studio different from Editor X?

Wix Studio was developed specifically for busy agency life. In comparison to Editor X, it offers a smoother, more efficient way to build high-end websites. AI, out-of-the-box tools, presets and reusable templates allow you to build with speed, while Custom CSS offers total precision and customization. 
On Wix Studio, you can integrate with all of our native business solution apps and add custom functionality using APIs, SPIs or your own custom components. At account-level, it provides a game-changing workspace, so you can run and manage your business in a more streamlined way, with total clarity. It also has its own dedicated mobile app, so you can manage your agency, from any device.

### What are some of the design features that make Wix Studio different from Editor X?

Wix Studio's design features, like AI responsiveness and proportional scaling, are literally game-changing, putting it in a league of its own compared to Editor X. 
Here are some of the new features that allow you to build exceptional creations in a smoother flow: 
- Smart tools that take care of responsiveness and layout
- A new editing mode so you can prioritize design efficiency
- A revamped stack and new grid experience to create intricate layouts more intuitively
- Custom CSS to create styles, animations and responsive behaviors to your exact specs
- An expanded range of no-code design capabilities, from interactions to brand new components like mega menu and slideshows
- Add Custom React components to any site

### Will you have training materials for updating the sites of existing clients?

At the moment, when you switch to Wix Studio, your existing sites will continue to live on their current Editor, under Sites. Only new sites built with Wix Studio will live in the Studio Editor. 
As soon as the update from Editor X to Studio becomes available, the [Wix Studio Academy](https://www.wix.com/studio/academy) will host educational events and provide training materials to guide you through the process.

### Using Editor X in Wix Studio

Click a question below to learn more about using Editor X in Wix Studio.

### What will happen to my current sites built on Editor X?

You can keep building on Editor X for now. We’ll gradually open up the option to [update sites to Wix Studio](https://support.wix.com/en/article/wix-studio-faqs-transitioning-from-editor-x) in January over several weeks.
Once the update is available to everyone, we’ll close the option to create new sites on Editor X — for this reason, we highly recommend using Wix Studio for any new projects you get.
Having said that, know that you’ll get plenty of notice and all the info before this happens.
**Note: **If you've never used Editor X before, the option to create new sites is now closed.

### Will existing Editor X sites be updated to Wix Studio or stay as they are?

In the first phase, your sites will not be automatically updated. The transition will change your workspace only. All sites will remain on their original Editor and are accessible through the Sites tab of the Wix Studio workspace.
In the coming months, we plan to fully transition Editor X to Wix Studio. Eventually, all Editor X sites will be updated to Wix Studio, and you'll no longer be able to create new sites on Editor X. Don’t worry—you’ll get plenty of notice before this happens.

### Are you planning to phase out Editor X?

Eventually, yes, Editor X will transition into Wix Studio and all sites will be updated. This update  will happen gradually, over several weeks starting January. 
Once the update is available to everyone, we’ll close the option to create new sites on Editor X — for this reason, we highly recommend using Wix Studio for any new projects you get.

### Can I stay on Editor X if I do not like the Wix Studio Editor?

Editor X and Studio will eventually merge in the future. Starting January, we'll open up the option to update sites from Editor X to Wix Studio. This means you won't have the option to stay on Editor X. 
Visit [Wix Studio Academy](https://www.wix.com/studio/academy) to learn more about the new platform.

### How will this affect Partners who offer Editor X services in Wix Marketplace?

At launch, Editor X will still be live, so you'll continue to get Editor X leads and can still build sites on the platform if you want to. Eventually, you'll be able to sell Wix Studio services in the Marketplace.

### If I have a responsive site built on Editor X and want to update it to Wix Studio, will it remain responsive?

At launch, you can only create new sites with Wix Studio. In the next phase, when the update from Editor X to Wix Studio becomes available, the sites you update will remain responsive and their behavior will not change.

### How are you going to update Editor X sites to Wix Studio, will it cause bugs?

Once the update is ready, sites built on Editor X will seamlessly move to the Studio Editor. There shouldn't be any bugs or changes to live sites.

### Are Wix Studio's Premium plans more expensive than Editor X's?

Visit the [Wix Studio Premium plans page](https://www.wix.com/premium-purchase-plan/studio) for pricing and details.

### If I upgrade an Editor X site now, will the price change when Editor X transitions to Wix Studio?

Wix Studio Premium plans are similar or equivalent to Editor X plans. Upon updating to Studio, if you move to a lower priced plan, in comparison to your existing Editor X plan, any remaining credit will be used to extend your plan to a longer duration.
