---
title: "Wix Editor: Linking to a URL with an Unsupported Character"
---

If you enter an invalid URL link or a web address that contains unsupported characters, the following error message is displayed: **Check the URL and try again**.

To bypass the validation, use a link shortening service such as [bit.ly](http://bit.ly/) or [goo.gl](http://goo.gl/).
