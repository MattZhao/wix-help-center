In the Studio Editor, [sections](https://support.wix.com/en/article/studio-editor-adding-and-managing-sections) come with a built-in grid, containing a single cell (housing the entire section). Split the section into more cells to give a responsive structure to the content. There are various customizable layouts to choose from.

### Adding cells to a section

Add cells to a section to create a responsive, structured layout. Keeping the elements in separate cells ensures they stay in place on all screens. Choose a layout, then move elements to the cells - you can always split the cells or add new ones later.

> **Looking to add cells to a container?**
>
> You can [apply an advanced CSS grid](https://support.wix.com/en/article/studio-editor-working-with-an-advanced-css-grid) on the container.

#### To add cells to a section:

Select the relevant section.  Click the **Blank** drop-down at the top of the section.

Choose a layout: **Rows**, **Columns**, **Collage**, etc.

**Tip: **You can change the layout from the drop-down at any time - it will not move your elements around.  Drag elements to the relevant cells.

> **Do your grid cells overlap on mobile?**
>
> We recommend switching to a vertical layout (like Rows) to resolve this issue.

### Customizing the section grid

Make the grid look just as you want. You can split or merge existing cells, add new ones and drag the grid lines to adjust their size. You can also add gaps to create some space between the cells.

#### To customize the section grid:

Select the relevant section.  Choose how you want to customize the grid:

### Resize the grid

You can resize a cell directly on the canvas, or enter the exact width and height in the Inspector panel. Note that the cell height depends on the overall section height. 
**On the canvas:**Drag the gridlines around a cell to change its size. 
[image: Dragging the bottom gridline of a grid row to adjust its height in the Studio Editor]
**In** **the Inspector:**
1. Click the **Open Inspector** icon  at the top right of the editor.
2. Scroll down to **Layout**.
3. Depending on what you want to resize, click **Columns** / **Rows**.
4. Edit the size of the relevant column or row (in px or %).

**Tip:** You can also equalize the grid vertically  or horizontally , to make the rows or columns the same size.

### Add more cells to the grid

Click **Add Cell** and choose where to add it on the grid.
**Note:**A section grid can include up to 16 cells. If you need more cells, you can either:
- Split the grid into multiple sections
- Switch to an advanced CSS grid. As it's not possible to switch back from the advanced grid, we recommend creating a copy of the section first.

[image: A shortcut on the canvas to add a new column or row to the grid]

### Split a cell

1. Select the cell you want to split.
2. Click the relevant icon: **Split Horizontally**  or **Split Vertically** .

**Note:**A section grid can include up to 16 cells. If you need more cells, you can either:
- Split the grid into multiple sections
- Switch to an advanced CSS grid. As it's not possible to switch back from the advanced grid, we recommend creating a copy of the section first.

[image: A screenshot showing how to select a cell and split it using the toolbar above the cell]

### Merge cells

1. Select one of the relevant cells.
2. Hold the **Shift** key on your keyboard while selecting the other cell.
3. Click **Merge**.

**Note:** This merges the grid cells on all breakpoints.

### Add gaps between cells

Using gaps, you can add some space between the grid cells.
1. Click the **Open Inspector** icon  at the top right of the editor.
2. Scroll down to **Layout**.
3. Enter values for the horizontal and / or vertical gap.

### Delete a cell

You can remove a cell from the section at any time. This deletes both the cell and the elements within. 
1. Select the relevant cell.
2. Click the **More Actions** icon .
3. Click **Delete**.

[image: The menu that opens when clicking the More Actions icon on a cell, allowing you to delete it amongst other actions]

> **Note:**
>
> Currently, it is not possible to duplicate a cell.

### Swapping and flipping cells in the grid

Reorganize the section grid quickly and efficiently by swapping cells. Using drag and drop, you can instantly swap between 2 cells – they instantly take each other's spot on the grid.

Alternatively, you can flip the entire grid horizontally or vertically to explore different options of presenting your client's content.

#### To swap cells:

Select the relevant section.  Choose what to do next:

### Swap 2 cells

1. Select the first cell.
2. Hold the **Drag** icon  at the top of the cell while dragging it onto the other cell. **Tip: **When you see the **Swap content** indication, it means you can drop the cell.

[image: Using drag and drop to swap 2 cells in the section grid]

### Flip the grid

1. Click the **Open Inspector** icon  at the top right of the editor.
2. Scroll down to **Layout**.
3. Click the relevant icon: **Flip columns** or **Flip rows**.

### Switching to an advanced CSS grid

Switching to an [advanced CSS grid](https://support.wix.com/en/article/studio-editor-working-with-an-advanced-css-grid) gives you more precise control of the layout per breakpoint. You can choose the number of rows and columns you want, and set their size using responsive measurements (e.g. fr, Min/max, %).

#### To switch from section grid to a CSS grid:

Select the relevant section.  Click the **Open Inspector** icon  at the top right of the editor.

  Scroll down to **Layout**.  Click **Switch **next to **Advanced CSS grid**.  Click **Switch to CSS Grid**.
