---
title: "Studio Editor Request: Setting the Animation Distance in px*"
---

In the Studio Editor, you can use different measurements (e.g. px, %) to set the [animation](https://support.wix.com/en/article/studio-editor-about-animations)'s distance. Currently, it is not possible to set this value in [px*](https://support.wix.com/en/article/studio-editor-setting-the-size-of-your-elements#setting-the-size-in-px).

We are always working to update and improve our products, and your feedback is greatly appreciated.
