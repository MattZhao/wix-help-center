---
title: "Studio Editor Request: Resizing the Top Row Without Affecting the Bottom Row in a Section Grid"
---

When dragging a row gridline in a [section grid](https://support.wix.com/en/article/studio-editor-customizing-a-section-grid), it changes the height of both the top and bottom rows. Currently, it is not possible to only resize the top row, while maintaining the bottom row's height.

We are always working to update and improve our products, and your feedback is greatly appreciated.
