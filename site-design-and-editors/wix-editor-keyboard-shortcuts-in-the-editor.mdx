---
title: "Wix Editor: Keyboard Shortcuts in the Editor"
---

Use keyboard shortcuts in the Editor to manage your elements, tools, and pages. There are shortcuts available for general Editor use, as well as editing text.

**In this article, learn more about:**

[Keyboard shortcuts in the Editor](https://support.wix.com/en/article/wix-editor-keyboard-shortcuts-in-the-editor#general-editor-shortcuts)  [Keyboard shortcuts for editing text](https://support.wix.com/en/article/wix-editor-keyboard-shortcuts-in-the-editor#text-editing-shortcuts)

> **If you are using a Mac:**
>
> - Use the **Command** ⌘ key instead of the **Ctrl** key.
> - Use the **Option** key instead of the **Alt **key.

---

The below keyboard shortcuts are available in your Editor:
