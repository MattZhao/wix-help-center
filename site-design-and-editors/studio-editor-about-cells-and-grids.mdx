---
title: "Studio Editor: About Cells and Grids"
---

Grids are a powerful tool when it comes to responsive design. The grid is made up of cells, and each element, or group of elements, gets its own cell. This keeps your layout in place on every screen size, ensuring that elements don't overlap.

You can add cells to organize a section, or apply an advanced CSS grid for more precise control. The CSS grid is also available for elements like containers and repeater items which cannot be split into cells.

---

### Section grid

In the Studio Editor, [sections](https://support.wix.com/en/article/studio-editor-adding-and-managing-sections) come with a built-in grid, containing a single cell (housing the entire section). Split the section layout into more cells to give a responsive structure to the content. There are various customizable layouts to choose from.

After choosing the relevant layout, refine it to your needs by [adding new cells or splitting existing ones](https://support.wix.com/en/article/studio-editor-customizing-a-section-grid). To adjust the size of each cell, just drag the grid lines on the canvas.

---

### Advanced CSS grid

Need more precise control of the section grid? Switch to an advanced CSS grid to adjust the rows, columns and their size with advanced measurements (e.g. fr, Min/max, %). You can tailor these settings per breakpoint so the grid makes sense on every screen size.

Apply an advanced CSS grid on an entire section, or just a specific cell. It's also a way to add a grid to elements other than sections, like a container or a repeater item. If the option is available, you can find it under the Layout section in the Inspector panel.

### How do I know which grid is right for the section?

Switching to a CSS grid gives you more precise control of the layout per breakpoint. You can set the number of rows and columns you want, and set their size using advanced responsive measurements (e.g. fr, Min/max, %).
[image: A screenshot of the Layout section in the Inspector after applying an advanced grid]
If you just need the section's elements to have an organized and responsive layout - there is no need to switch to an advanced grid. Set the size of each cell on the current canvas, and we'll ensure the cells look great on every screen.
[image: A GIF showing how to drag the grid lines on the canvas]

### Does switching to a CSS grid disrupt the existing layout?

No, the elements don't move around when you switch to an advanced CSS grid. A new layout of rows and columns simply replaces the previous one, based on the number of cells you had.
For example, if you had multiple cells in 1 row, a column is automatically added so the elements stay in separate cells.
