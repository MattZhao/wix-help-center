---
title: "Wix Editor: Viewing a Wix Site Using Firefox on Android"
---

It is possible to load your site using Firefox on an Android device, however, we are currently not testing functionality, and therefore unable to offer support for any issues that may occur on this device.

We have investigated this matter and discovered that the amount of traffic coming to Wix sites from this browser on Android is very low.

We will continue to monitor mobile traffic and if we see an increase in traffic from this device, we will make changes accordingly.
