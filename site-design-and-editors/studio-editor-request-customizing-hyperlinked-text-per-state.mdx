---
title: "Studio Editor Request: Customizing Hyperlinked Text per State"
---

Currently, it is not possible to customize hyperlinked text for each state (**Regular**, **Hover**, and **Clicked**).

> **Want to change the text color in each state?**
>
> You can [add the Color animation](https://support.wix.com/en/article/studio-editor-adding-a-preset-click-or-hover-interaction) to play on **Hover** / **Click**. This workaround only applies if the hyperlinked text is in its own text box.

We are always working to update and improve our products, and your feedback is hugely appreciated.
