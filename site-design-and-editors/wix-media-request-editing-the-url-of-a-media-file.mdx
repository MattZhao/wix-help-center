---
title: "Wix Media Request: Editing the URL of a Media File"
---

Currently, it is not possible to edit the URL of an image, video etc. that you upload to the Media Manager.

When you [copy the URL of a media file in the Media Manager](https://support.wix.com/en/article/wix-media-retrieving-the-url-of-a-file-in-the-media-manager), you will see something like the following example: video.wixstatic.com/video/**0be7c8_44551759192e465eaf0e0b350962a**/480p/mp4/file.mp4.

The name of your file does not appear in the URL. Instead, the Wix server, where your images are hosted, automatically assigns an ID to your file (shown in bold in the example above).

We are always working to update and improve our products, and your feedback is hugely appreciated.
