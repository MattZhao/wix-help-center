---
title: "Wix Audio Request: Set Prices Based on Download File Types in Wix Music"
---

Currently, you can set a price for downloading tracks, singles or albums. However, you cannot set different pricing options for different track versions. For instance, you cannot set one price for a FLAC version of the track and a different price for the MP3 version of the same track.

We are always working to update and improve our products, and your feedback is hugely appreciated.
