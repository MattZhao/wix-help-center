---
title: "Studio Editor Request: Adding 3D Models and Elements"
---

Currently, it is not possible to add a 3D element or model from the **Add Elements** panel.

As an alternative, you can [add a HTML iFrame to the page](https://support.wix.com/en/article/studio-editor-adding-an-html-iframe-element), and embed external code to display a 3D model / element.

We are always working to update and improve our products, and your feedback is greatly appreciated.
