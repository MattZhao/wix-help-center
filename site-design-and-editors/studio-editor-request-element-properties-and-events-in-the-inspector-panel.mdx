title: "Studio Editor Request: Element Properties and Events in the Inspector Panel"
---

In the Studio Editor, you can select an element to see its ID and event handlers in the Code panel . Currently, these settings are not available in the Inspector panel.

We are always working to update and improve our products, and your feedback is greatly appreciated.
