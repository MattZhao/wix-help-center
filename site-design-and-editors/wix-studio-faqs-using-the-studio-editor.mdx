### Studio Editor features

Click a question below to learn more about the Studio Editor features.

### What new design tools does Wix Studio offer?

Whether you’re more familiar with creating on the classic Wix Editor or Editor X, Wix Studio’s design tools allow you to create exceptional websites, however suits you best. You can work with pixel-level control or take advantage of AI responsiveness and out-of-the-box design tools to meet your client’s exact vision in less time.

- Build efficiently on an advanced and intuitive visual canvas, powered by smooth drag and drop
- Create intricate layouts more intuitively with a revamped stack and new grid experience
- Add responsive behavior to any page in a matter of clicks with game-changing built-in tools
- Use custom CSS to create any unique web experience you can imagine
- Build bespoke apps and widgets on Blocks and add custom React components to any project
- Access rich design libraries with engaging new motion effects, like no-code scroll and sticky behaviors and ready-to-use interactions

### Do I have to use code to build sites on Wix Studio?

You can use code but it's not mandatory. With Wix Studio, we have introduced advanced no-code features, such as animations and interactions, so you have the choice of both.

### What AI features will be available on Wix Studio?

You can make any page or section responsive in just a few clicks with our game-changing, patented, Responsive AI tool that analyzes your design and applies responsive logic to it. Over time, we'll expand the tool's capabilities to do more.

Use the AI Text Creator, a customized version of the GPT model by OpenAI, to generate text for your site when you need to work fast or require creative inspiration. And turn your text prompts into images—in seconds—with our AI image generator.

Add more functionality to the sites you build with the help of [Wix AI Assistant](https://dev.wix.com/docs/develop-websites/articles/workspace-tools/developer-tools/wix-ai-assistant/working-with-the-wix-ai-assistant-in-the-wix-ide). It can generate code, give instructions on how to use the code correctly and help with resolving errors.

Discover even more AI tools to auto-enhance images, remove image backgrounds, auto-generate trailers and recommend products. We have many more in the works—keep an eye out for what's coming your way.

### What does Responsive AI mean?

Responsive AI is patented technology that adds responsiveness to any page or section with the click of a button. The AI tool analyzes and places a responsive structure on the design, allowing faster and more efficient site creation. Responsive AI users can choose to continue with the suggested layout or discard changes and to go back to the original design.

### What is responsive design on Wix Studio?

With the Wix Studio Editor, you can use AI to make site pages and sections instantly responsive—in just a couple of clicks. You can create custom breakpoints, use modular flex layouts and take advantage of out-of-the-box responsive behaviors, like scale proportionally, to build smarter and more efficiently than ever before. For those who want it, deep CSS control allows you to create high-end websites with complex layouts and interactions.

### Where can I experiment with the Studio Editor features?

From the [Discover page](https://support.wix.com/en/article/wix-studio-about-the-discover-page), you can use sandboxes to experiment with elements of the Wix Studio Editor in more detail. Use them to play with responsive layout or code, explore CMS functionality and more.

### Can my team and I work on a Wix Studio site at the same time?

Yes, you and multiple teammates can work on a Wix Studio site simultaneously and see design changes in real time.

### Does Wix Studio support multilingual sites?

Yes, Wix Studio fully supports the [multilingual](https://support.wix.com/en/article/studio-editor-adding-wix-multilingual) functionality. You can translate sites into 180 languages manually or automatically.

### Will the live site performance be better on Wix Studio?

We are constantly improving live site performance and it will be prioritized for Wix Studio too. 
You may see slower performance on sites with heavy videos and content. We recommend checking page performance using [Page Speed Insights](https://support.wix.com/en/article/site-performance-understanding-pagespeed-insights#understanding-googles-suggestions) and following the recommendations [here](https://support.wix.com/en/article/site-performance-best-practices#third-party-code).

### Do I need to pay for Wix Studio?

For now, no additional payment is required to use Wix Studio. You only pay for Premium subscriptions as usual. Learn more about [Wix Studio Premium plans](https://support.wix.com/en/article/wix-studio-upgrading-sites).

### What Business Solutions apps can I use in Wix Studio? How have they been improved?

With Wix Studio, you can build robust and fully-responsive sites for clients in any industry using our built-in business solutions for eCommerce, Bookings, Restaurants, Events & Tickets, CMS, Blog, Subscriptions and much more.

With eCommerce sites, you can now use dynamic pages to display each product category, shape product pages however you like, design distinctive cart pages using Wix Blocks, and customize checkout with APIs to create unique discount, shipping, and payment options for a completely tailored experience.

Many of our business solutions are part of [Wix Headless](https://support.wix.com/en/article/about-wix-headless) too, so you can bring Wix eCommerce, Bookings and more, to any tech stack.

All business solutions and tools are fully in sync. Your clients can use our native CRM and Marketing tools to help grow their business, without the need for plugins or third-party apps, and manage everything from end-to-end from one unified dashboard.

Our native apps are built to give you peace of mind, with features that allow you to stay in-control and up-to-date, even when you're on the move. With the [Wix mobile app](https://support.wix.com/en/article/wix-owner-app-an-overview), clients can run their business, without impacting design. With the brand new [Wix Studio app](https://support.wix.com/en/article/wix-studio-app-an-overview) you can run your agency anywhere. Use it to manage all your sites whenever it's needed, keep track of projects, teammates, Marketplace leads, customer support and more.

### Will I be able to create custom templates with Wix Studio?

Yes, you’ll be able to create, manage and reuse your own custom templates within your Wix Studio workspace, so you can get started quickly and save time when building at scale. Learn more about [creating custom templates](https://support.wix.com/en/article/wix-studio-creating-and-using-custom-templates).

### What apps and integrations work with Wix Studio?

The [Wix App Market](https://support.wix.com/en/article/about-the-wix-app-market) has 100s of apps that are compatible with Wix Studio, plus you can build your own reusable apps on [Wix Blocks](https://support.wix.com/en/article/wix-blocks-getting-started). Develop custom UI components or add-ons and extend the functionality of our business solutions with open APIs, SPIs and integrations.

### How do I build apps or components to use with Wix Studio?

Wix Blocks is a creation tool that allows you to build responsive, reusable and customizable assets, to add custom experiences and interactions to any Wix site.

With Wix Blocks, you can develop reusable UI components and add-ons, integrate them into Wix Studio and tailor them to any site's theme. You can also adjust the code packages you build with Blocks, from site-to-site, to tailor the functionality to each client’s use-case.

Grow revenue with Blocks by developing full-stack applications for sale in the Wix App Market (245M+ users). You can easily integrate and add functionality to existing app builds using readymade REST APIs and webhooks. Plus, you can develop and sell your code packages, UI components and add-ons to other developers too. Learn more about [Wix Blocks](https://support.wix.com/en/article/blocks-unboxed-a-quick-tour).
