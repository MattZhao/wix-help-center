---
title: "Wix Editor Request: Changing the Font Size of Subpage Items in a Menu"
---

Currently, the font size for both the main items and subpage items are the same.

It is not possible to change the font size of the subpage items without it affecting the main menu items.

We are always working to update and improve our products, and your feedback is hugely appreciated.
