---
title: "Wix Editor Request: A Drop-Down Feature in a Text Box"
---

Currently, it is not possible to add a drop-down feature to a text box which your visitors can click to select an option.

In the meantime you can use the selection user input element to add a drop-down to your site. [Learn More](https://support.wix.com/en/article/cms-setting-up-a-custom-form-using-dropdown-input-elements)

We are always working to update and improve our products, and your feedback is hugely appreciated.
