---
title: "Studio Editor Request: Adding a Hyperlink to a Container"
---

While you can hyperlink text, images and buttons in the Studio Editor, it is not possible to add a link to a container.

As an alternative, you can add and set up a linked image inside the container, and set it to be transparent.

### To add a link to a transparent image:

[Add an image](https://support.wix.com/en/article/studio-editor-adding-creating-and-uploading-images) to the container.  Click the Link icon .  Select a link type on the left and add the relevant link information.  Click **Done**   [Open the Design tab in the Inspector panel](https://support.wix.com/en/article/studio-editor-using-the-inspector-panel).  Set the **Image opacity** slider to 0%.
