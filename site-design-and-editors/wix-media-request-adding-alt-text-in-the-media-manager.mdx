---
title: "Wix Media Request: Adding Alt Text in the Media Manager"
---

Currently, it is not possible to add alt text to a file directly inside the Media Manager. You must [add alt text to each individual file in the Editor](https://support.wix.com/en/article/optimizing-your-images-and-galleries-for-seo-alt-text#adding-alt-text-to-individual-images).

We are always working to update and improve our products, and your feedback is hugely appreciated.
