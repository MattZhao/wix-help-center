---
title: "Pricing Plans: Checking How Many Package Sessions Were Used"
---

After you sell a package to a client (e.g. a package that allows clients access to six classes per month), you can view how many sessions they have booked.

### To view the number of sessions that have been used:

Go to the [Subscriptions](https://www.wix.com/my-account/site-selector/?buttonText=View%20Purchased%20Subscriptions&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https://www.wix.com/dashboard/\{\{metaSiteId\}\}/membership/orders) tab in your site's dashboard.  Select a purchased plan from the list.

View the number of sessions remaining.  (Optional) Click the **Edit **icon to manually add or remove sessions.

> **Tip:**
>
> To check package usage in the [Wix app](https://support.wix.com/en/article/wix-owner-app-an-overview), just tap the **Subscription **shortcut.
