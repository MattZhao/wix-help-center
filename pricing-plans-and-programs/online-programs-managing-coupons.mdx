### Managing coupons

Wix Online Programs offers two types of coupon options to help you promote and reward participants. The first is a fixed monetary discount, such as a $5 discount, which is ideal for attracting new customers. The second is a percentage discount, like 20% off, which is perfect for rewarding existing participants. For both types of coupons, you can set an expiration date and limit usage to one coupon per customer. Additionally, you can control the total number of times each coupon can be used, ensuring you have full control over your promotions.

DashboardWix app
1. [Go to Coupons](https://www.wix.com/my-account/site-selector/?buttonText=Manage%20Coupons&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https://www.wix.com/dashboard/\{\{metaSiteId\}\}/coupons/) in your site's dashboard.
2. Choose what you want to do next:
Create a coupon
1. Click **+ New Coupon**.
2. Select the type of coupon you want to offer:

- **$ Discount**: Offer a fixed monetary discount amount.
- **% Discount**: Offer a percentage discount.
3. Enter the **Coupon code **participants need to use the coupon.
4. Enter the **Coupon name **for your own records.
5. Enter the **Discount** you want to offer.
6. Select the relevant programs from the **Apply to** drop-down:

- **All Programs:** Participants can use the discount for all programs.
- **Specific Program: **The discount is available for the programs you choose. Select the relevant program from the **Program** drop-down.
7. Select the dates the coupon is valid between.
8. (Optional) Select the **Limit uses **checkbox(s) to:

- ** Limit the total number of uses for this coupon: **Set the number of times the coupon can be used.
- **Limit** **to one use per customer: **The same participant can't use the coupon more than once.
9. Click **Create Coupon**.

Duplicate a couponIf you want to create a new coupon with settings that are similar to a coupon you already have, you can save time by duplicating it and then making changes.

1. Click the **More Actions **icon  next to the relevant coupon.
2. Select **Duplicate**.
3. Edit the coupon and click **Create Coupon**.

Activate, deactivate or delete a couponYou can deactivate a coupon when you no longer want to offer a particular promotion and then activate it again when the time is right. If you won't need it in the future, you can delete it. 

1. Click the **More Actions **icon  next to the relevant coupon.
2. Select an option:

- **Deactivate / Activate: **Select **Deactivate **so customers can't use it or **Activate **to make it available.
- **Delete: **Select **Delete** and then click **Yes, Delete** to confirm.

**Tip: **By default, the coupon section displays only your active coupons. Tap the drop-down to view coupons with other statuses.
Edit a coupon
1. Click the **More Actions **icon  next to the relevant coupon.
2. Select **Edit**.
3. Change the relevant information.
4. Click **Save**.

Copy coupon code
1. Hover on the relevant coupon.
2. Click the **Copy coupon code** icon  to copy the code to your clipboard.

### FAQs

Click a question below to learn more.

### Can I create coupons for other products?

Yes. You can create coupons for:
- [Wix Bookings](https://support.wix.com/en/article/wix-bookings-creating-coupons-using-the-wix-owner-app)
- [Wix Events](https://support.wix.com/en/article/wix-events-creating-event-coupons-using-the-wix-owner-app)
- [Pricing Plans](https://support.wix.com/en/article/pricing-plans-creating-coupons-using-the-wix-owner-app)
- [Wix Restaurants](https://support.wix.com/en/article/wix-restaurants-creating-a-coupon)
- [Wix Stores](https://support.wix.com/en/article/wix-stores-offering-discounts-and-coupons)

### Can I use coupons if my site only accepts cash?

Yes. You can apply coupons to services purchased with the [Manual payment method](https://support.wix.com/en/article/setting-up-manual-offline-payments). Make sure to mark the service as paid to update the number of coupons remaining.

### Can customers apply coupons to free programs?

No. Customers cannot apply coupons to free programs.

### How do customers use the coupon?

Customers can enter a coupon code on checkout in the **Enter a coupon code** field.

### Do coupons work for programs paid using pricing plans?

No. Customers can't use coupons for programs set up to be paid with pricing plans only.

### Can I create a bulk of personal coupons?

No. The [Bulk Coupon Creator app](https://www.wix.com/app-market/bulk-coupon-creator?referral=search-result&appIndex=0&referralTag=Bulk%20Coupon%20Creator&referralSectionName=search-result) is not available for Wix Online Programs.

### How can I promote my coupon?

Use the **Promote** link to easily create an email marketing campaign or social post for any of your coupons.
**To promote your coupon:**
1. [Go to Coupons](https://www.wix.com/my-account/site-selector/?buttonText=Manage%20Coupons&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https://www.wix.com/dashboard/\{\{metaSiteId\}\}/coupons/) in your site's dashboard.
2. Click the **More Actions** icon  next to the relevant coupon.
3. Select **Promote**.
4. Select a promotion option:

- [Send a social post](https://support.wix.com/en/article/social-posts-creating-and-customizing-a-social-post).
- [Send an email marketing campaign](https://support.wix.com/en/article/email-marketing-sending-your-email-campaign).

### Are coupon codes case sensitive?

No, coupon codes are not case sensitive. Customers can enter your codes in capital or lowercase letters.

### What happens if the discount is more than the program price?

Make sure you aren't giving away program for free. Apply the price discount coupon only to program that cost more than the value of the discount. 
For example, if you create a $10 price discount coupon and a customer applies it to an $8 program, that item will be free.
