---
title: "Error Messages When Verifying Your Site with Pinterest"
---

When trying to verify your site with Pinterest you may receive the following errors on the Pinterest "Confirm Website" dashboard:

"Oops! API Method not found""Oops! Looks like we had trouble connecting to your website. Please try again later."

This is not a problem with your Wix site, it is a problem with Pinterest. We also see non-Wix users affected by this issue.

You can be sure that when you add the verification meta tag to your site, it is added to the code and visible to Pinterest.

### If you are receiving a Pinterest verification error:

Try again a few times.If it still does not work, try to verify through this link: www.pinterest.com/website/verify.If it still does not work, contact Pinterest directly. If Pinterest says that it is a Wix problem, ask them for more information. We would like to know what the problem is so that we can investigate and fix it.
