---

Meta tags contain information about a page that web browsers and search engines can read. You can also [add additional meta tags](https://support.wix.com/en/article/adding-additional-meta-tags-to-your-sites-pages) to your site to give search engines additional information about your pages.

### Troubleshooting additional meta tag issues

If you're having issues with adding additional meta tags, try the following:

### Check if the meta tags is already added

You can add up to 10 meta tags. However, you can't add the same meta tag twice.It's also not possible to add a default meta tag that Wix already created for you.

[Learn More](https://support.wix.com/en/article/understanding-your-pages-default-seo-settings)

### Make sure that the meta tag format is correct

You can only use **\<meta>** and **\<link>** tags in valid HTML format. 

For example:

\<meta key="value" another_key="value"/>

\<link rel="value" href="value"/>
