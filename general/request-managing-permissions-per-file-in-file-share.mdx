---
title: "Request: Managing Permissions per File in File Share"
---

Currently, when you set permissions (e.g. who can edit files), those permission apply to all files in all folders in your library. You cannot grant different permissions for different files.

We are always working to update and improve our products, and your feedback is greatly appreciated.
