---
title: "Live Site Errors"
---

Standard HTTP status codes can appear in your browser if there is an error loading your site. Each status code represents a different type of error message. The most common codes are 401, 403, 404, 500 and 502.

### Click below to learn how to resolve live site errors:

[Error 401 (unauthorized)](https://support.wix.com/en/article/live-site-error-error-401-unauthorized)  [Error 403 (forbidden)](https://support.wix.com/en/article/live-site-error-error-403-forbidden)  [Error 404 (not found)](https://support.wix.com/en/article/live-site-error-error-404-not-found)  [Error 500 (internal server error)](https://support.wix.com/en/article/live-site-error-error-500-internal-server-error)  [Error 502 (bad gateway)](https://support.wix.com/en/article/live-site-error-error-502-bad-gateway)

> **Tip:**
>
> If you receive the error message **ERR_CONNECTION_TIMED_OUT**, check your internet connection. Click [here](https://support.wix.com/en/article/wix-technical-assistant) to troubleshoot.

---

If you're still unable to view your live site, [contact us](https://www.wix.com/contact) with the following information:

The specific error you are receiving, including a [screenshot](https://support.wix.com/en/article/adding-a-screenshot-to-a-ticket) of the error.  Your Wix username or email address.   Your domain name and site name.   Your Operating System (e.g. macOS Sonoma, Windows 10).  The different browsers and browser versions you have tried.

**Note: **Go to [whatismybrowser.com](http://www.whatismybrowser.com) to find out what browser version you are using.   Your geographic location and which Internet Service Provider (ISP) you use.   Which internet security programs are installed on your computer (e.g. antivirus, firewall).  Which troubleshooting steps you've already tried.
