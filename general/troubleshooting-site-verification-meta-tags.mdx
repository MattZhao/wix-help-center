---
title: "Troubleshooting: Site Verification Meta Tags"
---

If you're experiencing issues adding meta tags to verify ownership of your site, check the following possible errors.

#### Meta tag has been added to the wrong search engine

Check that the meta tag added is for the** **right search engine. For example, pasting a Google tag into Bing will cause issues.

#### Meta tag formatting is incorrect

The correct format is \<meta name=”XX” content=”XX”/>. Check to see If your code is missing a ‘\<’, a ‘ “ ‘, or has extra attributes. Any other format will cause an issue.
