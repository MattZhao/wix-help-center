---

The Wix Pinterest Feed app has been removed from the Wix App Market. However you can still add content from Pinterest to your site in 2 ways; you can embed a Pinterest widget, or add the Social Media Feed app to your site and set it to display your Pinterest content.

**In this article, learn how to: **

[Embed a Pinterest widget](https://support.wix.com/en/article/adding-pinterest-content-to-your-site#embedding-a-pinterest-widget)   [Add the Social Media Feed app](https://support.wix.com/en/article/adding-pinterest-content-to-your-site#adding-the-social-media-feed-app)

---

### Embedding a Pinterest widget

Pinterest offers a few different widgets which you can embed onto your site. You'll need to generate the code directly from Pinterest and then come back to Wix and embed the code using our HTML element.

> **Before you begin:**
>
> Click the links below to find out how to generate code for the widget you want to add:
> - [Pinterest Board](https://developers.pinterest.com/tools/widget-builder/?type=board&boardHeight=240&boardWidth=400&imageWidth=80&template=square)
> - [Pinterest Pin](https://developers.pinterest.com/tools/widget-builder/?type=pin)
> - [Pinterest Profile](https://developers.pinterest.com/tools/widget-builder/?type=profile&boardHeight=240&boardWidth=400&imageWidth=80&template=square)
> - [Pinterest Follow button](https://developers.pinterest.com/tools/widget-builder/?type=follow)
> - [Pinterest Save button](https://developers.pinterest.com/tools/widget-builder/?type=pinit)
> **Note:** You need to copy both sets of code. The last piece of code needs to be added to the end of the first piece of code before the closing tag.

Once you have the code ready, embed it as described below.

Wix EditorStudio Editor

1. Click **Add Elements **** **on the left side of the Editor.
2. Click **Embed Code**.
3. Click **Embed HTML**.
[image: A screenshot of the the Add Elements panel showing the option to Embed HTML.]
1. Click **Enter Code**.
2. Make sure **Code** is selected under **What do you want to add?**.
3. Paste the code you copied from step 1 into the **Add your code here (HTTPS only)** field.
4. Click **Apply**.
5. (Optional) Enter alt text that describes what you're embedding in the **What's in the embed? Tell Google **field.
6. When ready, publish your site.

### Adding the Social Media Feed app

The Social Media Feed app is a third-party app which allows you to add your Pinterest URL and display a live feed of all your Pinterest content. You can [add the Social Media Feed app](https://www.wix.com/app-market/twitter-feed) directly from the Wix App Market.
