---
title: "About TTL"
---

Time to live (TTL) is the value of time that tells servers how long to store a DNS record locally before discarding. 

You should leave the TTL for your DNS records set to the default time.

> **Important:**
>
> Changing a TTL value does not speed up the time it takes for a DNS record to propagate. It only changes the amount of time before your computer is forced to make a new DNS request.
