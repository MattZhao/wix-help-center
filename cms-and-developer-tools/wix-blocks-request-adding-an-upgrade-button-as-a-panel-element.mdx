---
title: "Wix Blocks Request: Adding an 'Upgrade' Button as a Panel Element"
---

Currently in Wix Blocks, you must manually implement the logic of sending an app user to an upgrade page.

An 'upgrade' button would be part of Wix Blocks [panel elements](https://support.wix.com/en/article/wix-blocks-velo-api-reference-for-panel-elements). When app users click the button, they will be directed to the default upgrade app page.

We are always working to update and improve our products and your feedback is greatly appreciated.
