---
title: "Wix Blocks Request: Building Custom Panels for Non-Blocks Widgets"
---

Currently in Wix Blocks, you can build custom panels for your Blocks widgets, such as Settings or Layout panels, but it is not possible to build these panels for non-Blocks widgets.

This feature would allow you to leverage the user-friendly panel building abilities in Blocks to build custom panels for widgets that were not built in Blocks, such as self-hosted widgets and CLI.

We are always working to update and improve our products, and your feedback is greatly appreciated.
