---
title: "Wix Blocks Request: Adding a Custom Curser"
---

Currently in Blocks, it is not possible to [customize the cursor style](https://support.wix.com/en/article/studio-editor-adding-a-custom-cursor), by uploading an image of your choice. This means you are limited to the default cursor options provided by the system.
