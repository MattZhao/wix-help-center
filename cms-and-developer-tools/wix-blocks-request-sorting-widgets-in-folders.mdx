---
title: "Wix Blocks Request: Sorting Widgets in Folders"
---

Currently, it is not possible to sort and organize widgets in folders within Wix Blocks. This means that you have to scroll through all available widgets in a single list, which can be time-consuming and cumbersome, especially when working on complex projects with numerous widgets.
