---
title: "Wix Blocks Request: Exporting a Component Built on the Editor to Blocks"
---

Currently, it is not possible to build a component in one of the editors, and then export it to Wix Blocks. Instead, you must rebuild the component in Blocks.

We are always working to update and improve our products and your feedback is greatly appreciated.
