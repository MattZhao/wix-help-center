---
title: "CMS Request: Adding a Field Type for Color to Collections"
---

Currently, there isn't a field type in CMS (Content Management System) collections for color values. With a field type for color, a user could link the color value they add to the field using the **Connect to CMS **icon  in your editor. This means they could apply it to the color value of elements such as a piece of text or a border.

For example, this would make it possible for each dynamic item within a repeater to have its own color background and border.

We are always working to update and improve our products, and your feedback is greatly appreciated.
