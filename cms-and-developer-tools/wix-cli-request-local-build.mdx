---
title: "Wix CLI Request: Local Build"
---

Currently, when using the [Wix CLI](https://dev.wix.com/docs/develop-websites/articles/workspace-tools/developer-tools/git-integration-wix-cli/working-with-the-wix-cli) to develop a site, you need to open an editor in order to test your code.

This feature would allow you to run a local build for development and testing purposes using the Wix CLI.

We are always working to update and improve our products, and your feedback is greatly appreciated.
