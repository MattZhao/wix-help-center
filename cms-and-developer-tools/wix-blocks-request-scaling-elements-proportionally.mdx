---
title: "Wix Blocks Request: Scaling Elements Proportionally"
---

Currently, in [Wix Blocks](https://support.wix.com/en/article/blocks-unboxed-a-quick-tour), it is not possible to set elements to scale proportionally when being resized for different screen sizes.

This feature, which is [available in Wix Studio,](https://support.wix.com/en/article/studio-editor-setting-the-size-of-your-elements) would ensure that an element's proportions (width and height) maintain the same aspect ratio on all screen sizes.

We are always working to update and improve our products, and your feedback is greatly appreciated.
