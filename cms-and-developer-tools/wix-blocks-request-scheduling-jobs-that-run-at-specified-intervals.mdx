---
title: "Wix Blocks Request: Scheduling jobs that run at specified intervals"
---

Currently in Blocks, there is no option to schedule jobs that run at specified intervals.

The job scheduler feature would allow you to schedule code to run at specified intervals, by creating a job.

We are always working to update and improve our products and your feedback is greatly appreciated.
