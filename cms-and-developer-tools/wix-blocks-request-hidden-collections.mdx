---
title: "Wix Blocks Request: Hidden Collections"
---

Currently in Blocks, it is not possible to keep [CMS database collections](https://support.wix.com/en/article/wix-blocks-about-collections) you created as hidden from a site builder who installed your app.

This feature would allow you to create private collections, which could be used by your app code and logic, but would be hidden from whoever installed the app.
