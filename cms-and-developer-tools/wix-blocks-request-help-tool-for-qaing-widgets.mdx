---
title: "Wix Blocks Request: Help Tool for QAing Widgets"
---

Currently in Wix Blocks, there is no dedicated tool to help you efficiently check (QA) widgets. This can make it difficult to ensure that all key areas of your widgets are functioning as expected.

This feature would provide a help tool that guides you to essential areas to check, such as responsive behavior, dynamic text, show/hide elements, panel connections, and theme wiring.

We are always working to update and improve our products, and your feedback is greatly appreciated.
