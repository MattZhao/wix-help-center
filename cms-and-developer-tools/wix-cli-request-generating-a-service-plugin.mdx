title: "Wix CLI Request: Generating a Service Plugin"
---

We're excited to announce that you can now use the [Wix CLI](https://dev.wix.com/docs/build-apps/develop-your-app/frameworks/wix-cli/about-the-wix-cli-for-apps) to generate a service plugin extension when building an app. Learn how to [add service plugin extensions with the CLI](https://dev.wix.com/docs/build-apps/develop-your-app/frameworks/wix-cli/supported-extensions/backend-extensions/service-plugins/add-service-plugin-extensions-with-the-cli).
