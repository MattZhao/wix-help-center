---
title: "CMS Request: Using the Selection Tags Element to Only Display Plain Text"
---

Currently, it is not possible to use the [Selection Tags input element](https://support.wix.com/en/article/cms-adding-and-setting-up-selection-tags) to display plain text without any functionality. You can use the Selection Tags element to let visitors click to filter content or click to submit selections to your collection.

> **Workaround:**
>
> You can [connect text elements](https://support.wix.com/en/article/cms-formerly-content-manager-connecting-text-elements-to-collection-fields) to the Tags field type to show the tags as plain text without any clickable functionality.

We are always working to update and improve our products, and your feedback is greatly appreciated.
