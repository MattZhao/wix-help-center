title: "Wix Blocks Request: Make Velo Service Plugins (SPIs) Available in Blocks"
---

Currently, it is not possible to use [Velo Service Plugins](https://dev.wix.com/docs/velo/articles/api-overview/service-plugins-spis) (SPIs) within Wix Blocks.
