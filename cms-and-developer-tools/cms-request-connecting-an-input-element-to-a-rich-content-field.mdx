---
title: "CMS Request: Connecting an Input Element to a Rich Content Field"
---

Currently, it is not possible to connect an input element, such as text input or a text box, to a rich content field in a collection. This would allow visitor submissions to be stored as rich content.

We are always working to update and improve our products, and your feedback is hugely appreciated.
