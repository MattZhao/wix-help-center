### Tell me more about QR codes

A QR (Quick Response) code is a type of barcode. It holds information that can be read by a QR code scanner, usually a smartphone camera or app, and can be shared online or printed.
QR codes boast many benefits. They can streamline an ordering process by sending users directly to menus, offer a fast and easy way to connect to WiFi, and even generate leads by sending users to a sign-up form.

### Creating a QR code

Create your QR code by choosing the type of content you wish to direct your visitors to. This could be text, a link or an image, for example. You can can then select the size and color of your QR code.

#### To create a QR code:

[Go to the QR Code Generator](https://www.wix.com/tools/qr-code-generator).  Click **Create QR Code**.  Select the content type you want your QR code to direct your users to: **Text**, **URL**, **Image**, **Email**, **PDF**,** **and more.  Enter / upload the relevant details / content.

Customize your QR code using the following options:

- **Select Size: **Drag the slider to increase or decrease the final size of your QR Code. You can create a code of maximum size 1000 x 1000 px, and minimum size 100 x 100 px.
- **Colors: **Choose the background and dots colors of your QR code.

Click **Download.**  Select the file type you want to download your QR code as: **PNG**, **SVG**, or **JPEG**.

### Will my QR code ever expire?

No. QR codes never expire. The only time your code might ‘expire’ is when the destination URL is changed or deleted. Downloaded QR codes are static images and it is not possible for them to change once downloaded.

### Is there a scan limit for QR codes?

No. There is no limit to how many times your QR code can be scanned.

### Can I track how many times a QR code was scanned?

It is not currently possible to track how many times a code was scanned / clicked.
