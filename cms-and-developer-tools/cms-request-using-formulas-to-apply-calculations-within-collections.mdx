---
title: "CMS Request: Using Formulas to Apply Calculations within Collections"
---

We are excited to announce that you can now create formulas to calculate values from CMS (Content Management System) collection fields. With expressions, you can use mathematical functions to perform calculations based on different Number field types and/or static numbers. Learn more about [applying calculations with expressions](https://support.wix.com/en/article/cms-using-cms-expressions-to-manipulate-text-strings#mathematical-functions-1).
