---
title: "Wix Blocks Request: Creating Dashboard Plugins"
---

Currently in Wix Blocks, you can create [plugins](https://dev.wix.com/docs/build-apps/develop-your-app/frameworks/wix-blocks/site-plugins/about-site-plugins-in-blocks) that integrate directly into Wix business solution apps, such as Stores or Bookings. However, you cannot create plugins for the dashboards of these apps.

This feature would introduce the ability to extend the functionality of Wix apps' dashboards. By integrating these plugins, app builders could build dashboard extensions that have much more visibility for users who are already using Wix apps.

We are always working to update and improve our products, and your feedback is greatly appreciated.
