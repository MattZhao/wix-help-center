---
title: "Wix Blocks Request: Installing an App Widget on a Specific Site Page"
---

Currently in Wix Blocks, it is not possible in the Installation Settings of an app to select the option to install a widget on a specific site page.

We are always working to update and improve our products and your feedback is greatly appreciated.
