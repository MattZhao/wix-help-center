---
title: "CMS Request: Adding Checkboxes to Dropdown Input Element Choices"
---

Currently, in dropdown input elements, it is not possible to show checkboxes that visitors can click to select multiple options. This feature would allow visitors to choose multiple selections from a single dropdown input element.

We are always working to update and improve our products, and your feedback is greatly appreciated.
