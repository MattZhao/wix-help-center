---
title: "Wix Blocks Request: Multi-Line Text Input Panel Element"
---

Currently in Blocks, it's not possible to add a multi-line text input as a Blocks [custom panel element](https://support.wix.com/en/article/wix-blocks-velo-api-reference-for-panel-elements). This limits text inputs to a single line.
