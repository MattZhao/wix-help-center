---
title: "CMS: Adding Default Values to Fields in Your Collections"
---

Add default values to collection fields that automatically get added to the fields when you add a new item. Later, if needed, you can edit the field values to change them from their default values. This is a great way to streamline content creation, ensure consistency and reduce errors in your CMS (Content Management System).

> **Important:**
>
> Default field values are not applied to items added via [input elements](https://support.wix.com/en/article/cms-about-user-input-elements) or the [Wix app](https://support.wix.com/en/article/cms-managing-your-collections-from-the-wix-owner-app). The default fields only apply to items that you or site collaborators add within your CMS collections from desktop computers.

### To add a default value:

Go to [CMS](https://www.wix.com/my-account/site-selector/?buttonText=Go%20to%20CMS&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https://www.wix.com/dashboard/%7B%7BmetaSiteId%7D%7D/database/) in your site's dashboard. Alternatively, you can click **CMS ** in your editor.  Click the relevant collection.   Click **Manage Fields**.  Click the field you want to add a default value to.   Click the **Default value **tab.  Enter the default value you want to use for the field.   Click **Save**.
