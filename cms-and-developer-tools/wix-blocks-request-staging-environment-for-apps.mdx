---
title: "Wix Blocks Request: Staging Environment for Apps"
---

Currently in Wix Blocks, it is not possible to view or make changes to your app in a staging environment. However, you can [preview and test a widget](https://support.wix.com/en/article/wix-blocks-a-blocks-app-workflow#preview-and-test-your-widget) in an app before publishing it.

This feature would allow you to create and test apps in a staging environment before transferring them to a production environment.

We are always working to update and improve our products and your feedback is greatly appreciated.
