---
title: "CMS Request: Dynamic Text Input Option for Custom Forms"
---

Currently, it is not possible to let your visitors add extra text input fields to a custom form on your site.

You can [create a custom form](https://support.wix.com/en/article/cms-creating-a-custom-form-with-input-elements-that-submit-to-your-collection) on your page with user input elements that include text boxes, radio buttons, upload buttons, and text input. However, this form only displays the input elements you add to the page. It is not possible for your visitors to add extra fields if they need them, e.g. for adding additional instructions that are not covered by the form.

We are always working to update and improve our products, and your feedback is greatly appreciated.
