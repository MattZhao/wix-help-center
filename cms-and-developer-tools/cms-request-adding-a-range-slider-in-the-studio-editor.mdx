---
title: "CMS Request: Adding a Range Slider in the Studio Editor"
---

Currently, in the Studio Editor, it is not possible to add a Range Slider input element. This would allow you to create a slider that visitors drag to filter items that have a Number field value within a specified range. As a result, only items with a Number field value within the selected range would appear in the connected repeater, gallery, or table.

We are always working to update and improve our products, and your feedback is greatly appreciated.
