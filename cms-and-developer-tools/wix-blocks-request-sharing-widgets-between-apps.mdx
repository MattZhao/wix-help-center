---
title: "Wix Blocks Request: Sharing Widgets Between Apps"
---

Currently in Wix Blocks, it is not possible to share a widget between apps in a way that updates the widget across all apps when it is updated in one place. This means that you have to manually update a widget in each app individually.

This feature would allow you to share a widget between apps and ensure that any changes made to a widget in one app automatically update for all apps that use the same shared widget.

We are always working to update and improve our products and your feedback is greatly appreciated.
