title: "Wix Blocks Request: Creating an App with AI"
---

Currently, it is not possible to use AI to create an app on Blocks. This feature would allow you to use AI tools to define, build and configure a Blocks app.

We are always working to update and improve our products, and your feedback is hugely appreciated.
