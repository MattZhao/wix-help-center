---
title: "Wix Blocks Request: Ability to Code Locally Using a CLI"
---

Wix currently does not support the ability to code locally using a Command Line Interface (CLI) in Wix Blocks. This feature would allow you to develop and test your code within the Wix editors and would benefit you by providing a more efficient workflow, enabling quicker debugging and testing cycles to create new versions of your apps.

We are always working to update and improve our products and your feedback is greatly appreciated.
