---
title: "Wix Blocks Request: Move an App Between Studio Workspaces"
---

Currently in Blocks, you can't move your app between different [Wix Studio workspaces](https://support.wix.com/en/article/wix-studio-a-tour-of-the-workspace). This means that if you created an app in one workspace and worked on it, it will remain in that workspace.

This feature would allow more flexibility across Wix Studio workspaces.
