---
title: "Wix Blocks Request: Building Using Horizontal Stacks"
---

Currently, in [Wix Blocks](https://support.wix.com/en/article/blocks-unboxed-a-quick-tour), it is not possible to group several components together in a horizontal arrangement or stack. This feature would allow you to align elements side-by-side in a single row, making it easier to create organized and visually appealing layouts.

We are always working to update and improve our products, and your feedback is greatly appreciated.
