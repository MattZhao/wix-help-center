---
title: "Wix Blocks Request: Converting Widgets to Plugins"
---

Currently in Wix Blocks, it is not possible to directly convert an existing widget into a plugin. This means that users must recreate plugins from scratch.

This feature would allow users to convert an existing widget into a plugin without needing to completely rebuild it as a plugin.

We are always working to update and improve our products and your feedback is greatly appreciated.
