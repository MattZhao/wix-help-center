---
title: "CMS Request: Connecting Section Backgrounds in the Studio Editor to the CMS"
---

We're excited to announce that it is now possible to connect section backgrounds to the CMS (Content Management System) in the Studio Editor. This allows you to manage the images that appear as section backgrounds in your CMS collections.
