---
title: "Wix HTTP Functions Request: Customizing the Endpoint URL"
---

Currently, when exposing API endpoints using [HTTP functions](https://dev.wix.com/docs/develop-websites/articles/coding-with-velo/integrations/exposing-services/expose-a-site-api-with-http-functions), you cannot customize the endpoint URL. All endpoints must start with the **_functions** prefix.

This feature would allow you to change the prefix for endpoints exposed through http functions. For example, you could change the prefix to **_api**, resulting in an endpoint URL similar to *https://www.your-domain.com/_api/functionName*.

We are always working to update and improve our products, and your feedback is greatly appreciated.
