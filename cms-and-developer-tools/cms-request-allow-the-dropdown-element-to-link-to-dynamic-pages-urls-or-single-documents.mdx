---
title: "CMS Request: Allow the Dropdown Element to Link to Dynamic Pages, URLs, or Single Documents"
---

Currently, it is not possible to link the dropdown input element to dynamic pages, documents, or URLs. This feature would allow visitors to click a dropdown and select a dynamic page, document, or URL. Upon selecting they would navigate to the dynamic page or URL, or download the document.

We are always working to update and improve our products, and your feedback is greatly appreciated.
