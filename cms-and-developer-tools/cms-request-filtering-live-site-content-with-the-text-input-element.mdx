---
title: "CMS Request: Filtering Live Site Content with the Text Input Element"
---

Currently, it is not possible for visitors to use the [Text Input element](https://support.wix.com/en/article/cms-adding-and-setting-up-a-text-input) to filter live site content. The Text Input element can be used to collect content only.

> **Workaround:**
>
> You can [add the Wix Site Search app](https://support.wix.com/en/article/adding-and-setting-up-wix-site-search-7353315) to allow visitors to search throughout your site's content.

We are always working to update and improve our products, and your feedback is greatly appreciated.
