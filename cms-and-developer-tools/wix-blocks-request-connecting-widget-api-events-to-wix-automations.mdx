---
title: "Wix Blocks Request: Connecting Widget API Events to Wix-Automations"
---

Currently in Blocks, it’s not possible to connect [widget API events](https://dev.wix.com/docs/build-apps/wix-blocks/code-in-blocks/widget-api-events) to [Wix-Automations](https://dev.wix.com/docs/build-apps/build-your-app/automations/automation-triggers), so that an event in your app triggers an automation.
