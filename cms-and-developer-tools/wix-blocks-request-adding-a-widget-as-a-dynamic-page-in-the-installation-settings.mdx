---
title: "Wix Blocks Request: Adding a Widget as a Dynamic Page in the Installation Settings"
---

Currently in a Blocks app [installation settings](https://support.wix.com/en/article/wix-blocks-app-and-widget-installation-settings), you can define that a certain widget is added to a site [as a new page](https://support.wix.com/en/article/wix-blocks-app-and-widget-installation-settings#added-as-a-new-page). However, you cannot add a widget to a site as a [dynamic page](https://support.wix.com/en/article/cms-about-dynamic-pages).
