---
title: "CMS Request: Adding the Rich Content Element to a Repeater"
---

We are excited to announce that you can now add the Rich Content viewer element to repeaters to display content for multiple items at a time. If you have an older Rich Content element on your site, make sure to add a new one so you get the updated version that allows you to attach to repeaters.
