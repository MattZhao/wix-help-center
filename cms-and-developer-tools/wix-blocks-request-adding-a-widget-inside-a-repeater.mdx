---
title: "Wix Blocks Request: Adding a Widget Inside a Repeater"
---

Currently in Wix Blocks, it is not possible to add and use widgets inside repeaters when building an app in the Blocks editor.

This feature would allow you to build complex and reusable compositions. For example, if creating a Team Members widget, you could make a 'Single Member' widget and then add it inside a repeater to build out the full component.

However, you can add one widget inside another in the Blocks editor for reusability (e.g. create one 'button' widget and then use it inside other widgets in your app). [Learn how to create a widget within a widget.](https://support.wix.com/en/article/wix-blocks-creating-and-managing-widgets-within-widgets)

We are always working to update and improve our products, and your feedback is greatly appreciated.
