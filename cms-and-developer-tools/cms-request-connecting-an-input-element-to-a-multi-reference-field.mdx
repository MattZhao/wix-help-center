---
title: "CMS Request: Connecting an Input Element to a Multi-Reference Field"
---

Currently, it is not possible to connect an input element, such as a drop-down or radio buttons, to a [Multi-Reference field](https://support.wix.com/en/article/cms-creating-multi-reference-fields) in a collection.

We are always working to update and improve our products, and your feedback is hugely appreciated.
