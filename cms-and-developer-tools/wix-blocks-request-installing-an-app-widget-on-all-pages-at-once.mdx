---
title: "Wix Blocks Request: Installing an App Widget on all Pages at Once"
---

Currently in Wix Blocks, it is not possible in the Installation Settings of an app to select the option to install a widget on all site pages.

We are always working to update and improve our products and your feedback is greatly appreciated.
