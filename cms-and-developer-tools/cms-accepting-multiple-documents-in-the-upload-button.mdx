---
title: "CMS: Accepting Multiple Documents in the Upload Button"
---

You can set your [upload button](https://support.wix.com/en/article/cms-adding-and-setting-up-an-upload-button) to allow visitors to submit multiple document files at a time. After selecting **Document **as your **Supported file type** in the upload button settings, connect the button to a 'Multi-document' or 'Media gallery' field type in your CMS collection. This is useful for collecting various files such as applications, assignments, or any other document-related submissions.

### How do I connect to a 'Multi-document' field type?

1. Select **Document **from the **Supported file type** drop-down in the upload button settings.
2. Drag the **Max number of files** slider to set the limit on how many files can be uploaded per submission.
3. Click the **Connect to CMS **icon   on your upload button.
4. Click the **Choose a dataset** drop-down and select an existing dataset that connects to the collection you will store submissions in. Alternatively, select **Add a Dataset**, then choose the collection you want to store submissions in.
5. Add a 'Multi-document' field to your collection where you will store the upload button submissions:

**Tip: **Alternatively, you can connect to an existing 'Multi-document' collection field. 

1. Click the **File connects to** drop-down and select **Add new field**.
2. Enter a **Field Name **for the new collection field.
3. Click the **Field Type **drop-down and select **Multi-Document**.
4. Click **Add**.

### Can visitors submit multiple images or videos with the upload button?

Yes. Make sure to choose** Image & Video** as the supported file type in the button settings. Then connect the button to a 'Media gallery' field type in your collection. 

1. In the upload button settings, select **Image & Video **from the **Supported file type **drop-down.
2. Drag the **Max number of files** slider to set the limit on how many files can be uploaded per submission.
3. Connect the button to a 'Media Gallery' field in your collection: 

1. Click the **Connect to CMS **icon  on your upload button.
2. Click the **Choose a dataset** drop-down and select an existing dataset that connects to the collection you will store submissions in. Alternatively, select **Add a Dataset**, then choose the collection you want to store submissions in.
3. Add a 'Media gallery' field to your collection where you will store the upload button submissions:

**Tip: **Alternatively, you can connect to an existing 'Media gallery' collection field. 

1. Click the **File connects to** drop-down and select **Add new field**.
2. Enter a **Field Name **for the new collection field.
3. Click the **Field Type **drop-down and select **Media Gallery**.
4. Click **Add**.

### Do I need a 'Submit' button to allow visitors to submit their uploaded files?

Yes. Without a 'Submit' button, visitors can still upload the files, but they won't have a way to submit them to your collection. 
**To add a 'Submit' button: **
1. Add a regular button in your editor and change the text to 'Submit'.
2. [Connect the button to the same dataset](https://support.wix.com/en/article/cms-connecting-a-button-to-a-dataset) that connects to your upload button.
3. Set the **Click action connects to **field to **Submit**.

Learn more about [creating a 'Submit' button](https://support.wix.com/en/article/cms-creating-a-custom-form-with-input-elements-that-submit-to-your-collection#step-5-create-a-submit-button) for the input elements that make up your custom form.
