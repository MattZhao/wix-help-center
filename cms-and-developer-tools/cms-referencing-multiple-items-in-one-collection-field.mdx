---
title: "CMS: Referencing Multiple Items in One Collection Field"
---

A reference field creates a connection between an item in one collection and an item in a different collection. A multiple items reference field is similar to a reference field, except it allows you to reference more than one item from another Collection.

Multiple item reference fields create a two-way connection between collections. This means that when you create a multiple-item reference field in collection A that points to collection B, a corresponding multiple-item reference field is automatically created in collection B that points to collection A.

> For an overview of this process, check out our [Ultimate CMS Guide video](https://youtu.be/S2AgB6wGnk4?t=1355&si=CDz-ngbN9vlcQ-un).

### To create a multi-reference field:

Go to [CMS](https://www.wix.com/my-account/site-selector/?buttonText=Open%20Content%20Manager&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https://www.wix.com/dashboard/%7B%7BmetaSiteId%7D%7D/database/) in your site's dashboard.  Click the relevant collection.  Click the **Add** icon  to create a new field.  Select **Reference** or** Multi-Reference** as the Field Type.  Enter a **Field Name**.   Select which collection you want to reference to under **Referenced Collection**.  Click **Save**.

> **Tip:**
>
> After setting up your multiple items reference field, learn how to [display content from multiple content collections using reference fields](https://support.wix.com/en/article/cms-using-reference-fields-to-display-content-from-multiple-collections).
