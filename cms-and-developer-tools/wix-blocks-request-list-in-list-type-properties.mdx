---
title: "Wix Blocks Request: List in List Type Properties"
---

Currently in Blocks, you can add a [list type property](https://dev.wix.com/docs/build-an-app/develop-your-app/frameworks/wix-blocks/blocks-widget-api/creating-and-managing-list-type-properties-in-widget-api) to the [widget API](https://dev.wix.com/docs/build-an-app/develop-your-app/frameworks/wix-blocks/blocks-widget-api/about-the-widget-api). However, it is not possible to add a "list in list", or nested list, type of property.
