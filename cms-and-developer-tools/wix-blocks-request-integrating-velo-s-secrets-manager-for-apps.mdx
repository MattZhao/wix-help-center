---
title: "Wix Blocks Request: Integrating Velo's Secrets Manager for Apps"
---

Currently in Blocks, you cannot integrate Velo's Secrets Manager in your applications.

This serverless Secrets Manager feature, would allow to create, store and manage secrets such as API keys. The value of each secret would be safely stored and encrypted in the Secrets Manager. Only app collaborators would be able access it, and the name for each secret can be used in the app's code.

We are always working to update and improve our products and your feedback is greatly appreciated.
