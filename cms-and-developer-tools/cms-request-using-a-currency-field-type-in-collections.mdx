---
title: "CMS Request: Using a Currency Field Type in Collections"
---

Currently, CMS (Content Management System) collections do not have a currency field type you could use to display numbers with a currency prefix/suffix on your site.

> **Workaround:**
>
> With expressions, you can [use the TEXT function to apply currency formatting to numbers](https://support.wix.com/en/article/cms-using-cms-expressions-to-manipulate-text-strings#number-formatting-with-the-text-function). For example, you could use the TEXT function with a pattern format to convert a Number field into a currency format (e.g. $1,234.57).

We are always working to update and improve our products, and your feedback is greatly appreciated.
