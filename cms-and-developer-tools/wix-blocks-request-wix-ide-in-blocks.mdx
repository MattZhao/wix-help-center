---
title: "Wix Blocks Request: Wix IDE in Blocks"
---

Currently, it is not possible to use the [Wix IDE](https://dev.wix.com/docs/develop-websites/articles/workspace-tools/velo-workspace/wix-ide/wix-studio-about-the-wix-ide) in Blocks

This feature would allow you to develop in a browser-based environment built on Visual Studio Code and to code in concurrent mode.

We are always working to update and improve our products and your feedback is greatly appreciated.
