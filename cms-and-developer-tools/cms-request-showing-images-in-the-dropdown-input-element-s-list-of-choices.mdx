---
title: "CMS Request: Showing Images in the Dropdown Input Element's List of Choices"
---

Currently, in dropdown input elements, it is not possible to include images in the list of choices. This feature would allow visitors to see a thumbnail image next to each option they select from within the dropdown list.

We are always working to update and improve our products, and your feedback is greatly appreciated.
