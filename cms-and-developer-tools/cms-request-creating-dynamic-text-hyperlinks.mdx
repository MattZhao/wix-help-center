---
title: "CMS Request: Creating Dynamic Text Hyperlinks"
---

Currently, it is not possible to create text hyperlinks by linking characters in text elements to URL fields in CMS collections. If you connect a text element to a URL field, the text displays the URL itself rather than linking to the URL.

> **Workaround:**
>
> You can [connect buttons to URL fields in collections](https://support.wix.com/en/article/cms-connecting-a-button-to-a-dataset) to create dynamic links.

We are always working to update and improve our products, and your feedback is greatly appreciated.
