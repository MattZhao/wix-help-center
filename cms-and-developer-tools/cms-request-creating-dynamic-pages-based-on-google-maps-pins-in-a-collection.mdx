---
title: "CMS Request: Creating Dynamic Pages Based on Google Maps Pins in a Collection"
---

Currently, you cannot create a [dynamic page](https://support.wix.com/en/article/cms-about-dynamic-pages) that links to a field containing a Google Maps pin.

However, you can create dynamic pages based on Text and Number field types in a collection. For example, the dynamic page below displays the title, address and a map of each item in a collection. The page is linked to the 'Location Name' field to select which item to display.

### Tell me more

- The collection has a field called 'Location Name'.
- The dynamic page settings link to this field.
- A button is linked to the dynamic page, and lets you link to an item in the collection.

You can create a different button for each item, so you can display each of the items in the collection using the same page.

We are always working to update and improve our products, and your feedback is hugely appreciated.
