---
title: "CMS: Converting an Existing Page to a Dynamic Page"
---

A [dynamic page](https://support.wix.com/en/article/cms-about-dynamic-pages) in the Wix CMS (Content Management System) allows you to display unique content from your CMS collection on a single page layout. This can save you time and effort, especially if you have a lot of similar content to manage. For example, if you run a real estate website, you can create a dynamic page to showcase individual property listings, pulling information directly from your CMS collection without having to design a separate page for each property.

> For an overview of this process, check out our [Ultimate CMS Guide video](https://youtu.be/S2AgB6wGnk4?t=227&si=CN4AgYrS-HyZGn35).

### To convert an existing page to a dynamic page:

Wix EditorStudio Editor
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Click **Pages & Menu**on the left side of the editor.
3. Hover over the page you want to convert and click the **More Actions **icon .
4. Select **Convert to dynamic page**.
[image: Screenshot of converting a static page to a dynamic page.]
1. Click **Start Now**.
2. Click to choose whether to save the page content to a new collection or an existing collection:

- **New collection: **Enter a name for the collection. If using Velo, you can edit the collection ID of the new collection.
- **Existing collection: **Select the existing collection where you want to save the page content.
3. Click **Next**.
[image: Screenshot of saving content to a new collection.]
1. (If saving to a new collection) Choose which elements to convert to dynamic and set up the fields that will connect to the dynamic elements:

1. In the panel on the right, select or deselect the elements that you want to convert to dynamic elements.

**Note: **Dynamic elements get their content from your [CMS collection fields](https://support.wix.com/en/article/cms-formerly-content-manager-about-your-collection-fields). If you want an element to remain static, meaning it stays the same on each version of the dynamic page, deselect the element. You can [connect more supported page elements](https://support.wix.com/en/article/cms-formerly-content-manager-elements-and-the-collection-fields-they-can-connect-to) later.
2. Hover over an element in the panel on the right and click the **Edit **icon  to change the name, key (Velo only), or field type that will connect to the element. Click **Save** when you're done and repeat this step for each element.
3. Click **Connect Elements**.
[image: Screenshot of editing a field that will connect to a dynamic element.]
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Click **Pages**  on the left side of the editor.
3. Hover over the page you want to convert and click the **More Actions **icon .
4. Select **Convert to Dynamic Page**.
[image: Screenshot of converting a static page to a dynamic one.]
1. Click **Start Now**.
2. Click to choose whether to save the page content to a new collection or an existing collection:

- **New collection: **Enter a name for the collection. If using Velo, you can edit the collection ID of the new collection.
- **Existing collection: **Select the existing collection where you want to save the page content.
3. Click **Next**.
[image: Screenshot of choosing to save to a new collection.]
1. (If saving to a new collection) Choose which elements to convert to dynamic and set up the fields that will connect to the dynamic elements:

1. In the panel on the right, select or deselect the elements that you want to convert to dynamic elements.

**Note: **Dynamic elements get their content from your [CMS collection fields](https://support.wix.com/en/article/cms-formerly-content-manager-about-your-collection-fields). If you want an element to remain static, meaning it stays the same on each version of the dynamic page, deselect the element. You can [connect more supported page elements](https://support.wix.com/en/article/cms-formerly-content-manager-elements-and-the-collection-fields-they-can-connect-to) later.
2. Hover over an element in the panel on the right and click the **Edit **icon  to change the name, key (Velo only), or field type that will connect to the element. Click **Save** when you're done and repeat this step for each element.
3. Click **Connect Elements**.
