---
title: "CMS: Displaying Your Wix Stores Categories on Any Page"
---

Showcase all your Wix Stores product categories in a gallery, repeater, or table on any page such as your Home or Cart page. When customers click a category, they go to the relevant Category Page where they can view its products. Alternatively, you can [create a new dynamic list page to display your categories](https://support.wix.com/en/article/cms-displaying-your-wix-stores-product-categories-on-a-dynamic-list-page).

> **Important:**
>
> You must have [the new version of Wix Stores product categories](https://support.wix.com/en/article/wix-stores-about-the-category-page) to follow this tutorial. If you don't have it, learn how to [manually create a gallery of categories](https://support.wix.com/en/article/wix-stores-creating-an-index-of-product-categories) with the original version of product categories.

> **Before you begin:**
>
> - Create multiple [product categories](https://support.wix.com/en/article/wix-stores-creating-product-categories) in Wix Stores.
> - Make sure to [add the CMS](https://support.wix.com/en/article/cms-formerly-content-manager-getting-started) to your site if you haven't already.
> - [Enable Wix app collections](https://support.wix.com/en/article/cms-formerly-content-manager-working-with-wix-app-collections) so you can use Wix Stores with the CMS.

### Step 2 | Connect your gallery, repeater or table to the CMS

Connect the collection fields to your repeater, gallery or table. The values from these dynamic fields change on your live site depending on the category shown. Make sure to link the buttons or images to the **Page URL**. This link allows visitors to click to go to the relevant Stores Category Page.

Wix EditorEditor XStudio Editor
1. In your Editor, click the repeater, Pro Gallery, or table.
2. Click the **Connect to CMS** icon  .
3. Click **Create Dataset**. If you already have a dataset on your page, click the **Choose a dataset **drop-down and select **Create a New Dataset**.
4. Click the **Choose a collection **drop-down and select **Collections **under the **Stores **Wix app collection.

1. (Optional) Click the **Dataset name **field and enter a name for the dataset.
2. Click **Create**.
3. (Repeaters only) Under **Connections**, click the repeater element you want to connect (e.g. Text, Button, Image).
4. Under **Connection options**, click the relevant drop-downs and select the dynamic collection fields you want to connect: 

- **Name (Text): **The category name set in Wix Stores.
- **Main Media (Image): **The category image set in Wix Stores.
- **Slug (Text): **The unique part of the URL at the end of your Category Page web address. You can set these by [editing the SEO settings of each Stores category](https://support.wix.com/en/article/wix-stores-seo-for-category-pages).
- **ID (Text): **The unique identifier code in the backend of each category.
- **Navigate Page URL: **The web address of the relevant Category Page. For buttons, click the **Click action connects to **drop-down to select **Navigate Page URL**. For images or the Pro Gallery, click the **Links connect to **drop-down to select **Navigate Page URL**.

1. (Repeaters only) Click **Repeater connections** and repeat steps 7-8 above to connect additional elements in the repeater.
2. Click to adjust your repeater elements, Pro Gallery or table as needed.

**Tip: **You can add or remove elements from your repeater at any time. Disconnect elements if you want to use static content that doesn't change according to the relevant category.
3. Click **Preview** to test the functionality.
4. Click **Publish** if you are ready to make the changes go live.

- **Main Media (Image): **The category image set in Wix Stores.
- **Slug (Text): **The unique part of the URL at the end of your Category Page web address. You can set these by [editing the SEO settings of each Stores category](https://support.wix.com/en/article/wix-stores-seo-for-category-pages).
- **ID (Text): **The unique identifier code in the backend of each category.
- **Page URL: **The web address of the relevant Category Page. For buttons, click the **Click action connects to **drop-down to select the **Page URL**. For images or the Pro Gallery, click the **Links connect to **drop-down to select the **Page URL**.
9. (Repeaters only) Click **Repeater connections** to connect additional elements in the repeater.
10. Click to adjust your repeater elements or Pro Gallery as needed.

**Tip: **You can add or remove elements from your repeater at any time. Disconnect elements if you want to use static content that doesn't change according to the relevant category.
11. Click **Preview** to test the functionality.
12. Click **Publish** if you are ready to make the changes go live.

### (Optional) Step 3 | Manage the dataset settings

In your dataset settings, you can choose the maximum categories that can display at a time. You can add filters to include specific categories or use sorts to control the category order.

> **Note:**
>
> [Tables](https://support.wix.com/en/article/cms-formerly-content-manager-displaying-collection-content-in-a-table) are not affected by these dataset settings. Click **Manage Table** on the table element to manage the fields that appear and their order.

Wix EditorEditor XStudio Editor
1. Go to the dataset settings:

1. Click **CMS **** **on the left.
2. Click **Manage Page Connections**.
3. Click the **More Actions **icon  next to the relevant dataset and select **Dataset settings**.
2. Edit the **Maximum items displayed **field to set the maximum number of categories that can load at a time on the page. This is also the maximum categories that can load per page in a connected [pagination bar](https://support.wix.com/en/article/cms-adding-and-setting-up-a-pagination-bar) or per click in ["Load More" and navigational buttons](https://support.wix.com/en/article/cms-displaying-dynamic-content-in-a-repeater#step-5-optional-create-load-more-or-navigational-buttons).
3. (Optional) Click **+ Add Filter **to [only show specific categories](https://support.wix.com/en/article/cms-formerly-content-manager-adding-filters-and-sorts-to-datasets-to-control-live-site-content#adding-filters-to-your-dataset-to-exclude-items-from-your-page) in the element.
4. (Optional) Click **+ Add Sort **to [choose the order in which the categories appear](https://support.wix.com/en/article/cms-formerly-content-manager-adding-filters-and-sorts-to-datasets-to-control-live-site-content#adding-sort-conditions-to-your-dataset-to-sort-the-items-on-your-page) in the element.

2. Click **Publish** if you are ready to make the changes go live.
