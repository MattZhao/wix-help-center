---
title: "Wix Blocks Request: Adding Velo APIs for Webhook Events"
---

Currently in Wix Blocks, you cannot trigger serverless webhook events in your app without hosting your own server. These events can include app events such as "app installed", "app upgraded" and "app deleted".

This feature would allow you to use Wix serverless APIs to trigger any webhook event.

We are always working to update and improve our products and your feedback is greatly appreciated.
