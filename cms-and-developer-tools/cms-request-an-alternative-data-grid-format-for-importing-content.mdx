---
title: "CMS Request: An Alternative Data Grid Format for Importing Content"
---

Currently, the only option you can use to bulk import content into a collection is to [import your content from a CSV file](https://support.wix.com/en/article/cms-formerly-content-manager-importing-content-into-a-collection).

There is no other built-in data grid or spreadsheet format with more functionality for bulk content import.

We are always working to update and improve our products, and your feedback is greatly appreciated.
