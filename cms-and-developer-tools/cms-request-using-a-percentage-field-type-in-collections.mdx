---
title: "CMS Request: Using a Percentage Field Type in Collections"
---

Currently, CMS (Content Management System) collections do not have a percentage field type you could use to display numbers as percentages on your site.

> **Workaround:**
>
> With expressions, you can [use the TEXT function to apply a percentage format to numbers](https://support.wix.com/en/article/cms-using-cms-expressions-to-manipulate-text-strings#number-formatting-with-the-text-function). For example, you could use the TEXT function with a pattern format to convert a Number field into a percentage (e.g. 3.14%).

We are always working to update and improve our products, and your feedback is greatly appreciated.
