---
title: "Wix Blocks Request: Adding an Upload Button to a Custom Panel"
---

Currently in Blocks, it’s not possible to add an [upload button](https://support.wix.com/en/article/cms-adding-and-setting-up-an-upload-button) element to [custom panels](https://support.wix.com/en/article/wix-blocks-designing-custom-panels-for-your-widgets-action-bar-buttons) in your app. This element would allow site builders to upload their own files right from the app’s custom panel.
