---
title: "CMS Request: Mobile Layout Options for the Table Element"
---

Currently, the [table element](https://support.wix.com/en/article/cms-formerly-content-manager-displaying-collection-content-in-a-table) has the same layout options on [mobile](https://support.wix.com/en/article/wix-editor-about-the-mobile-editor) and across [breakpoints](https://support.wix.com/en/article/studio-editor-designing-across-breakpoints) as it does on desktop. This can be problematic for viewing tables that have many rows and columns on smaller screens. It is not possible to use more flexible layout options specifically for viewing tables on mobile devices and different breakpoints.

> **Workaround:**
>
> Instead of using a table to display your CMS content, you could use a [repeater](https://support.wix.com/en/article/cms-displaying-dynamic-content-in-a-repeater) or [gallery](https://support.wix.com/en/article/cms-displaying-collection-content-in-a-pro-gallery).

We are always working to update and improve our products, and your feedback is hugely appreciated.
