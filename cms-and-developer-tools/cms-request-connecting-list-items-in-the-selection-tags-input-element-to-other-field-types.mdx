---
title: "CMS Request: Connecting List Items in the Selection Tags Input Element to Other Field Types"
---

Currently, when using the [Selection Tags input element](https://support.wix.com/en/article/cms-adding-and-setting-up-selection-tags) to **collect content**, you can toggle **Connect list items** to use values from your CMS collection as the choices visitors select. You can only connect these choices to Text and Number field types. You cannot connect these choices to other field types such as the Tags field type.

When using the Selection Tags input element to **filter content**, you can connect to the Tags field type. This allows visitors to click a tag to view only items that have the selected tag in the dataset's connected elements.

We are always working to update and improve our products, and your feedback is greatly appreciated.
