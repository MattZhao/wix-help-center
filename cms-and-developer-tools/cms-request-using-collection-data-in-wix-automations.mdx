---
title: "CMS Request: Using Collection Data in Wix Automations"
---

Currently, it is not possible to use CMS (Content Management System) collection data in Wix Automations. This feature would allow you to automate many new processes based upon the data in your CMS collections.

We are always working to update and improve our products, and your feedback is greatly appreciated.
