---
title: "CMS Request: Connecting an Address Field to a Table"
---

Currently, you can't connect an address field in a collection to the table element.

However, you can use a text field in a collection to store an address, but it is only saved as text. This is not the same as an address field, that contains location information you can link to and display on a map.

We are always working to update and improve our products, and your feedback is greatly appreciated.
