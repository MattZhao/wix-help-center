---
title: "Wix Blocks Request: Add Unique IDs for Widget Instances"
---

Currently, when you install a blocks app on a site and add a widget to the canvas more than once, all instances of that widget will have the same **instanceId**. The **instanceId **is a property in the object returned by the [getDecodedAppInstance()](https://dev.wix.com/docs/velo/api-reference/wix-application/get-decoded-app-instance) in the [wix-application](https://dev.wix.com/docs/velo/api-reference/wix-application/introduction) module.
