---
title: "CMS: About Page Link Collection Fields for Dynamic Pages"
---

When you create dynamic pages, the system adds Page Link fields in your collection. These Page Link fields create the web addresses used by the dynamic pages.

> **Tip:**
>
> Go to your editor's page settings to [add variables to your dynamic page URLs](https://support.wix.com/en/article/cms-creating-unique-dynamic-page-urls#adding-variables-to-dynamic-page-url-slug-structures). Variables can be static text or dynamic field values that vary depending on the relevant item's field value. Editing the URL values in your editor automatically updates the Page Link fields in your collection.

Primary fields are super important because they are used in the dynamic item page URL. Make sure to add unique content to the Primary field for each item that you wish to have a dynamic item page. Without content in the Primary field, a dynamic item page URL cannot be created for the item.

> Learn more about the importance of [creating unique dynamic page URLs](https://support.wix.com/en/article/cms-creating-unique-dynamic-page-urls).
