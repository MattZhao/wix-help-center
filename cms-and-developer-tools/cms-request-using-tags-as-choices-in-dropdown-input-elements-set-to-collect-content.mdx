---
title: "CMS Request: Using Tags as Choices in Dropdown Input Elements Set to Collect Content"
---

Currently, when [using the dropdown input element to collect content](https://support.wix.com/en/article/cms-setting-up-a-custom-form-using-dropdown-input-elements), it is not possible to use the tags field type as choices. However, you can use the tags field type when using the dropdown input element to [filter the content  that displays](https://support.wix.com/en/article/cms-formerly-content-manager-setting-up-filters-for-site-visitors-using-input-elements).

We are always working to update and improve our products, and your feedback is greatly appreciated.
