---
title: "Wix Blocks Request: Adding a Tabs Element to a Panel"
---

Currently in Wix Blocks, it is not possible to navigate between different states in a [custom panel](https://dev.wix.com/docs/build-apps/develop-your-app/frameworks/wix-blocks/editor-experience/design-custom-panels-in-blocks) using tabs.

This feature would allow you to add a tabs panel element, enabling you to organize, and users to navigate, between different states or sections.

We are always working to update and improve our products and your feedback is greatly appreciated.
