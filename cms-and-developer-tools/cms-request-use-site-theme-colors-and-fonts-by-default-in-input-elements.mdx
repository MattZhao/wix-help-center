---
title: "CMS Request: Use Site Theme Colors and Fonts by Default in Input Elements"
---

When you add [input elements](https://support.wix.com/en/article/cms-about-user-input-elements), they use preset styles that do not automatically correspond to your site's color and font themes. Currently, it is not possible to add input elements that use your site's color and font themes by default. You can, however, manually adjust the font and colors of input elements in their design settings.

We are always working to update and improve our products, and your feedback is greatly appreciated.
