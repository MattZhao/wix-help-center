---
title: "Wix Blocks Request: Adding more characters to Widget API properties"
---

Currently, in Wix Blocks, widget API properties can only contain up to 2,000 characters.

This feature would allow you to have text properties that are longer than 2,000 characters. For example, if you want to pass a longer JSON file in the properties.

We are always working to update and improve our products and your feedback is greatly appreciated.
