title: "CMS: Connection Options and Supported Collection Fields for Each Element"
---

With the CMS (Content Management System), you can connect various parts of your site's elements to different types of [collection fields](https://support.wix.com/en/article/cms-formerly-content-manager-supported-content-in-collection-field-types). Review the tables in this article to learn which collection field types can connect to each part of your site's elements. Some element connections, such as button click actions, can also connect to [dataset actions](https://support.wix.com/en/article/cms-about-dataset-click-actions-for-buttons-and-images) such as 'Load more' or 'Next item', or to [dynamic pages](https://support.wix.com/en/article/cms-linking-to-dynamic-pages).

**In this article, learn about:**

[CMS connection options for each element](https://support.wix.com/en/article/cms-formerly-content-manager-elements-and-the-collection-fields-they-can-connect-to#cms-connection-options-for-each-element)  [User input elements and their connection fields](https://support.wix.com/en/article/cms-formerly-content-manager-elements-and-the-collection-fields-they-can-connect-to#user-input-elements-and-their-connection-fields)

### User input elements and their connection fields

The CMS works with a variety of user input elements that let you capture, store, display, and edit visitor content in a collection. Using these elements, you can [create your own forms](https://support.wix.com/en/article/cms-creating-a-custom-form-with-input-elements-that-submit-to-your-collection) or [allow visitors to filter the content](https://support.wix.com/en/article/cms-formerly-content-manager-setting-up-filters-for-site-visitors-using-input-elements) on your site.
