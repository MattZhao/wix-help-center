---
title: "CMS Request: Create Multiple Layouts for a Single Dynamic Page"
---

Currently, it is not possible to create multiple layouts for a single dynamic page and choose which layout to apply to each CMS collection item.

We are always working to update and improve our products, and your feedback is greatly appreciated.
