---
title: "Wix Blocks Request: Allow Different Grids for Different Presets"
---

Currently in Blocks, it is not possible to use different grids in different [design presets](https://support.wix.com/en/article/wix-blocks-about-design-presets). This means that you are restricted to a single grid layout across all presets, limiting design flexibility and customization options.
