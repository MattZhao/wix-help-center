### Customizing your view

Customize your view in a report to focus on the data that matters most to you. You can change a report's time period, add filters, group data, and more, depending on what type of view you chose.

> **Note:**
>
> Some views limit the amount of data shown and how far back it goes. If you can't get to the data you need, switch to a different view.

### Comparing report periods

Compare report data from different periods to discover how your business has performed in different time periods. For example, when you access your Sales Over Time report, you can check how your online store did this year compared to last year.

#### To compare report periods:

DashboardWix appWix Studio app
1. [Go to All Reports](https://www.wix.com/my-account/site-selector/?title=Select%20a%20Site&buttonText=Analytics%20Reports&actionUrl=https%3A%2F%2Fmanage.wix.com%2Fdashboard%2F%7B%7BmetaSiteId%7D%7D%2Fanalytics/reports/?referralInfo=sidebar) in your site's dashboard.
2. Select an 'Over Time' report.
3. Select a period under **Compare to**:

- **None**: Is selected by default, only shows the current selected period.
- **Previous period**: Compares the current selected period to the period before. For example, compare this month to the month before it.
- **Last year**: Shows how your data changed this year versus the year before.

### Saving a custom report view

Edit report views to display the fields and filters that work for you, then save that view so you can easily access it again.

> **Note:**
>
> This feature is only available if the report has a **table** view.

#### To save a custom view:

[Go to All Reports](https://www.wix.com/my-account/site-selector/?title=Select%20a%20Site&buttonText=Analytics%20Reports&actionUrl=https%3A%2F%2Fmanage.wix.com%2Fdashboard%2F%7B%7BmetaSiteId%7D%7D%2Fanalytics/reports/?referralInfo=sidebar) in your site's dashboard.  Select the relevant report.  Click the **Table** view at the top.  [Customize your view](https://support.wix.com/en/article/customizing-wix-analytics-reports#customizing-your-view) of the report.  Select **Save as new view **under the **Manage View **drop-down on the right.  Enter a name for this new view.  Click **Save**.

### Managing custom report views

Once you have saved report views, you can manage and edit them. Make changes to a saved view, choose which view is the default view, edit the name of a view, or delete a view.

> **Note:**
>
> This feature is only available if the report has a **table** view.

#### To manage your custom report views:

[Go to All Reports](https://www.wix.com/my-account/site-selector/?title=Select%20a%20Site&buttonText=Analytics%20Reports&actionUrl=https%3A%2F%2Fmanage.wix.com%2Fdashboard%2F%7B%7BmetaSiteId%7D%7D%2Fanalytics/reports/?referralInfo=sidebar) in your site's dashboard.  Select the relevant report.  Click the **Table** view at the top.  Select a saved view from the drop-down.  Click the **Manage View** drop-down on the right.

Choose what to do:

- **Save changes**: Make changes to a saved view.
- **Save as new view**: Save a new view with the filters and columns that are currently applied.
- **Rename**: Rename a saved view.
- **Set as default view**: Make this the default view that appears when you select the report.
- **Delete**: Delete this view from the list.

### Can I reset a report?

Yes, you can reset your report to remove all changes and return to the way the data was initially presented.

1. [Go to All Reports](https://www.wix.com/my-account/site-selector/?title=Select%20a%20Site&buttonText=Analytics%20Reports&actionUrl=https%3A%2F%2Fmanage.wix.com%2Fdashboard%2F%7B%7BmetaSiteId%7D%7D%2Fanalytics/reports/?referralInfo=sidebar) in your site's dashboard.
2. Select the relevant report.
3. Click the **More Actions** icon .
4. Click **Reset filters**.
[image: A screenshot of the reset filters button in a report.]
**Tip:** To reset a report in the **Table** view, select the **Default **view from the drop-down.[image: A screenshot of selecting a default report from the list of report views.]

### Can I create a new Analytics report?

Yes, you can [create a new Wix Analytics Report](https://support.wix.com/en/article/creating-a-new-wix-analytics-report) to answer specific questions that weren’t addressed in any of your pre-defined reports.
**Note: **Customizing reports is only available from the [Business Elite plan](https://support.wix.com/en/article/choosing-a-premium-plan) (for Wix Editor users) or the [Elite plan](https://support.wix.com/en/article/wix-studio-upgrading-sites) (for Studio users).
