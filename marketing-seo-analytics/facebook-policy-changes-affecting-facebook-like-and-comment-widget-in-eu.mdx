---
title: "Facebook Policy Changes Affecting Facebook Like and Comment Widget in EU"
---

We are aware that a recent change to Facebook's Policy concerning their Like Button for the Web, which is affecting both the Like and Comment Widget in the EU.

As a result of this change, the widgets will not be visible on the site unless the visitor is currently logged into their Facebook account.

If you would like to read more about this change from Facebook, you can do so [here](https://developers.facebook.com/docs/plugins/like-button).
