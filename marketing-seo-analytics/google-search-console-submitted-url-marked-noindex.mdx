---
title: "Google Search Console: Submitted URL Marked 'Noindex'"
---

If you [submitted a page for Google to index](https://support.wix.com/en/article/google-search-console-using-the-url-inspection-tool) and received the **Submitted URL Marked 'noindex'** error message, it means that Google has identified that your page should not be indexed and displayed in search results.

The 'noindex' tag is a meta tag that you can add to a page's HTML code in order to prevent search engines from showing it in search results. However, this error message doesn't necessarily mean that there is a 'noindex' tag in your code. There can be various reasons for this error to come up, that you can easily check and fix.

If you're getting the **Submitted URL Marked 'noindex'** error message, try these steps:

### Step 1 | Check the URL

Make sure that you entered the URL of the page correctly when you submitted it for indexing. 
You should also make sure that it corresponds with an existing page on your site that doesn't return a [404](https://support.wix.com/en/article/google-search-console-404-error) error message or [5xx ](https://support.wix.com/en/article/google-search-console-5xx-error)error message.

### Step 2 | Make sure search engines can index your page and site

Check your site's pages to make sure that search engines are not prevented from indexing them. In this case, the page would have a "noindex" tag in the code and Google will not include it in search results.
Learn how to check if search engines can index your pages in:
- [Wix Editor](https://support.wix.com/en/article/wix-editor-preventing-search-engines-from-indexing-your-page)
- [Studio Editor](https://support.wix.com/en/article/studio-editor-adding-and-managing-pages#hiding-a-page)

You should also check [your site's settings](https://support.wix.com/en/article/preventing-search-engines-from-indexing-your-site) to make sure that search engines can index it.

### Step 3 | Check if the page is password protected

Make sure that your page is not password protected. In this case, the page would have a "noindex" tag in the code and Google will not include it in search results.
Learn more about password protected pages in:
- [Wix Editor](https://support.wix.com/en/article/wix-editor-password-protecting-a-specific-page-of-your-site)
- [Studio Editor](https://support.wix.com/en/article/studio-editor-adding-and-managing-pages#changing-the-page-settings)

### Step 4 | Check if the page is a members only page

You should make sure that the page is not set to members only. Members only pages are excluded from search results by default. 
Learn more about members only pages in:
- [Wix Editor](https://support.wix.com/en/article/wix-editor-creating-members-only-pages)
- [Studio Editor](https://support.wix.com/en/article/studio-editor-adding-and-managing-pages#changing-the-page-settings)

### Step 5 | Use the URL Inspection Tool

If the page is indexed, not a members only page, or not password protected, you should inspect the URL using Google's URL Inspection Tool. 
The URL Inspection Tool allows you to submit individual pages to Google and simulate how Google crawls or renders a URL on your site. You can use it to diagnose errors that are preventing the page from being indexed. [Learn more](https://support.wix.com/en/article/google-search-console-using-the-url-inspection-tool)

### Step 6 | Check the Last Crawled date

Check the date below **Last read** in the [Sitemaps report](https://support.google.com/webmasters/answer/7451001) in Google Search Console. If the date is over a month ago, the error message is most likely not relevant anymore.

### Step 7 | Request Google to index the page

If you've checked all the above and the page is still not indexed, request Google to index by clicking **Request Indexing **in the URL inspection tool.
