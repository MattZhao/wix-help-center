---

You can use the Wix Site Inspection tool to get insights about the discoverability, mobile usability, and indexability of your site's pages. [Learn more about Wix Site Inspection](https://support.wix.com/en/article/wix-site-inspection-an-overview).

> **Important:**
>
> To connect to Google Search Console, you must have a [Premium plan](http://www.wix.com/upgrade/website) and a domain connected to your site. This can be either a domain [purchased from Wix](https://support.wix.com/en/article/connecting-a-domain-purchased-from-wix) or a domain purchased [from another domain host](https://support.wix.com/en/article/connecting-a-domain-purchased-elsewhere).

---

### Overview Coverage Report

Once you submit a URL to the tool, you will get an overview report that contains more information about your page:

If it was previously submitted for indexingIf Google has already indexed the page or not Date of the last time Google has crawled the page

---

### Testing a Live URL

Test your page's URL to make sure it's accessible and working properly. The tool will test your link for errors/warnings and check if Google is able to index it.

> **Important:**
>
> In order to use the URL Inspection Tool, you must first [verify your Wix site with Google Search Console](https://support.wix.com/en/article/connecting-your-site-to-google-in-the-wix-seo-setup-checklist).

### Show me how

1. Go to [Google Search Console](https://search.google.com/search-console).
2. Enter your site's domain in the search bar at the top and click the Enter key.

**Note:** Make sure you enter the full URL, including **"https://www"** in the beginning.
3. Click **Test Live URL **on the right.

---

### Understanding Warnings and Errors

When you [submit a page](https://search.google.com/search-console) to Google's URL Inspection Tool, it will test your page for any warnings or errors you should know about.

---

### Requesting Google to Index a URL

If you need Google to index a URL for the first time or if you've made changes to an indexed page, you can request Google to do so in the URL Inspection Tool. If Google doesn't find any errors in your live URL, it will be added to a priority-based crawl queue.

### Show me how

1. Go to [Google Search Console](https://search.google.com/search-console).
2. Enter your site's domain in the search bar at the top and click the Enter key.

**Note:** Make sure you enter the full URL, including **"https://www"** in the beginning.
3. Click **Request Indexing**.
