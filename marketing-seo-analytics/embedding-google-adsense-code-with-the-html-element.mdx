---
title: "Embedding Google AdSense Code with the HTML Element"
---

Adding Google AdSense code using the HTML element is not recommended. Unfortunately, Wix cannot provide support for Google AdSense ads placed on your site using this method.

Alternatively, you can display AdSense ads using the Wix Monetize with AdSense app. [Learn More](https://support.wix.com/en/article/apps-made-by-wix-adding-and-setting-up-the-wix-monetize-with-adsense-app)
