---
title: "Verifying Your Site On Search Engines Using Custom Code"
---

You can verify your ownership by adding verification meta tags as custom code on your site. Verifying your site on search engines confirms your ownership, and helps your site's presence in search engine search results.

> **For the meta tag to properly validate:**
>
> - The code must be in a [valid HTML format](https://support.wix.com/en/article/header-code-meta-tag-guidelines#correct-format-for-header-codes-per-tool).
>
> - The format should be \<meta name=”XX” content=”XX”/>
> - Missing or extra attributes such as ‘\<’, a ‘ “ ‘, will create an issue.
> - The tag must belong to the right webmaster.
> - The tag will work when the site is published.

[Using custom code with an upgraded site](https://support.wix.com/en/article/verifying-your-site-on-search-engines-9255141#using-custom-code-with-an-upgraded-site)  [Using custom code with a free site](https://support.wix.com/en/article/verifying-your-site-on-search-engines-9255141#using-custom-code-with-a-free-site)

### Using custom code with an upgraded site

Add custom code in your dashboard to verify your site. You can add custom code to specific site pages or all of your pages.

#### To use custom code:

[Go to Settings](https://www.wix.com/my-account/site-selector/?buttonText=Manage%20Settings&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https://www.wix.com/dashboard/%7b%7bmetaSiteId%7d%7d/settings) in your site's dashboard.  Click the **Custom Code** tab under **Advanced Settings**.  Click** + Add Custom Code** at the top right.  Paste the code snippet in the text box.   Enter a name for your code.

**Tip: **Give it a name that is easy to recognize so you can quickly identify it later.   Select an option under **Add Code to Pages**:

- **All pages: **This adds the code to all of your site's pages, including any new pages that you'll create in the future. Choose whether to load the code only once per visit or on each page your visitor opens.
- **Choose specific pages: **Use the drop-down menu to select the relevant pages.
    Choose where to place your code:

- Head
- Body - start
- Body - end
    Click **Apply**.

### Using custom code with a free site

Add custom code in your editor to verify your site pages.

#### To use custom code:

Wix EditorStudio Editor
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Click **Pages & Menu ** on the left side of the editor.
3. Click the **More Actions** icon  next to the relevant page.
4. Click **SEO basics**.
5. Click the **Advanced SEO **tab.
6. Click **+ Add New Tag** under** Additional Tags**.
7. Enter your meta tag in HTML format.
8. Click **Apply**.

1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Click **Pages**  on the left side of the editor.
3. Click the **More Actions** icon  next to the relevant page.
4. Click **SEO Basics**.
5. Click the **Advanced SEO **tab.
6. Click **+ Add New Tag** under** Additional Tags**.
7. Enter your meta tag in HTML format.
8. Click **Apply**.
