Wix uses JavaScript so that you can create a stunning site with lots of freedom in the design. Additionally, we use SSR (Server Side Rendering) to help search engines crawl your site, view your meta tags and extract the relevant content from each of your pages. Click [here](https://support.wix.com/en/article/viewing-your-pages-source-code-the-way-search-engines-do) to learn how to view your page's source code like search engines do.

### Understanding External Tool Suggestions

SSR allows most external SEO tools to read your page's source code. However, as these tools are external and subject to many factors, we cannot guarantee 100% accuracy. For the best results, you can use official search engines' SEO tools such as the Google Search Console.
