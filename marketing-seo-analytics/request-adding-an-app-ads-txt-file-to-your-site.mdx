---
title: "Request: Adding an App-Ads.txt File to Your Site"
---

Currently, it is not possible to add an app-ads.txt file to your site. The app-ads.txt file works like an ads.txt file for mobile apps. Adding this file would let you identify the digital sellers that you've authorized to sell your products. [Learn more about app-ads.txt](https://www.app-ads-txt.com/)

We are always working to update and improve our products, and your feedback is greatly appreciated.
