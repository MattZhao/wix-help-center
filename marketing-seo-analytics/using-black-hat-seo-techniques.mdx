---
title: "Using Black Hat SEO Techniques"
---

Black hat SEO is a type of SEO optimization that uses unethical techniques to manipulate search ranking results for the site. These techniques don't comply with [search engine guidelines for quality](https://developers.google.com/search/docs/advanced/guidelines/webmaster-guidelines), and there are risks involved with using them.

In general, these techniques don't improve the user experience of your site, and can even negatively impact the experience. For this reason, search engines reduce the ranking of sites that use these techniques so that more useful or higher-quality sites appear above them.

### Risks of using Black Hat SEO

Using black hat SEO techniques can cause search engines like Google to rank your site lower or completely remove your site from search engine results. [Learn more about Google Search Essentials.](https://developers.google.com/search/docs/essentials#quality_guidelines)

Search engines may not discover these techniques on your site immediately. However, they constantly improve their detection of black hat SEO techniques, and it's likely that your site will get penalized eventually.

In the long run, it's a better idea to work on [optimizing your site's content for SEO](https://support.wix.com/en/article/optimizing-your-sites-content-for-seo) if you want to improve your search engine ranking.

### Black Hat SEO examples

Some common examples of black hat SEO techniques are: hidden text or links, automatically generated content, keyword stuffing, buying or selling backlinks, and using redirects to manipulate ranking.

### Hidden texts and links

Text that is visible only to search engines goes against search engine guidelines. Some examples of this type of text are:

- Any text that is written in the same color (or close to) as the web page background. For example, white text on a white background.
- Any text situated in an area of the page that has been defined as hidden or invisible using CSS.
- Extremely small fonts that are too small for site visitors to see.
- Any text that is hidden behind another element (e.g., an image).

**Note:** [Alt text for images](https://support.wix.com/en/article/add-alt-text-to-images-and-galleries) is not considered hidden text because it helps search engines and screen readers understand the content of an image.

### Automatically generated content

This is low-value text that is automatically generated by a program using specific topics or keywords. It is usually not useful to site visitors because it doesn't make sense. 
Some types of automatically generated text include:
- Automatic translations that are not verified before publishing
- Text created using automatically generated synonyms of words
- Text created from collating search results
- Text create by combining content from different web pages without adding any value

### Keyword stuffing

This is where a site contains a large number of irrelevant keywords, search phrases, or numbers to manipulate a site's ranking. The keywords or numbers often appear out of context and do not make sense to readers.

Some examples of keyword stuffing include:
- Listing the same keyword or search phrase over and over.
- Adding keywords or search phrases to places where they do not logically or organically fit.
- Mentioning keywords or search phrases solely to inflate the number of times they appear in your content.

To improve your site's ranking, it's better to focus on [creating high-quality content](https://support.wix.com/en/article/optimizing-your-sites-content-for-seo) that's useful to your visitors instead of forcing keywords into your content.

### Buying or selling backlinks

Backlinks (also known as incoming links, inbound links, or inward links) are links that direct users to your site from other relevant sites. Sites that have [backlinks from reputable sites](https://support.wix.com/en/article/gaining-backlinks-for-your-site) rank higher in search results. 
Websites that buy or sell links to other websites to artificially improve a site's ranking are penalized by search engines. Using automated programs to create links to your site can also affect your site's ranking.

### Using URL redirects to manipulate page rank

There are many legitimate reasons to use a URL redirect. For example, you can use a URL redirect to [maintain your previous site's search ranking](https://support.wix.com/en/article/maintaining-your-sites-google-rankings-with-url-redirects-when-moving-to-wix) when moving your site to Wix.
However, some types of redirects go against search engine quality guidelines. Redirecting a user to [a page with different content](https://developers.google.com/search/docs/advanced/guidelines/sneaky-redirects) than what was made available to the search engine crawler is penalized by search engines. 
For example, if a user searches for recipes, they expect the URLs in the search results to take them to pages about food. If a URL redirect takes them to a page completely unrelated to food, this would be considered a manipulative redirect.
