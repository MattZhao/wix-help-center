---
title: "Request: Adding Sitemaps for Multilingual Site Versions"
---

We are excited to announce that you can now [create additional sitemaps](https://support.wix.com/en/article/understanding-your-sites-sitemap-file) for the language versions of your site that you create using [Wix Multilingual](https://support.wix.com/en/article/wix-multilingual-an-overview).

> **Note:**
>
> Currently, Wix includes image information in the sitemaps for main pages, Wix Stores, Wix Events, Wix Blog, Wix Forum, Online Programs, Wix Restaurants and Portfolio. Don't worry - we'll be adding image information for more sitemaps in the future.
