---
title: "Wix Events Request: Creating Event Tickets Using Add-ons"
---

Currently, it is not possible to create an event ticket using add-ons, such as discounted parking or a free meal.

> **Workaround:**
>
> You can [create event tickets](https://support.wix.com/en/article/creating-tickets-for-your-event#step-2-create-one-or-more-ticket-types) with different price options. For example:
> - Event ticket with an add-on:
>
> - "Event Ticket + Meal" for $60.
> - "Event Ticket + Parking" for $50.
> - Separate tickets for events and add-ons:
>
> - "Event Ticket" for $40.
> - "Meal" for $20.
> - "Parking" for $10.

We are always working to update and improve our products, and your feedback is greatly appreciated.
