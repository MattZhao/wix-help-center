---
title: "Wix Events: Adding an Image to an Event"
---

Add great images to entice site visitors to sign up for your events. Once you add an image to an event, you can control the way it looks on the Events List and the Events Details page.

> **Tip:**
>
> Make sure you align the ratio of the images you upload with the settings you select in the Editor. For example, if you upload images with a 16:9 ratio, we recommend that you customize your Event List and Event Details page to display images with the same ratio.

---

### Step 1 | Add an image to an event

Start by adding a good-quality image to your event.

> **Tip:**
>
> You can [use the Wix Photo Studio to crop or resize images](https://support.wix.com/en/article/wix-media-using-the-wix-photo-studio-tools#crop-and-resize).

#### To add images to an event:

[Go to Events](https://www.wix.com/my-account/site-selector/?buttonText=Manage%20Events&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https://www.wix.com/dashboard/\{\{metaSiteId\}\}/events/) in your site's dashboard.  Create a new event or select an existing one.  Click the **Plus** icon  under **Event image** in the **General info** section.

(In the Media Manager) Select an existing image or click **Upload Media** to [upload a new image](https://support.wix.com/en/article/wix-editor-uploading-your-own-images).  Click **Save**.

> **Tip:**
>
> To replace or delete an image, hover over it and click the relevant icon.

---

### Step 2 | Customize image settings on the Events page

Go to your editor and select the layout you want to use in the Event List element on your Events page. After selecting a layout, you can customize the image settings.

#### To customize images on the Events page:

Wix EditorStudio Editor
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Go to the Events page: 

1. Click **Pages & Menu ** on the left side of the editor.
2. Click **Event Pages**.
3. Click your Events page.
3. Click the Event List** **element on your page.
4. Click **Settings**.
[image: Screenshot of going to the Event List settings.]
1. Click the **Layout **tab.
2. Select a layout:
Grid, List, or Calendar layouts
1. In the **Layout** section, select the **Grid**, **List**, or **Calendar **layout.
2. Scroll down to the **Image layout** section and select an image ratio.
3. Select a resize option:

- **Crop: **Images are cropped to the same size. If you uploaded images in different sizes and with different aspect ratios, part of the image may be cut off.
- **Fit: **If you select the fit option, the entire image is displayed and keeps its original aspect ratio.
4. Drag the slider to adjust the image opacity.
5. Select the color that appears behind the image.
**Tip: **If you selected the calendar layout, site visitors see the image only when clicking an event in the calendar.Side by side layout
1. In the **Layout** section, select **Side by side** layout option.
2. In the **Image layout **section, select the relevant layout:

- Images on the left
- Images on alternating sides
- Images on the right
3. Drag the **Proportions** handle to adjust the size of the image compared to the size of the text.
4. Select a resize option:

- **Crop: **Images are cropped to the same size. If you uploaded images in different sizes and with different aspect ratios, part of the image may be cut off.
- **Fit: **If you select the fit option, the entire image is displayed and keeps its original aspect ratio.

### Step 3 | Customize image settings on the Event Details & Registration page

Now that you know which image ratio is going to be used for the Event List, you can customize the image in the page that displays the event details.

#### To set the image display on the Event Details & Registration page:

Wix EditorStudio Editor
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Go to the Event Details & Registration page: 

1. Click **Pages & Menu ** on the left side of the editor.
2. Click **Event Pages**.
3. Click **Event Details & Registration**.
3. Click the Event Details** **element on your page.
4. Click **Settings**.
[image: A screenshot of clicking Settings on the Event Details element.]
1. Click the **Layout **tab.
2. Select a header layout: **Classic** or **Side by Side**.
3. Select a ticket picker layout: **List** or **Cards**.
4. Select the alignment of your header and event info.
5. (Classic layout only) Select the image aspect ratio: **1:1** or **16:9**.
6. (Side by Side layout only) Select an alignment option: **Left** or **Right**.
7. Select an image resize option:

- **Crop: **Images are cropped to the same size. If you upload images in different sizes and with different aspect ratios, part of the image may be cut off.
- **Fit: **If you select the fit option, the entire image is displayed and keeps its original aspect ratio.
8. Drag the slider to adjust the image opacity.
9. Select the color that appears behind the image.
