---
title: "Wix Events Request: Creating a New Page with \"Events\" in the URL"
---

Currently, if you create a new site page named "Events" on a site that has the Wix Events app, the page appears as **events-1** in your URL (e.g. www.mystunningwebsite.com/**events-1**). The use of "events" in the URL is reserved for the main Wix Events page.

We are always working to update and improve our products, and your feedback is greatly appreciated.
