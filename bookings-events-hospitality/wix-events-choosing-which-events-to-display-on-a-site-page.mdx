---
title: "Wix Events: Choosing Which Events to Display on a Site Page"
---

With Wix Events, you can create as many events as you need and choose which ones to showcase on any of your site pages.

> **Tip:**
>
> For all sections in this article, you can add a [new site page or events to an existing page](https://support.wix.com/en/article/wix-events-adding-additional-event-pages-to-your-site).

**In this article, learn how to:**

[Display a single event](https://support.wix.com/en/article/wix-events-choosing-which-events-to-display-on-a-site-page#displaying-a-single-event-on-a-site-page)  [Show a recurring event](https://support.wix.com/en/article/wix-events-choosing-which-events-to-display-on-a-site-page#showcasing-a-recurring-event-on-a-site-page)  [Manually select and reorder events](https://support.wix.com/en/article/wix-events-choosing-which-events-to-display-on-a-site-page#manually-selecting-and-ordering-events)  [Show all upcoming, past, or all events](https://support.wix.com/en/article/wix-events-choosing-which-events-to-display-on-a-site-page#showing-all-upcoming-past-or-all-events)  [Display different event categories on separate pages](https://support.wix.com/en/article/wix-events-choosing-which-events-to-display-on-a-site-page#displaying-different-event-categories-on-separate-pages)

### Displaying a single event on a site page

Showcase a specific event by dedicating a site page to it. This page would include all of the information your guests need to know.

> **Note:**
>
> Currently, displaying a single event is only available in the Wix Editor.

#### To display a single event on a page:

[Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).  Go to the page where you want to add a single event.  Click the Wix Events** **element on your page.   Click **Display Events**.  Select **A single event**.  Scroll down and select the event you want to display.

### Showcasing a recurring event on a site page

If you created a recurring event, you can display it in two ways: A single event with multiple dates, or show each occurrence as its own event.

Click below to see how each option looks like on the event list.

### Display as a single event with multiple dates

In the example below, the event is shown as one entry with several dates. When guests try to register, they select the date they want to attend.

### Display each occurrence of the recurring event separately

In the example below, each event date is listed as its own entry.

> **Notes:**
>
> - You need to have a [recurring event set up](https://support.wix.com/en/article/wix-events-creating-a-recurring-event-2644272) to select this option
> - If you are using the [Calendar layout](https://support.wix.com/en/article/wix-events-changing-the-event-list-layout), all occurrences of the event are displayed.

#### To showcase a recurring event on a page:

Wix EditorStudio Editor
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Go to the page where you want to add a recurring event.
3. Click the Wix Events** **element on your page.
4. Click **Display Events**.
5. Select **Multiple Events**.
6. Select an option from the **Which events are shown **drop-down:

**Note: **You can also choose to [manually select an event(s)](https://support.wix.com/en/article/wix-events-choosing-which-events-to-display-on-a-site-page#manually-selecting-and-ordering-events).

- **Upcoming & past:** All events, including past events, are displayed.
- **Upcoming:** All future events are displayed.
- **Past:** All past events are displayed.
7. (Optional) Select a category from the **Which category will be shown?** drop-down.
8. Select an option from the **Show recurring events as** drop-down:

- **One event: **The event is shown as one entry with several dates.
- **Individual events:** Each event date is listed as its own entry.
[image: A screenshot of selecting how to show recurring events from the Wix Editor.]

### Manually selecting and ordering events

You can choose specific events to display in the event list and customize the order in which they appear.

#### To manually select and order events:

Wix EditorStudio Editor
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Go to the page where you want to add an event.
3. Click the Wix Events** **element on your page.
4. Click **Display Events**.
5. Select **Multiple Events**.
6. Click the **Which events do you want to show **drop-down and choose **Select Manually**.

**Note:** If you don't choose this option, events are displayed according to the date they occur.
7. Click **Select Events**.
8. Select the checkbox(es) next to the events you want to display and click **Confirm**.
9. Choose the event order under **Display order:**

- **Chronologically: **Select **Chronological** to sort events by start date.
- **Sort manually: **Drag and drop the events to reorder them.
[image: A screenshot of manually selecting events to display on a site page of the Wix Editor.]
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Go to the page where you want to add an event.
3. Click the Wix Events** **element on your page.
4. Click **Settings**.
5. Click the **Display Events **tab.
6. Select an option from the **Which events are shown **drop-down and choose **Select Manually**.

**Note:** If you don't choose this option, events are displayed according to the date they occur.

- **Chronologically: **Select **Chronological** to sort events by start date.
- **Sort manually: **Drag and drop the events to reorder them.

> **When you choose the Select Manually option:**
>
> - New events you create in the editor automatically appear on your site, but you can hide them.
> - New events you create in the dashboard are hidden by default, but you can unhide them.

### Showing all upcoming, past, or all events

When displaying multiple events, you can display all events past and upcoming or limit the selection to only upcoming events or only past events.

> **Tip:**
>
> When displaying only upcoming events, once they've taken place, events are automatically removed from your site.

#### To select which type of events to display:

Wix EditorStudio Editor
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Go to the page where you want to add an event.
3. Click the Wix Events** **element on your page.
4. Click **Display Events**.
5. Select **Multiple Events**.
6. Select an option from the **Which events are shown **drop-down: 

- **Upcoming & past:** All events, including past events, are displayed.
- **Upcoming:** All future events are displayed. 

 **Note: **If you have no upcoming events, a "No Upcoming Events at the Moment" is displayed on your live site and sample events are displayed in the Editor.
- **Past:** All past events are displayed.
[image: A screenshot of selecting an option from the Which events are shown drop-down in the Wix Editor.]
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Go to the page where you want to add an event.
3. Click the Wix Events** **element on your page.
4. Click **Settings**.
5. Click the **Display Events **tab.
6. Select an option from the **Which events are shown **drop-down: 

- **Upcoming & past:** All events, including past events, are displayed.
- **Upcoming:** All future events are displayed. 

**Note: **If you have no upcoming events, a "No Upcoming Events at the Moment" is displayed on your live site and sample events are displayed in the Editor.
- **Past:** All past events are displayed.

### Displaying different event categories on separate pages

You can show different types of events on separate pages. For example, create one page for concerts and another for lectures, and then display each category on its respective page.

> **Before you begin:**
>
> [Create the categories](https://support.wix.com/en/article/wix-events-creating-and-managing-event-categories) you need and assign events to the relevant categories.

#### To display event categories on separate pages:

Wix EditorStudio Editor
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Go to the page where you want to add a single event.
3. Click the Wix Events** **element on your page.
4. Click **Display Events**.
5. Select **Multiple Events**.
6. Select an option from the **Which events do you want to show **drop-down:

- **Upcoming and Past:** All events, including past events, are displayed.
- **Upcoming Events:** All future events are displayed.
- **Past Events: **All past events are displayed.
7. Select a category from the **Which category will be shown?** drop-down.
8. (Optional) Repeat steps 2 - 7  to select a different category to display on a page.
[image: A screenshot of selecting an event category in the Wix Editor.]
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Go to the page where you want to add a single event.
3. Click the Wix Events** **element on your page.
4. Click **Settings**.
5. Click the **Display Events **tab.
6. Select an option from the **Which events do you want to show **drop-down:

- **Upcoming and Past:** All events, including past events, are displayed.
- **Upcoming Events:** All future events are displayed.
- **Past Events: **All past events are displayed.
7. Select a category from the **Which category will be shown?** drop-down.
