---
title: "Wix Events: Changing Registration Settings Using the Wix App"
---

Make changes to your event settings on the go with the Wix app. Open or close registration, increase your guest limit, and manage your waiting list - all from your mobile device.

### To edit the registration settings:

Go to your site in the Wix app.  Tap **Manage**  at the bottom.  Tap **Events**.  Select **Published Events **or **Draft Events**.  Select an event.  Tap the **Manage **tab.  Select **Registration settings**.  Choose what you want to do:

### Set where guests can register for the event

1. Tap **Registration Channel**.
2. Select where guests can register:

- **Wix events registration page:** Guests register on your site.
- **A different web address: **Enter the address where guests can register.
- **Guests don't need to register: **Create an event that doesn't require registration. [Learn more](https://support.wix.com/en/article/wix-events-customizing-registration-settings-messages)

### Set the registration status (when the event opens & closes)

Tap **Open** or **Closed **to manually change the current registration status. 
You can also set dates when registration automatically opens and closes.
1. Tap **Registration Status**.
2. Set the status:

- Tap **Open **or **Closed** to immediately change the status.
- Tap **Custom dates** to set when registration opens and closes:

1. Select an opening date and time.
2. Select a closing date and time.
3. Tap **Save**.

### Set a guest limit (RSVP only)

You can allow an unlimited number of guest to register or set a registration limit. If you limit the number of guests, you can optionally create a waitlist when you hit the maximum.
**Note: **For ticketed events, you can limit the number tickets for each ticket type.

1. Click **Guest Limit**.
2. Select an option:

- **Unlimited guests: **Set no limits to the number of guests that can register.
- **Limited guests: **Limit the number of guests that can register. 

1. Enter the number of guests that can register for this event.
2. Select what happens when registration is full:

- **Close registration: **Guests are blocked from registering.
- **Add guests to a waitlist: **Guests can join a [waitlist](https://support.wix.com/en/article/wix-events-limiting-registration-and-creating-waitlists-for-rsvp-events) so they can register if an opening becomes available.
3. Click **Save**.
