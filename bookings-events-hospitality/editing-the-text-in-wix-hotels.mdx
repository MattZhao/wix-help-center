> **Important:**
>
> This article refers to the original Wix Hotels. If you are using the new Wix Hotels by HotelRunner, which is not yet available to all users, please [read the information here](https://support.wix.com/en/article/wix-hotels-by-hotelrunner-an-overview). Learn how to [check which version of Wix Hotels you are using](https://support.wix.com/en/article/wix-hotels-by-hotelrunner-the-difference-between-the-new-and-previous-wix-hotels).

You can edit almost all the default text that appears in the Wix Hotels app to make it your own.

### To edit the text:

Click the Wix Hotels app in the Editor.Click **Settings**.Click the **Text **tab.Click the drop-down menu and select the page or element that you'd like to edit.

Edit the text in the text fields (click a page or element below to learn more):

### Room List Page

This is the list of all the rooms you offer. You can edit the list title and the button text.

### Search Box

The search box appears at the top of your room list. You can edit any of the text on the box.

**Note:** This is different to the Search Bar add-on that you can add to other pages of your site.

### Search Messages

These are the search results guests see when the search box does not find any suitable matches.

### Booking Form

This is the form guests need to complete when reserving a room through your site. You can edit the form title, the Special Requests field title, the button text and the summary labels.

### Confirmation Page

This is the page guests reach after they complete the reservation. You can edit the titles, reservation notice and summary labels.

> **Tip:**
>
> You can also change the text language by selecting a language from the drop-down list. The default text is translated, but text that you type in manually won't be translated. 
> **Note:** You should only use this feature to customize text for the primary language of the hotel. If you have activated other languages, you must use the default translated text.
