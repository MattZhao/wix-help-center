---
title: "Wix Restaurants Request: Varying Price for Same Item in Different Menus"
---

Currently, it is not possible to include the same menu item in two different menus (for example, an in-house menu and a take out menu) and set two different prices.

As workaround solution, you can create two menu items with the same name, description and options, and price them differently.

> **Tip:**
>
> When creating the duplicate menu item, do not select the existing item from the drop-down list.

We are always working to update and improve our products, and your feedback is greatly appreciated.
