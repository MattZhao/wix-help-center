---
title: "Wix Events Request: Setting Time Slots for Capacity Control"
---

Currently, it is not possible to set multiple check-in times or specific arrival time slots for events.

> **Workaround:**
>
> As a possible workaround, you can create separate ticket types for different time slots (e.g. A 3:00 ticket, a 3:30 ticket, etc.).

We are always working to update and improve our products, and your feedback is greatly appreciated.
