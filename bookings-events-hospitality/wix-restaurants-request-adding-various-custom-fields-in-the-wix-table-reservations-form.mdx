---
title: "Wix Restaurants Request: Adding Various Custom Fields in the Wix Table Reservations Form"
---

Currently it is only possible to [add a text input for custom fields](https://support.wix.com/en/article/wix-restaurants-customizing-your-table-reservations-form). Drop-down, radio buttons or any other input fields are not supported.

We are always working to update and improve our products, and your feedback is greatly appreciated.
