title: "Wix Events: Creating a Private Event"
---

When you publish an event, it's visible to all site visitors for viewing and registration. For private or exclusive events, you can limit access by approving site members or password-protecting the event page.

This ensures that only invited guests or approved members can participate, helping you maintain privacy and tailor the event experience to a specific audience.

**In this article, learn how to:**

[Limit registration to approved site members](https://support.wix.com/en/article/wix-events-creating-a-private-event#limiting-registration-to-approved-site-members)  [Password protect event pages](https://support.wix.com/en/article/wix-events-creating-a-private-event#password-protecting-event-pages)  [Frequently asked questions (FAQs)](https://support.wix.com/en/article/wix-events-creating-a-private-event#faqs)

### Limiting registration to approved site members

You can create an event that anyone visiting your site can see, but only approved members can register. With member-only events, only users who have signed up as members can RSVP.

> **Before you begin:**
>
> Make sure you have a [Members Area](https://support.wix.com/en/article/site-members-about-the-members-area) added to your site.

#### To limit registration to approved site members:

[Go to Events](https://www.wix.com/my-account/site-selector/?buttonText=Manage%20Events&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https://www.wix.com/dashboard/%7B%7BmetaSiteId%7D%7D/events/) in your site's dashboard.  Click **Manage** next to the relevant event.   Click the **Settings** tab.   Click **Edit** next to **Registration settings**.   Select **Only site members** under **Event permissions**.   Click **Save**.   [Set up your site signup form](https://support.wix.com/en/article/site-members-editing-the-signup-settings-for-the-default-and-custom-forms) so only people you approve can become site members.

**Note: **This prevents site visitors who aren't invited to your private event from logging in and registering.  (Optional) [Hide the Events Details page](https://support.wix.com/en/article/wix-editor-preventing-search-engines-from-indexing-your-page) from search engines if you don't want a specific page to appear in search results.

### Password protecting event pages

Events include a main event page, an Event Details & Registration page, and a Schedule page. You can password-protect any of these pages to restrict access. When a site visitor tries to view a protected page, they will be prompted to enter the password.

#### To password protect event pages:

Wix EditorStudio Editor
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Go to the Events page: 

1. Click **Pages & Menu ** on the left side of the editor.
2. Click **Event Pages**.
3. Click the **Settings** icon ﻿ next to relevant event page (e.g. Schedule, Events, Events Details & Registration).
4. Click the **Permissions** tab.
5. Click **Password holders **under** Who can access this page?**
6. Enter the page's password.
7. (Optional) [Customize the design of the password window](https://support.wix.com/en/article/site-members-changing-the-design-of-the-password-window).
8. (Optional) [Hide the Events Details page from search engines](https://support.wix.com/en/article/wix-editor-preventing-search-engines-from-indexing-your-page).

### FAQs

Learn more about creating a private event.

### Can I create a private link to an event?

Although Wix Events doesn’t offer a built-in option to create a private link, you can implement a workaround in the editor.
1. Add a [new site page and include an event list](https://support.wix.com/en/article/wix-events-adding-additional-event-pages-to-your-site).
2. Choose which [events to display](https://support.wix.com/en/article/wix-events-choosing-which-events-to-display-on-a-site-page) on the new page.
3. Click the **More Actions** icon  next to the new page.
4. Click **Settings**.
5. Click the **Permissions** tab.
6. Click **Password holders **under** Who can access this page?**
7. Enter the page's password.
8. Copy the page link and share it with guests, along with the password.
**Note:** Make sure this event is removed from other widgets on your site.

### Can I create multiple private events with different guest lists?

Yes. You can password-protect event pages to host multiple private events with different guest lists. Assign a unique password to each main event page and share it with the invited guests.

### Do I need to password protect each page of an event?

No. One password on the main event page protects all other pages.
