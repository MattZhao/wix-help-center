---
title: "Wix Events: Setting Registration Opening & Closing Times in Advance"
---

Set the dates and time that guests are able to RSVP or buy tickets for an event. Setting in advance when registration opens and closes can come in handy if you want to post events far in advance, but don't yet want to allow guests to register.

You may also want to close registration a couple days before the event takes place so that you have time to prepare. When registration is closed, the button text changes to **Details**.

> **Tip:**
>
> You can [edit this text and other button text](https://support.wix.com/en/article/wix-events-editing-event-text).

**In this article, learn how to set registration dates for:**

[RSVP events](https://support.wix.com/en/article/wix-events-setting-registration-opening-closing-times-in-advance#setting-registration-dates-for-rsvp-events)  [Ticketed events](https://support.wix.com/en/article/wix-events-setting-registration-opening-closing-times-in-advance#setting-registration-dates-for-ticketed-events)

---

### Setting registration dates for RSVP events

Control when guests can register for your RSVP event. You can set a custom start date and time and / or a close registration start date and time.

#### To set when registration opens and closes for an RSVP event:

[Go to Events](https://www.wix.com/my-account/site-selector/?buttonText=Manage%20Events&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https://www.wix.com/dashboard/\{\{metaSiteId\}\}/events/) in your site's dashboard.  Click to select the relevant event.  Click the **Settings **tab.  Click **Edit** next to the **Registration Settings**.  Click **Custom dates**.  Select an opening date and time.  Select a closing date and time.  Click **Save**.

---

### Setting registration dates for ticketed events

You can create different ticket types for the same event (e.g. student tickets, regular tickets). You can set a date when registration opens and closes for each ticket type separately.

#### To set when registration opens and closes for tickets:

[Go to Events](https://www.wix.com/my-account/site-selector/?buttonText=Manage%20Events&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https://www.wix.com/dashboard/\{\{metaSiteId\}\}/events/) in your site's dashboard.  Click the **Tickets** tab.  Select a ticket or create a new one.  Scroll down and click the **Set Ticket Sale Period** toggle to enable it.  Enter a start date and time.  Enter an end date and time.   (Optional) Select the **Hide tickets from the event details page when they are not on sale** checkbox.   Click **Save**.  Repeat steps 1-8 for any other ticket types.
