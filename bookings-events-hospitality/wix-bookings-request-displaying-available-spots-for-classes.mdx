> **Update:**
>
> It is now possible to add a Class Timetable to your site. Timetables can be set to display the number of available spots. [Learn More](https://support.wix.com/en/article/wix-bookings-adding-and-setting-up-a-daily-agenda-on-your-site)

We are always working to update and improve our products, and your feedback is hugely appreciated.
