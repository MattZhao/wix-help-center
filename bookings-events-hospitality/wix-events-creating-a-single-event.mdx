---
title: "Wix Events: Creating a Single Event"
---

Start by creating and customizing your event draft. When everything is ready, publish the event to share it with the world.

You can create RSVP events such as weddings and birthday parties or ticketed events such as concerts, conferences, or online classes. Learn more about [the differences between RSVP and Ticketed events](https://support.wix.com/en/article/wix-events-understanding-the-difference-between-rsvp-events-and-ticketed-events).

---

### Step 1 | Create an event draft

Start by adding the basic event details and saving your event draft.

> **Recurring events:**
>
> If you hold the same type of event again and again, save time by [creating a recurring event](https://support.wix.com/en/article/wix-events-creating-a-recurring-event-2644272).

#### To create an event draft:

[Go to Events](https://www.wix.com/my-account/site-selector/?buttonText=Manage%20Events&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https://www.wix.com/dashboard/\{\{metaSiteId\}\}/events/) in your site's dashboard.  Click **+ Add Event**  Select a type of event (this can't be changed after you click **Create Draft**):

- **Ticketed Event:** Sell event tickets (can include free tickets).
- **RSVP Event: **Guests register for the event.
    Add your event details:

### General info

- Enter the event name.
- Enter a brief description of the event under **Short Teaser**.

**Tip:** This appears in the Event List page and the Event Details page, if enabled.
- Connect this event to one or more event categories.

**Note: **Learn more about [creating and connecting categories](https://support.wix.com/en/article/wix-events-creating-and-managing-event-categories).
- Add an **Event image**:

1. Click the Add **+** icon.
2. (In the Media Manager) Select or upload an image and click **Add to Page**.

### Date and time

**If the date and time are still unknown:**
1. Enable the **Time is TBD **(to be determined) toggle.
2. (Optional) Edit the TBD message.

**If the event has a time and date:**
1. Select a start date and time.
2. Enter an end date and time or click the "X" icon to remove it.

**Note: **Events with no end time become "Past Events" 24 hours after the event starts.
3. Click the **Timezone** drop-down and select a time zone.
4. (Optional) Click the **Display timezone** checkbox.

**Tip: **For online events, we recommend displaying your time zone.

### Location

**If the location hasn't been set:**
1. Click the **Location is TBD **(to be determined) toggle to enable it.
2. (Optional) Edit the location message.

**If the event has a physical location:**
1. Click **Physical Location**.
2. Start typing the address of the location and select it from the list.
3. (Optional) Enter a **Venue Name **(e.g. Freemont Hotel).

**If the event takes place online:**
1. Click **Online**.
2. Enter an **Online Location Title **(e.g. Webinar).  

**Important: **Later you'll be able to make this a [Zoom](https://support.wix.com/en/article/wix-events-creating-an-online-zoom-event) video conferencing event. You can also [create an online event using other platforms](https://support.wix.com/en/article/wix-events-creating-online-events).

### "About the event" description

Add detailed event information about your event. The "About" description appears on the Event Details page, if enabled.

5.  When ready, click **Create Draft** at the top right.

---

### Step 2 | Create tickets (ticketed events only)

If your event is a ticketed event, you can now go ahead and [create one or more ticket types](https://support.wix.com/en/article/creating-tickets-for-your-event). Select your event in the dashboard, then go to the **Tickets and Seating** tab to get started.

---

### Step 3 | Customize your settings

Make sure to go to the **Settings **tab of your event in the dashboard. There you can customize any of the following:

**Registration settings: **[Set where, when, and who can register and edit registration messages](https://support.wix.com/en/article/wix-events-customizing-registration-settings-messages).  **Registration form: **Customize the fields that appear on the form:

- [Customize the registration form for RSVP events](https://support.wix.com/en/article/wix-events-customizing-the-registration-form-for-rsvp-events)
- [Customize the registration form for ticketed events](https://support.wix.com/en/article/wix-events-customizing-the-registration-form-for-ticketed-events)
    **Event policies: **Add a [policy checkbox](https://support.wix.com/en/article/wix-events-adding-a-policy-checkbox) that guests can check when they register.  **Emails: **[Manage emails you send and receive](https://support.wix.com/en/article/wix-events-managing-emails-you-send-and-receive).

If you have a ticketed event, you can also customize:

**Ticket settings: **Set your currency, taxation, and ticket limit per order.  **Invoices: **[Create invoices for ticket purchases](https://support.wix.com/en/article/wix-events-creating-invoices-for-ticketed-events).

---

### Step 4 | (Optional) Add features

In the **Features** tab of your event in the dashboard, you can find more features to enhance your events. The available features are:

**Video conferencing: **Turn your event into an online event using [Zoom](https://support.wix.com/en/article/wix-events-creating-an-online-zoom-event).  **Seating map (ticketed events only): **Let guests select tickets for specific seats by [creating a seating map](https://support.wix.com/en/article/wix-events-creating-a-seating-map).  **Automations: **Use [Wix Automations](https://support.wix.com/en/article/wix-events-using-wix-automations-to-promote-an-event) to create automated actions triggered by specific actions.  **Schedule: **[Create an event schedule](https://support.wix.com/en/article/wix-events-creating-an-event-schedule) to let guests know what is happening at your event at different times and in different locations.   **Groups: **Wix Groups lets you create a place for members to post updates, share images and more. Learn how to [connect an event to a group](https://support.wix.com/en/article/wix-events-using-wix-groups-to-promote-your-events).

---

### Step 5 | Publish the event

When you're ready, publish your event. It's now available to be displayed on your site.

#### To publish your event:

[Go to Events](https://www.wix.com/my-account/site-selector/?buttonText=Manage%20Events&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https://www.wix.com/dashboard/\{\{metaSiteId\}\}/events/) in your site's dashboard.  Click the **Drafts** tab.  Select the relevant event.  Click **Publish**.   Click **Publish** to confirm.

> **What's next?**
>
> After publishing your event, you can access the event link on the **Overview** tab of the relevant event.

### FAQs

Click a question below to learn more about creating a single event.

### Why isn't my event showing up automatically on my site?

The event you publish may not appear automatically on your site due to the settings selected in your editor. For instance, if you chose "Select Manually" under the "Which events are shown?" option, you'll need to manually select the event you just published. Learn about all the ways to [choose which events to display on your site](https://support.wix.com/en/article/wix-events-choosing-which-events-to-display-on-a-site-page).

### What location do I chose for a hybrid event (in person and online)?

You can create a hybrid event by selecting a physical location as your location and then adding video conferencing. Learn more about [creating hybrid events](https://support.wix.com/en/article/wix-events-creating-a-hybrid-event).

### How can I access the drafts I created?

You can access your drafts anytime from the Drafts tab.

### Can I change a published event back into a draft?

After you publish your event, you cannot change it back to draft mode. You can, however, hide it from your live site by [customizing which events you display](https://support.wix.com/en/article/wix-events-choosing-which-events-to-display-on-a-site-page).

### Can I preview my event before I publish it?

Yes. Just click **Preview Draft** to see what the event will look like on your live site.

### What kinds of online events can I create?

Choose the online event option that works for you:
- Create online events with [Zoom](https://support.wix.com/en/article/wix-events-creating-an-online-zoom-event).
- Create online events [hosted on other platforms](https://support.wix.com/en/article/wix-events-creating-online-events).
- Create live streaming events using [Wix Video](https://support.wix.com/en/article/wix-events-hosting-a-live-streaming-event).
- Create a [hybrid event](https://support.wix.com/en/article/wix-events-creating-a-hybrid-event) (in person and online).
