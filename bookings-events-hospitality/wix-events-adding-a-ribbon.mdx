---
title: "Wix Events: Adding a Ribbon"
---

When an event is unavailable to be booked, you can automatically display a ribbon to show the event status.

When enabled, three possible ribbons appear:

**Sold Out: ** When no more tickets are available for a ticketed event  **RSVP Closed: **When it's no longer possible to RSVP for a non-ticketed event  **Join Waitlist: **When it's not longer possible to RSVP, but guests can join a waitlist [Learn More](https://support.wix.com/en/article/wix-events-limiting-registration-and-creating-waitlists-for-rsvp-events)

> **Tip:**
>
> You can also display a separate membership ribbon to showcase [membership plans](https://support.wix.com/en/article/wix-events-creating-a-membership-plan).

### To enable ribbons on an event page:

Click Wix Events on a page in the Editor.

**Note: **Ribbon are set per page. If you display events on multiple site pages, make sure to enable or disable ribbons for each event page.   Click the Settings icon .  Click the **Display **tab.  Click the **Sold Out Ribbon** toggle to enable it.   Customize the ribbon:

1. Click the **Design** tab
2. Select **Ribbon**.
3. Select the font and text color.
4. Select the ribbon background color and opacity.

> **Customization for mobile:**
>
> To show or hide ribbons on mobile, click **Switch to Mobile **at the top of the Editor. There, you can click Wix Events and **Settings** to access the **Display **tab.
