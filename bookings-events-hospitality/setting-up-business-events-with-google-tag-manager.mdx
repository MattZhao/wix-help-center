---
title: "Setting Up Business Events with Google Tag Manager"
---

With Google Tag Manager, you can implement a tag management system so you can keep your tags and third-party code snippets updated and organized in one convenient location.

Wix by default pushes business events into the datalayer. The events names and the payload are based on EEC (Enhanced eCom ) structure  It is a user’s responsibility to EEC to GA4. There are several conversion templates that can be added to your container from the GTM Templates gallery (Variables).

**In this article, learn more about: **

[Business events sent by Wix](https://support.wix.com/en/article/setting-up-business-events-with-google-tag-manager#business-events-sent-by-wix)  [Adding a new event ](https://support.wix.com/en/article/setting-up-business-events-with-google-tag-manager#adding-a-new-event)

> **Before you begin:**
>
> [Connect your site to Google Tag Manager](https://support.wix.com/en/article/connecting-your-google-tag-manager-account-to-your-wix-site) in Marketing Integrations to start tracking visitor events on your site.

### Adding a new event

Click **Tags **from the left hand side menu.  Click **New.**  Enter a name for the tag (e.g. Wix Pageviews).  Click **Choose a tag type to begin setup **under **Tag Configuration**.   Select **Google Analytics**.  Select **Google Analytics: GA4 event**.  Enter the **Google Measurement ID**. This should be the same as in the previous step. We recommend creating a [constant](https://support.google.com/tagmanager/answer/7683362?hl=en&ref_topic=9125128&sjid=17855247187236799596-EU#constant) variable in Google Tag Manager.  Add **Event Name **as** add_to_cart**.
