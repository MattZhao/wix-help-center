We are excited to announce that you can now [create your Wix Hotels by HotelRunner site using the Studio Editor](https://support.wix.com/en/article/wix-hotels-by-hotelrunner-adding-and-setting-up-your-hotel).

> **Note:**
>
> Editor X is transitioning to Wix Studio. We're gradually releasing an update that lets you [move Editor X sites to Studio Editor](https://support.wix.com/en/article/wix-studio-faqs-transitioning-from-editor-x) in just a few clicks. [Update your Editor X site to the Studio Editor](https://support.wix.com/en/article/updating-an-editor-x-site-to-the-studio-editor) to add Wix Hotels to your site.
