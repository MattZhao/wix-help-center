---
title: "Checklist for Connecting Wix Hotels to the Channel Manager (HotelRunner)"
---

The Channel Manager feature from Wix partner HotelRunner can be complicated to sync and set up. Refer to the following checklist as you go through the process of connecting the Channel Manager.

Any changes you make to the Channel Manager must be done through your Wix account. Do not sign in from Hotelrunner.com to try to make updates, as it may cause discrepancies with rates and availability to external channels.

> **Important:**
>
> This article refers to the original Wix Hotels. If you are using the new Wix Hotels by HotelRunner, which is not yet available to all users, please [read the information here](https://support.wix.com/en/article/wix-hotels-by-hotelrunner-an-overview). Learn how to [check which version of Wix Hotels you are using](https://support.wix.com/en/article/wix-hotels-by-hotelrunner-the-difference-between-the-new-and-previous-wix-hotels).

---

### Before you begin:

### Check your iCal tab

Using both the Channel Manager and an iCal tab at the same time is not supported. Make sure you remove any iCal URLs from iCal before [connecting it with the Channel Manager](https://support.wix.com/en/article/importing-reservations-from-an-external-calendar-ical-to-wix-hotels).

### Check your weekend rates

Make sure to add both your weekday prices and [weekend prices](https://support.wix.com/en/article/adding-weekend-rates-for-your-rooms-in-wix-hotels) (if the price is the same, input the same value in both fields). The Channel Manager requires both to be completed to avoid any syncing issues.

### Avoid using multiple units

Wix does not fully support multiple units for room types connected to the Channel Manager. Including multiple units can lead to double booking, so we strongly suggest only creating room types with one unit each.

### Talk to HotelRunner support

A few channels require support from the Channel Manager - HotelRunner team. If you are having issues while connecting channels, reach out to them via the chat bubble in your Channel Manager tab or [contact HotelRunner directly](https://hotelrunner.com/en/contact/).

---

### Once you're connected:

### Create manual reservations for any blocked dates

Setting a room as 'Not Available' in Wix Hotels does not reflect in the Channel Manager and could cause double bookings. To block off dates, [create a manual reservation](https://support.wix.com/en/article/manually-adding-reservations-in-wix-hotels) for those dates, which will be accepted by all your channels and show the dates as unavailable.

### Do not enter anything in the 'Base allotment' field

There is a field called 'base allotment' in the advanced settings of each OTA channel. Do not enter anything in this field as it can break the sync with the channel. For questions about base allotments, [contact HotelRunner support](https://hotelrunner.com/en/contact/).

### Understand how the Channel Manager syncs

All syncing with the Channel Manager happens automatically. Updates happen within a few minutes for OTA channels, but can take longer for iCal channels. The 'Sync Now' button is unrelated and should only be used in conjunction with the Wix iCal Tab.

If you're noticing syncing issues particularly at the beginning of connecting Wix Hotels with HotelRunner, please look at the [Troubleshooting guide](https://support.wix.com/en/article/troubleshooting-the-wix-hotels-channel-manager) and follow the steps there.
