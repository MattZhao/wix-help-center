---
title: "Wix Events: Adding Additional Event Pages to Your Site"
---

Add as many event pages as you need to a site. You can customize event listings to display different types of events on separate pages, such as upcoming events on one page and promotional events on another.

---

### Step 1 | (Optional) Add a new site page

When you add an event list to a site, it's added to whatever page you're on. If you want to place it on a new page, add that page and give it a suitable name.

You can add a new page from the Wix Editor or Studio Editor.

Wix EditorStudio Editor
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Click **Pages & Menu ** on the left side of the editor.
3. Click **+ Add Page** at the top.
[image: A screenshot of the Pages & Menu panel in the Wix Editor.]
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Click **Pages**  on the left side of the editor.
3. Click **+ Add New Page** at the bottom.
[image: A screenshot of the Pages panel in the Studio Editor.]

### Step 2 | Add an event list to an existing page

Add the Events widget to an existing site page to showcase your events, making it easier to get them noticed.

Wix EditorStudio Editor
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Go to the page where you want to add an event list.
3. Click **Add Elements ** on the left side of the editor.
4. Click **Events**.
5. Drag the relevant Event list onto your page.

[image: A screenshot ofd the Add Elements panel where you can add an event list to any site page in the Wix Editor.]
1. [Go to your editor](https://manage.wix.com/account/site-selector/?actionUrl=https%3A%2F%2Fwww.wix.com%2Feditor%2F%7BmetaSiteId%7D%3FeditorSessionId%3D%7Besi%7D%26).
2. Go to the page where you want to add an event list.
3. Click **Add Elements ** on the left side of the editor.
4. Click **Events**.
5. Drag the relevant Event list onto your page.

[image: A screenshot ofd the Add Elements panel where you can add an event list to any site page in the Studio Editor.]
