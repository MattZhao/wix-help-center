---
title: "Wix Events: Creating Tickets for an Event Using the Wix App"
---

Create the type of tickets that suit your event. You can choose from a variety of pricing options or create free tickets to promote a special event. For example adult / student tickets or create donation based tickets where guests can set their own price.

> **Important:**
>
> It is not possible to sell tickets for RSVP events.

### To create event tickets:

Go to your site in the Wix app.  Tap **Manage**  at the bottom.  Tap **Events**.  Tap **Published / Draft Events**, then tap on the relevant event.  Tap **Create Tickets**.   Enter a ticket name (e.g. Crafty Cooking 101).  (Optional) Enter a ticket description.  Select the kind of ticket you want to create under **Ticket Type**:

### Fixed price

The ticket costs a set amount for all event guests.
1. Tap the** Currency **drop-down under **Price** and select the relevant currency.
2. Enter the ticket price.
3. Select an option under **Ticket Quantity:**

- **Unlimited tickets: **There is no maximum total number of tickets you are selling.
- **Limited tickets:** Enter the maximum total number of tickets you are selling.
4. Select who pays the** **[**Ticket service fee**](https://support.wix.com/en/article/wix-events-about-wix-ticket-service-fees):

- **Pass fee on to buyer: **The 2.5% fee is added to the ticket price. For example, if you set the ticket price to $100, buyers pay $102.50 and you receive $100.
- **Absorb fee: **The 2.5% fee is included in the ticket price. For example, if you set the ticket price to $100, buyers pay $100 and you receive $97.50.
5. (Optional) Edit the default** Ticket Policy**.
6. (Optional) Set when ticket sales start and end under **Advanced Settings**:

1. Enable the **Set Ticket Sale Period** toggle.
2. Select the **Opening date** and **Opening time **from the drop-down menus.
3. Select the **Closing date **and **Closing time **from the drop-down menus.
4. (Optional) Select the **Hide ticket if it is not on sale **checkbox.
5. Tap **Add**.
7. (Optional) Tap **+ Add a Ticket **to create additional tickets.
8. Tap **Done**.

### Price options

Charge different prices for your event tickets. For example, you can have ticket options for adult / child or orchestra / balcony, depending on the type of event.
1. Tap the** Currency **drop-down under **Price** and select the relevant currency.
2. Tap **Add Price Option**.
3. Enter the option name (e.g. Adult) and price.
4. Tap **+ Add Price Option **and enter a second option (e.g. Child) and price.

**Note: **Repeat this step to enter the price options you need.
5. Tap **Save**.
6. Select an option under **Ticket Quantity:**

- **Unlimited tickets: **There is no maximum total number of tickets you are selling.
- **Limited tickets:** Enter the maximum total number of tickets you are selling.
7. Select who pays the [**Ticket service fee**](https://support.wix.com/en/article/wix-events-about-wix-ticket-service-fees)[**:**](https://support.wix.com/en/article/wix-events-about-wix-ticket-service-fees)

- **Pass fee on to buyer: **The 2.5% fee is added to the ticket price. For example, if you set the ticket price to $100, buyers pay $102.50 and you receive $100.
- **Absorb fee: **The 2.5% fee is included in the ticket price. For example, if you set the ticket price to $100, buyers pay $100 and you receive $97.50.
8. (Optional) Edit the default** Ticket Policy**.
9. (Optional) Set when ticket sales start and end under **Advanced Settings**:

1. Enable the **Set Ticket Sale Period** toggle.
2. Select the **Opening date** and **Opening time **from the drop-down menus.
3. Select the **Closing date **and **Closing time **from the drop-down menus.
4. (Optional) Select the **Hide ticket if it is not on sale **checkbox.
5. Tap **Add**.
10. (Optional) Tap **+ Add a Ticket **to create additional ticket options.
11. Tap **Done**.

### Pay what you want

1. (Optional) Set the minimum price guests must pay for a ticket: 

1. Tap the **Minimum Price** toggle to enable it.
2. Tap the** Currency **drop-down and enter the minimum price.
2. Select an option under **Ticket Quantity:**

- **Unlimited tickets: **There is no maximum total number of tickets you are selling.
