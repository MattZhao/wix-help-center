---
title: "Wix Bookings Request: Moving a Participant to Another Class Using the Wix App"
---

Currently, it is not possible to move a participant from one class to another using the Wix app.

> **Workaround:**
>
> You can [move a participant from one class to another](https://support.wix.com/en/article/wix-bookings-managing-the-participant-list-for-your-classes#moving-participants-from-one-class-session-to-another) on desktop.

We are always working to update and improve our products, and your feedback is greatly appreciated.
