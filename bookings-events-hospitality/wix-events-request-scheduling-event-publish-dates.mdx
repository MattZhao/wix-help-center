---
title: "Wix Events Request: Scheduling Event Publish Dates"
---

Currently, you can publish an event immediately, but it is not possible to schedule it to be published for a future date. For example, scheduling an October event to be published in September.

We are always working to update and improve our products, and your feedback is greatly appreciated.
