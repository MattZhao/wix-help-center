---
title: "Wix Bookings Request: Setting a Minimum Number of Participants for Classes"
---

Currently, you cannot set a minimum number of participants for Classes in Wix Bookings. You can however, set a maximum number of participants.

We are always working to update and improve our products, and your feedback is hugely appreciated.
