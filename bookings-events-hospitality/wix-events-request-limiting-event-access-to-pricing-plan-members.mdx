---
title: "Wix Events Request: Limiting Event Access to Pricing Plan Members"
---

Currently, you can [create a membership plan](https://support.wix.com/en/article/wix-events-creating-a-membership-plan) using the [Pricing Plans app](https://support.wix.com/en/article/pricing-plans-an-overview). However, it is not possible to limit event access to members with a specific pricing plan only.

> **Alternatives to limit event access:**
>
> - [Only allow site members](https://support.wix.com/en/article/wix-events-customizing-registration-settings-messages#limiting-registration-to-site-members) to register for events.
> - [Password-protect event pages](https://support.wix.com/en/article/wix-events-creating-a-private-event#password-protecting-event-pages), requiring guests to enter a password to access them.

We are always working to update and improve our products, and your feedback is greatly appreciated.
