---
title: "Wix Events Request: Waitlists for Ticketed Events"
---

Currently, it is not possible to create a waitlist for ticketed events. It is, however, possible to create a waitlist for an RSVP events. [Learn How](https://support.wix.com/en/article/wix-events-limiting-registration-and-creating-waitlists-for-rsvp-events)

We are always working to update and improve our products, and your feedback is greatly appreciated.
