We're excited to announce that it is now possible to add line breaks. This feature is available with the [Wix Restaurants Menus (NEW) app](https://support.wix.com/en/article/wix-restaurants-adding-wix-restaurants-menus-new) and [Wix Restaurants Orders (NEW) app](https://support.wix.com/en/article/wix-restaurants-adding-and-setting-up-wix-restaurants-orders-new).
