---
title: "Wix Restaurants Request: Viewing a Full Order Log"
---

We're excited to announce that it's now possible to view an event log for any given order. This includes when and by whom the order was accepted or rejected, the reason for rejection, and so on. This feature is available with the [Wix Restaurants Orders (NEW) app](https://support.wix.com/en/article/wix-restaurants-adding-and-setting-up-wix-restaurants-orders-new).

>
> Learn about [the differences between the old and new online ordering apps](https://support.wix.com/en/article/wix-restaurants-about-the-differences-between-the-old-and-new-online-ordering-apps).
