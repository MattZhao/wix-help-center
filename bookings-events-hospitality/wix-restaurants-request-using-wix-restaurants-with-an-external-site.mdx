---
title: "Wix Restaurants Request: Using Wix Restaurants with an External Site"
---

Currently, it is not possible to use Wix Restaurants with an external site.

> **Tip:**
>
> You can create a single page menu site with Wix and link to it from your external site.

We are always working to update and improve our products, and your feedback is hugely appreciated.
