---
title: "Wix Restaurants Request: Changing the Time Slots for Table Reservations"
---

Currently, it is not possible to adjust the time intervals between reservation slots using the Wix Table Reservations app. The available time slots are set in 15-minute intervals, such as 10:00, 10:15, and 10:30.

We are always working to update and improve our products, and your feedback is greatly appreciated.
