---
title: "Wix Events Request: Creating Multiple Seating Maps for an Event"
---

Currently, you can [create one seating map](https://support.wix.com/en/article/wix-events-creating-a-seating-map) for a ticketed event, that includes different ticket types with unique seating arrangements (e.g. general admission, assigned seating, VIP areas).

However, it is not possible to create multiple seating maps for a single ticketed event, such as when using different facilities.

We are always working to update and improve our products, and your feedback is greatly appreciated.
