---
title: "The Odnoklassniki App is No Longer Available"
---

> **Important:**
>
> - This app has been retired from the Wix App Market and is no longer supported.
> - If you would like to continue creating buttons on Odnoklassniki (OK), you can create the button in Odnoklassniki and [embed the code in your Wix Editor](https://support.wix.com/en/article/embedding-an-odnoklassniki-ok-like-button-on-your-site).
