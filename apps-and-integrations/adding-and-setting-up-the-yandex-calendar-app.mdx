> **Important:**
>
> This app is no longer supported. Note that it is still possible to add the app by doing the following:
> 1. Click [here ](https://yandex.com/support/calendar/widget.html)and follow the instructions to receive an embed code.
> 2. Copy the code.
> 3. Add the code to page on your site using an HTML iFrame element. [Learn How](https://support.wix.com/en/article/wix-editor-embedding-a-site-or-a-widget#adding-html-content)
