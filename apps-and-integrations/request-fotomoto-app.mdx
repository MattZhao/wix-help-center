---
title: "Request: Fotomoto App"
---

Currently, Wix does not have a Fotomoto app. Fotomoto provides a Javascript code which needs to be added to a site's source code. This is not possible with a Wix site.

> **Tip:**
>
> If you're a photographer, we highly recommend that you check out [Wix Photo Albums](http://www.wix.com/app-market/wix-photo-albums/overview).
