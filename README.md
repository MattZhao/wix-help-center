# wix-help-center

Mintlify docs repo built from the WixQA help-center snapshot (6,221 articles, MIT license).
Generated by `benchmark/scenarios/docsite-mintlify/build-wix-help-center-repo.ts` in the Falconer `benchmark` flock. Do not edit pages by hand; regenerate instead.

- Pages: `<section>/<slug>.mdx`, with the article H1 moved into `title:` frontmatter.
- Text `<`, `{` and `}` are backslash-escaped so every page compiles as MDX.
- `docs.json`: one tab per section, one group per product (title prefix before ":"), feature-request articles in a nested "Feature requests" group.
